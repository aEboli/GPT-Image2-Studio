# GPT-Image2-Studio v0.2.18

`v0.2.18` 将主应用版本从 `0.2.17` 更新到 `0.2.18`。

## 更新内容

### 四个互斥配置区

- 配置抽屉顶部改为四个互斥配置区：`路由模式`、`直连模式`、`Gemini`、`主题`。原来的三通道选择栏加一个「配色」入口按钮不再存在。
- 只渲染当前选中配置区的连接字段，其余配置区的输入、下拉和按钮改为禁用而不只是隐藏，「获取模型列表」按钮同样按配置区禁用，不会再对一个没在用的通道发请求。
- 真正的生图路线状态从选择栏里拆出来单独保存。切到 `主题` 再切回来不会改动当前生效的调用通道，右上角状态继续显示原通道。
- 两个过长的配置区名收短：`直接调用模式` → `直连模式`，`Gemini模型` → `Gemini`。

### 主题区与界面配色

- 界面配色改为 `主题` 区里的一张独立卡片，`主题` 区不含任何连接字段。
- 配色选项固定为一行，抽屉过窄时横向滚动，不再按 4 列、2 列网格换行。
- 默认配色改为「经典靛蓝」，恢复 v0.2.6 的靛蓝色值（accent `#6f7cff`、面层 `#12192f`、点缀 `#879cff`），并在嵌入的 Temu 工作台镜像同一组值。
- 其余 6 套配色保持各自的传统色值。配色 ID 全部未变，已保存的选择仍能正确还原。
- 配色显示名收短：`青花甜白` → `青花`，`江南竹影` → `竹影`，`雨过天青` → `天青`，`故宫朱墙` → `朱墙`，`漆器朱漆` → `朱漆`，`敦煌石青` → `敦煌`。

### 文档与规范

- OpenSpec `workbench-usability-foundation` 规范改为描述四个互斥配置区和主题区内的配色卡片，替换原来的「配色入口紧跟 Gemini」验收场景。
- 两份 README 同步重写配置章节、核心功能条目和工具表，改为描述四配置区抽屉。
- 订正一处早于本次变更的文档偏差：平台画像表的应用内版本是 `2026-07-18.2`，中文 README 此前写作 `2026-07-18.1`。

## 升级说明

- 主应用每次更新仅递增一个补丁版本，即 `+0.0.1`。
- 既有配置、生成记录和图片资产不需要迁移。
- 已保存的界面配色选择不需要重新设置；仍停留在默认配色的用户会看到默认色从魏紫变为经典靛蓝。
- 商品图采集扩展使用独立版本线，本次主应用更新不会修改扩展版本。
