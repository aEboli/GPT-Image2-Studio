# GPT-Image2-Studio v0.2.6

`v0.2.6` 汇总套图记录工作台、Listing 真实性边界、提示词参考图复用、画廊/查看器细节和 Vercel Serverless 运行时修复，并提供对应的 Windows 桌面与浏览器兼容安装包。

## 版本亮点

- **套图记录工作台**：桌面宽屏采用左侧可持续加载的记录列表和右侧图片/Listing 常驻详情；关键词、日期筛选、多选、加载更多、当前详情和滚动状态互不干扰。移动端使用可展开的记录选择器，选择后自动收起。
- **Temu 导出预检基础**：保留现有本地 Temu 标准 Excel 待补全导出，新增批次预检、严格导出状态与远程图片验证的底层契约；缺失事实、图片或平台字段仍会明确列为问题，不会编造值或自动发布。
- **Listing 与生成计划**：进一步区分产品/包装尺寸重量、可信来源和估算边界；完善标题、关键词、SKU 颜色标签和图片角色文案，使买家可见标题与 SKU 图片名不再暴露内部货号或源文件编码。
- **提示词与图片查看体验**：提示词和参考图可独立清空；当前结果可以添加或拖入参考图，首次进入显示最近 10 张，当前会话成功生成后扩展至最近 50 张。图片详情的参数面板同时呈现文件名和相对路径。
- **Vercel Serverless 修复**：Vercel 安装生产依赖而非桌面开发工具，服务导出标准请求处理入口，避免 Electron 依赖和被截获的本地 `listen()` 回调导致函数初始化失败。

## 行为与安全边界

- Temu Excel 仍仅在本地 Node.js 或 Windows 桌面程序中生成。它不会登录、导入或发布到 Temu；真实平台导入校验、登录与验证码流程不属于本次自动化验收。
- 已完成的导出继续只使用保存的商品和 SKU 事实。价格、尺寸、重量、库存、产地或可公开访问图片缺失时，工作簿保留空单元格并在“导出问题”工作表提示人工补全。
- 本地图片使用 Cloudinary unsigned upload 时只接受 `cloudName` 与 `uploadPreset`；不会保存 API Key、API Secret、签名、Authorization 或 Cookie。远端资源的配额、生命周期和删除仍由用户的 Cloudinary 账户负责。
- Cloudflare 对本地文件导出等不支持能力继续返回明确的 runtime capability 契约，不读取本地 manifest，也不伪造下载文件。
- Vercel Serverless 修复已通过本地模拟回归测试；本次没有执行生产环境部署或生产复测。
