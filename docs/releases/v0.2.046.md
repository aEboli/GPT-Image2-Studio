# GPT-Image2-Studio v0.2.046

`v0.2.046` 将主应用版本从 `0.2.045` 更新到 `0.2.046`。

## 更新内容

- 思考等级下拉框移除预计耗时后缀，统一显示 `Low`、`Medium`、`High`、`XHigh`；实际思考等级值和请求行为保持不变。
- GPT 路由、直连、套图和写真等具体像素分辨率只显示 `宽 x 高`，移除 `1K`、`1.5K`、`2K`、`2.5K`、`720P` 和“最大”等展示前缀；原有像素 `value`、默认值、比例兼容和上游请求保持不变。
- 保留 Gemini 的 `512`/`1K`/`2K`/`4K` 与 Grok 的 `1k`/`2k` provider 分辨率档位，不把协议档位误改成像素值。
- 中英文 README 新增运行方式选择表，重写快速开始入口，并明确 UI 显示值与实际请求值的关系；同步更新 Windows 桌面与兼容安装包文档。
- 归档参数选择器的 OpenSpec 增量规范，补充共享模块同步、静态初始选项和渲染选项的回归断言。

## 版本规则

- 普通更新：更新位 +1。
- 版本格式为 `major.minor.patch`，patch 固定三位数字；上级版本变化时，下级版本归零。

## 升级说明

- 既有配置、生成记录和图片资产不需要迁移。
- 商品图采集扩展使用独立版本线，本次主应用更新不会修改扩展版本。
