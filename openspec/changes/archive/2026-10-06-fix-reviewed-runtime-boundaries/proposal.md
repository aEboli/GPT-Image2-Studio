## Why

全项目审查已复现八项问题：请求地址覆盖会转发服务端密钥、PPT 清单路径越界、桌面随机端口隔离保存配置、扩展注入函数丢失作用域、清单并发读写损坏 JSON、提示词历史覆盖、运行中任务被裁剪，以及 Listing 正文读取绕过超时。用户已要求修复这八项问题。

## What Changes

- 绑定服务端凭据与已配置地址；请求覆盖地址时必须自带有效凭据。
- 校验 PPT 清单 ID，拒绝目录穿越与非法文件名。
- 通过限于主工作台的 Electron IPC 持久化桌面 API 配置，保留随机监听端口。
- 向扩展注入函数显式传递版本参数。
- 以文件为单位串行保存清单和追加历史，并用临时文件原子替换。
- 保留全部运行中任务，只裁剪已结束的历史任务。
- 将 Listing 超时覆盖到响应正文消费结束。

## Impact

- 涉及配置合并、桌面入口、扩展后台、记录存储、任务快照及 Listing 网络读取。
- 浏览器共享实现同步到 `public/lib`，增加可复现的回归测试。
- 不变更版本、不发布产物、不迁移或删除用户已有生成文件。
