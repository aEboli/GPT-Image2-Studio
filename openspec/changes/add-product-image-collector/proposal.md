## Why

套图模式虽然已经支持文件上传、拖放和页面级粘贴图片，但没有显式的剪贴板导入入口，也无法接收浏览器扩展采集的一整批商品图。用户目前需要先依赖第三方采集工具下载图片，再从文件系统手工筛选和上传，商品主图、详情图与 SKU 图之间的来源和顺序也会丢失。现有“复制到 Studio”只复制版本化文本清单，无法让聊天软件把几十张选中图片识别为一次粘贴的多个独立文件。

需要增加一个与 GPT-Image2-Studio 配套的浏览器扩展，以 1688、Amazon、Temu、TikTok Shop、SHEIN 和大健云仓 GigaB2B 的消费者可见商品详情页为明确边界，高精度采集商品区域图片、批量下载到同一商品文件夹，并通过版本化清单交给 Studio。该链路必须保留当前套图参考图 15 张上限，不把非商品图、任意剪贴板网址或受保护页面数据无边界地带入本地服务。

## What Changes

- 在套图参考图标题区增加“从剪贴板导入”入口，并让套图界面的 `Ctrl+V` 直接识别扩展清单或原生图片，继续复用现有参考图文件状态、去重、压缩、识别和生成链路。
- 定义 `GPT_IMAGE2_STUDIO_PRODUCT_IMAGES_V1` 文本清单协议，保存商品页来源、商品标识、标题、采集时间以及主图、详情图、SKU 图的有序图片条目。
- 当清单图片超过套图剩余槽位时打开带真实缩略图的批次预览，缩略图通过同源受限代理按需读取；自动预选不超过剩余槽位的图片并要求用户明确确认，不得静默截断或提高生成接口的 15 张上限。批次预览提供单行全选、全不选、反选及主图/详情图/SKU 分类选择，并在每张图片下方提供纯图标放大入口，在当前弹窗内查看大图且不改变选择状态。批次列表不得被 `Escape` 直接关闭；大图打开时，`Escape` 只返回批次列表。Studio 批次弹窗在桌面视口中使用接近内容工作区的自适应宽高（最大约 1980×1180px），大屏候选网格以约 210px 最小卡片宽度自然排布，最多一行 8 张；选择操作原地同步候选卡片并保持列表滚动位置、焦点和已加载缩略图。Studio 放大查看与插件内查看器使用一致的 contain/cover、滚轮缩放、左键边界拖动、旋转、双击复位、前后导航、外部点击关闭和分层 Escape 行为，并继续通过同源受限代理读取图片。
- Studio 批次候选卡片的媒体区固定为 1:1，所有原图使用 `contain` 在纯白背景中完整显示；图片本体固定为媒体区宽高的 98%，因此正方形图片也在四边各保留约 1% 白边，非正方形图片继续保留剩余轴白边且不裁切。分类、序号和尺寸信息移到图片下方操作栏的左半区，放大按钮位于等宽的右半区，图片层不再被文字覆层遮挡。已选卡片和媒体区使用明显橙色边框与描边，未选卡片继续使用中性边框。
- 为本地运行时增加受限商品图代理，只接受受支持平台的商品详情页来源及与该平台匹配的明确图片 CDN，限制请求体、查询参数、重定向、文件类型和单图大小；同一边界同时服务候选缩略图和确认后的文件导入，跨平台来源与图片域名组合必须拒绝。
- 新增 Manifest V3 浏览器扩展，在受支持平台的商品详情页自动显示一个不读取商品数据的悬浮入口；只为明确的商城域名声明受限站点权限，使入口首次点击即可直接打开采集窗，不依赖先点击扩展栏 action 授予临时权限。平台适配器分别约束详情页 URL、可信图片域名、商品 ID、标题、主图、详情图、SKU 图和已知 DOM 回退区域；自动内容脚本使用可表达的最窄路径模式，后台与采集器再按完整 URL 二次校验。采集窗默认固定铺满网页可视区右侧全高，桌面宽度约占视口的 31% 并限制在 520–540px，在当前显示缩放下接近截图中的 800px；桌面布局每行 4 张，缩略图媒体区约为 115–120px，分组保留 8px 水平内边距，四列卡片以 6px 小间距均匀排列。头部左侧只显示商品标题，隐藏清单为了追踪和下载而保留的标准平台后缀；右侧品牌区在刷新与关闭按钮之前动态显示来源平台名称，并在固定区域内相对居中。按钮与文字维持紧凑比例，仅增加面板及图片卡片的可用空间。图片底部使用一条黑色半透明信息栏和白色文字，完整显示短分类名称与分辨率，同时让被覆盖的图片内容保持可辨认。支持从合并标题栏空白区域拖动和左右边缘停靠；主图、详情图和 SKU 图分组使用同一色相、同一饱和度并按明度形成连续且明显的层次。全选、反选、开启/关闭折叠以及三个追加分类选择共六个小按钮保持在同一行，空间不足时该行可横向滚动而不换行。采集优先读取平台公开声明的结构化商品图片，仅在对应声明结果不可用时使用该平台已知商品区域兼容回退；主图和详情图继续在各自分类内按规范化 URL 合并重复项。SKU 图在平台公开稳定来源变体标识时按规范化 URL 与受限 `variantKey` 共同识别，没有可信标识时回退到规范化 URL 与规格名称；同图同名但来源变体不同的真实选项分别保留，同一来源变体的重复 DOM 仍只保留第一次出现的完整条目、顺序和文件名。跨分类相同 URL 继续分别保留主图、详情图或 SKU 图语义，默认排除推荐、评价、头像、Logo、广告、导航和占位图。
- 采集窗右上角品牌与平台区域改为主题切换按钮，点击后按“白天、蓝调、夜晚”循环切换，并在平台名称后用太阳、水滴或月亮小图标显示当前主题。三套主题分别适配标题栏、选择工具、状态行、分组、卡片、SKU 名称、底部操作栏、提示和图片查看器；蓝调采用明显的中深蓝“蓝调时刻”表面、冷白文字和亮青色选择态，不再是接近白天主题的浅灰蓝。SKU 名称行分别使用白天黄橙、蓝调亮青和夜晚洋红的高对比背景、文字与分隔线，不再复用难以辨认的浅青色微调。主题切换只更新现有面板样式与图标，不重建图片列表，也不改变选择、滚动、折叠或查看状态。
- 商品标题优先读取平台明确的商品名称节点；1688 当前页面只读取 `#productTitle .title-content`，不把同一父容器中的代发排行、库存稳定性、退款率、揽收率或加购人数拼入标题。最终标题统一以无引号的 `——平台名称` 结尾，并避免重复追加同一平台后缀；旧版带弯引号或直引号的后缀会规范化为纯平台文字。
- Temu 新版消费者详情页按稳定语义区域采集：主图库限定在 `#leftContent` 的列表框，SKU 图限定在 `#rightContent` 的命名规格单选项，详情图限定在 `#goodsDetail` 的商品详情媒体。用户触发采集后，插件可以点击该详情容器内文案精确匹配的 `See more` 并等待详情图片节点稳定，但不得点击推荐区的 `View more` 或 `See more items`。可信 `data-src` 已指向商品 CDN 时，当前 `src` 的 1×1 懒加载占位尺寸不得导致真实图片被过滤。
- TikTok Shop 同时支持旧 `www.tiktok.com/shop/pdp/...` 与当前 `shop.tiktok.com/<locale>/pdp/...` 消费者详情路由。当前页面优先读取受限大小的 `__MODERN_ROUTER_DATA__`，只接受商品 ID 与地址一致的 `product_model`：`images` 作为有序高清主图，`description` 中明确的图片条目作为详情图，带图销售属性的每个 `property_value_id` 作为一个稳定 SKU 来源；不同尺寸 SKU 共用同一属性值图片时不得重复展开。声明数据存在时不再追加 DOM 缩略图或整页媒体；仅在声明数据不可用时使用标题与 Open Graph 商品名严格匹配的已知主图、详情图区域。最终清单保留页面声明的可信高清 URL 和宽高，去重身份可以忽略 TikTok CDN 查询参数及 `~tplv-...` 变换后缀，但不得把推荐、Logo、头像、店铺、评价或其他页面图片带入结果。
- Amazon 当前商品页优先读取受限大小的 `ImageBlockATF` 与 `ImageBlockBTF` 内联声明，只接受地址栏当前 ASIN：ATF 的 `colorImages.initial` 作为完整有序主图库，BTF 的 `colorToAsin` 与同名 `colorImages` 作为带图 SKU，并以 ASIN 形成稳定来源键。采集器只做受限字符串解码和 JSON 解析，不执行页面脚本；有效声明命中后不再追加 DOM 缩略图或其他规格的隐藏大图。A+ 商品描述区继续作为详情图边界，评价图、占位图、视频封面和非当前 ASIN 声明均排除；声明 URL 的原始分辨率未知时先保留为 0，等待面板加载规范化原图后更新自然尺寸，不把 40×40 缩略图或当前渲染尺寸冒充原图分辨率。
- 大件云仓主图与规格缩略图中的已知 `x-oss-process` 缩放参数在采集时恢复为同一可信 CDN 对象的原图地址；每个规格从 `.options-item[data-gmd-attr-product_id]` 或其商品链接的 `product_id` 读取稳定来源身份，即使多个关联商品共用相同缩略图和相同显示名称也分别保留。当前激活规格使用有序主图库最后一张作为 SKU 图，其他命名规格使用其规格缩略图对应的原始对象，并保持规格顺序与名称。采集器不点击规格或跳转商品，主图集合在 SKU 映射前固定；面板卡片可为大件云仓原图派生受限尺寸的轻量预览，并通过同一 CDN 的轻量 `image/info` 元数据读取真实原图宽高，但复制、查看和下载继续使用规范化原图。
- SHEIN 当前商品页把主图库、详情内容、颜色 SKU 和整页商品容器分开处理：优先读取 `ProductGroup` 声明的高分辨率主图并以当前 `main-picture` 区域作为兼容回退，详情图只接受真实 `details-pic` 媒体，SKU 图继续限定在颜色选项。页面状态已为同一资源明确声明 `900x` 图片时，主图和 SKU 图都使用该声明地址，不把 `220×293` 画廊或颜色缩略图冒充最终图片；不同尺寸或格式但资源路径哈希相同的声明、Open Graph 和 DOM 表示只保留高分辨率声明项。不得再用覆盖整页的 `goods-detail` 类名收集详情图，也不得把画廊缩略图、社交图标、属性图标、店铺图片、评价图或推荐图混入详情图。
- 扩展支持全选、反选以及追加选择全部主图、详情图或 SKU 图；三个分类按钮不得取消其他分类或单图的既有选择。单图勾选、组内全选、全选、反选和分类追加选择只原地同步卡片、计数与按钮状态，不销毁重建图片列表，面板滚动位置、当前焦点和已加载缩略图必须保持稳定。每个分组标题栏同时显示分类数量、该组已选数量、支持半选状态的组内全选框和纯图标组内下载按钮，组内下载只提交该组当前选中图片且无选中项时禁用。已选卡片使用明显青绿色边框，卡片勾选框和组内全选框使用同一青绿色强调，未选卡片使用克制的中性边框；SKU 规格名称行按白天、蓝调和夜晚主题使用彼此可见区分的高对比颜色，图片名称和分辨率分别显示在图片底部左右两侧。头部左侧完整显示纯商品标题并允许在自身区域内换行，右侧品牌区显示当前平台名称且相对居中；清单中的完整平台后缀保持不变，不再在标题下方显示选择统计。选择总数、商品图总数和 SKU 规格数集中显示在六个选择按钮下方的状态行。每张图片继续提供带可访问名称和悬停提示的纯图标查看/单图下载按钮，查看器作为采集窗内部叠加层，仅覆盖并压暗插件内容且不超出插件边界，商品页其余部分保持原状；删除左上角“返回”和图片说明标题，只在右上角保留半透明关闭图标。底部半透明工具栏提供以 cover 方式铺满插件舞台的“全屏”、向左旋转、向右旋转、放大、缩小和“恢复初始视图”六个带中文提示的紧凑图标控件。查看器以图片自然像素为统一缩放基准：默认打开使用 contain 完整显示，必要时允许低于常规 50% 缩放下限；全屏使用 cover 填满舞台并允许裁切。默认 contain、继续缩小、全屏和其他任何缩放比例都保持左键抓取拖动；某轴上的图片小于舞台时只能在该轴空白范围内移动并保持整图可见，图片大于舞台时可平移到两侧图片边缘但不得越界。“恢复初始视图”每次执行都会结束正在进行的拖动，将旋转与位移归零，并按当前舞台重新计算与首次打开一致的 contain 比例；它与“全屏”都可连续重复点击且不保留选中或锁定外观。查看器继续支持滚轮缩放、点击图片外区域或右上角关闭按钮关闭；快速双击图片执行相同复位并保持查看器打开。底部删除当前图片名称和整体次序说明，只保留半透明前后切换按钮。选中图片可复制为 Studio 清单或下载到默认下载目录下按日期和商品分层的文件夹，下载文件使用可读的中文类别与 SKU 规格名称，不再额外下载 JSON 文件。
- 在底部操作栏的“复制到 Studio”和“下载所选”之间增加“复制图片”。该命令只作用于当前选中项，通过扩展专用的 Windows Native Messaging 剪贴板助手逐张复用可信商品图校验，把成功图片保存到临时批次目录，并一次写入系统剪贴板的 FileDrop 文件列表，使聊天软件可一次粘贴多个独立图片文件；安装助手后不要求启动或打开 Studio，也不依赖本地 HTTP 端口。采集清单和直接复制单批最多支持 1000 张图片，扩展到助手的请求限制为 4 MiB，图片总量仍限制为 512 MiB；该数量边界不提高套图生成的 15 张参考图上限。异步图片准备完成后，助手必须把最终 FileDrop 写入显式调度到专用 STA 线程，并对短暂剪贴板占用执行有界重试。复制成功后在插件内部短暂显示半透明的成功提示并淡入淡出，连续复制时重新播放；扩展不尝试写入多个浏览器 `ClipboardItem`，不扫描任意本地端口，不增加通用 IPC 或 `tabs` 权限。助手未安装、运行时非 Windows、全部图片失败或系统剪贴板写入失败时必须显示明确错误。部分图片失败时仍复制成功项并分别报告成功与失败数量。
- 为受支持商城的站内无刷新导航增加轻量入口监测：内容脚本可以覆盖已经授权的商城主机，但只有完整商品详情 URL 通过二次校验时才挂载悬浮入口，用户点击前不得扫描商品图片。商品路由变化时清理上一商品的采集窗并重新同步入口，使 Amazon、Temu、TikTok Shop、SHEIN 和大健云仓等 SPA 跳转不再依赖扩展栏 action。悬浮入口和采集窗需要识别并替换扩展更新后遗留的失效 DOM 实例；打开、采集、复制和下载消息增加有界超时，失败或无响应后必须恢复可操作状态。长批量复制等待期间只锁定会发起另一项传输或重新采集的命令，选择、查看、折叠和关闭仍保持响应；SKU 规格行不得通过运行时测量或缩小字号来适应卡片宽度。
- 所有卡片缩略图在稳定方形媒体区内以纯白背景和 `contain` 完整展示，图片本体固定为媒体区宽高的 98%，四边各露出约 1% 白底；非 1:1 图片允许更多留白而不得裁切。查看、复制、保存和下载继续使用清单中的原始图片 URL。SKU 卡片在图片信息与查看/下载操作之间以固定 `12px` 粗体完整显示该条目的规格名称，不添加“规格”“SKU”或序号前缀，不使用省略号或动态缩字。名称允许在卡片宽度内任意断行，并按实际行数自然增高；短名称不得预留多行空白，超长内容继续撑高卡片。同一网格行的查看/下载操作栏保持底部对齐。白天、蓝调和夜晚分别使用黄橙、亮青和洋红系高对比名称配色；主图和详情图不显示该行。
- 在创作工具菜单增加“商品图采集插件”入口，由本地应用生成并下载扩展 ZIP；明确保留 Chrome 的用户安装确认，不声称或尝试静默安装。
- “商品图采集插件”名称在鼠标悬停或键盘聚焦时显示完整说明，明确支持平台、主图/详情图/SKU 图能力、Studio 复制与按商品下载、安全边界以及 Chrome/Edge 安装确认；说明不得遮挡名称或被菜单裁切。
- 将扩展源码和共享协议纳入桌面安装包白名单，并增加协议、筛选、代理、打包、布局和运行时验证。

## Capabilities

### New Capabilities

- `product-image-collector`: 定义 1688、Amazon、Temu、TikTok Shop、SHEIN 和大健云仓商品图发现、保守筛选、分组、Studio 清单复制、Windows 多文件图片复制、同目录下载、来源证据、最小权限和扩展包分发行为。

### Modified Capabilities

- `creation-mode`: 增加原生剪贴板图片和商品图采集清单的显式导入、批次预览及 15 张槽位边界。
- `desktop-application`: 增加受限商品图代理和浏览器扩展包下载入口，同时保持渲染进程与外部导航的最小权限边界。

## Impact

- Frontend: `public/index.html`、`public/app.js`、`public/styles.css` 及新的共享浏览器模块。
- Local API: 新增同时支持受限缩略图读取与确认导入的单图代理以及扩展包下载端点；不修改现有生成、分析或记录接口。Windows 多文件剪贴板由扩展专用助手处理，不经过 Studio API。
- Extension: 新增 `extensions/product-image-collector/`，支持 Chrome/Edge 中六个平台的消费者可见商品详情页。
- Packaging: 桌面包增加扩展源码；扩展 ZIP 在用户请求时生成，不提交构建产物。
- Cloud: 云端运行时不代理第三方商品图，也不生成本地扩展包；页面必须返回清晰的运行时不支持反馈。
- Security: 不读取或传输 Cookie、API Key、密码和登录令牌，不绕过登录、反爬或平台保护，不允许任意 URL 代理。
