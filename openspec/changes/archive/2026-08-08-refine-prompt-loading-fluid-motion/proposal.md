## Why

提示词生图正在处理时，主预览目前让内部填充与外环做对称上下漂浮，多任务时还会整体旋转。画面更像轻质发光气泡，无法传达用户所说的液体流沙的重量、向下沉降和连续流动感。

## What Changes

- 保留现有生成阶段、并发任务数量、最多六个预览节点和节点复用逻辑，只优化加载壳内部的视觉运动。
- 将中心填充拆成液体主体、液面扰动、下坠细流和底部沉积层，表现加速下落、撞击摊平、黏滞回流和轻微余振。
- 让液体层使用独立的重力/黏度参数，随 `uploading`、`connecting`、`generating`、`saving` 阶段和并发能量在有限范围内变化；这些参数只控制视觉时序，不冒充真实生成百分比。
- 多任务预览保持稳定的屏幕向下重力方向，不再让整个 orb 场持续旋转；外环继续以低幅独立运动提供处理中反馈。
- 保持无可见文案、`aria-hidden` 装饰语义、`role=status` 状态播报和 `prefers-reduced-motion` 降级。

## Capabilities

### Modified Capabilities

- `creation-mode`: 仅优化提示词生图主预览的加载壳液体重力反馈，不改变图片拆解、融图分析和快速溶图的共享加载壳契约。

## 验收边界

- 生成中的中心液体必须能看出向下位移、底部堆积/摊平和非对称回流，不能只做对称的 `translateY` 漂浮。
- 液体装饰不得溢出容器、改变预览布局尺寸或遮挡其他控件；多任务 orb 的中心间距和稳定槽位保持现有契约。
- 阶段颜色、阶段进度和任务状态文本保持现有含义；视觉物理参数不得被解释为实际 API 进度。
- 减少动态效果时，液体、细流、沉积层、外环和多任务场均停止动画，但保留静态底部锚定形态。

## Impact

- 前端动效结构：`public/app.js`、`public/styles.css`。
- 纯函数视觉参数：`lib/preview-loading-shell.mjs` 及同步的 `public/lib/preview-loading-shell.mjs`。
- 验证：预览加载运行时测试、工作台 CSS 契约测试、OpenSpec 严格校验和隔离端口浏览器截图。
- 不改变生成 API、队列调度、任务持久化或图片结果数据。
