## Why

当前套图示例的首张图请求包含较长的主提示词和参考图标签。主提示词混合了画面要求、中文界面标签、用途型比例说明、通用平台/行业描述，以及重复的商品身份、表面内容和目标语言边界，增加了每张图携带的上下文。

需要精简模型实际接收的文字，同时保留商品事实、画面角色、参考图归属、平台硬性规则、商品主体保护和目标语言要求。分辨率、质量、格式等已通过独立 API 参数发送，不应在普通套图提示词中重复描述。

## What Changes

- 精简套图普通轮播图与 SKU 图的规划提示词，删除重复或只复述界面设置的文字，保留当前图片角色所需的画面目标、用户事实、有效平台/品类约束、参考图证据和质量要求。
- 将比例说明压缩为短英文值，例如 `Aspect ratio: 1:1.`，不再附带比例用途、中文比例名称或额外构图解释。
- 将系统生成的角色、平台、品类和视觉风格控制文字改为简洁英文，省略通用且无动作含义的界面标签；保留用户输入的商品名称、描述、卖点和参考图备注原文。
- 合并重复的商品身份、商品表面内容及目标语言约束；参考图标签只保留识别图片、角色和必要来源证据所需的信息。
- 保持请求路由、API 参数、图片选择、轮播规划、平台限制、参考图角色语义及 `infographic-rebuild` 专用提示词不变。

## Non-Goals

- 不翻译或改写用户输入的商品名称、描述、卖点、尺寸事实或参考图备注；其中含有中文时继续按原文传递。
- 不改变生图模型、推理等级、分辨率、比例值、质量、输出格式、背景、上游 API 结构或请求数量。
- 不改变图片角色规划、平台约束、参考图调度、商品身份与商品表面内容保护的含义。
- 不压缩 `infographic-rebuild` 的来源事实和翻译要求。

## Capabilities

### Modified Capabilities

- `creation-mode`: 普通轮播图和 SKU 图使用精简的英文控制提示词与比例说明，避免重复参考图身份标签。

## Impact

- 影响套图计划提示词、套图运行时生成提示词和参考图用途标签的构造。
- 需要更新相关 planner、runtime prompt 与 reference-label 测试；无需修改 API 请求构造或生图参数。
