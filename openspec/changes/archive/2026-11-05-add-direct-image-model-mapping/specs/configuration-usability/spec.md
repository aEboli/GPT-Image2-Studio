## ADDED Requirements

### Requirement: 直连生图映射使用可编辑胶囊

系统 SHALL 在 GPT 直连配置的「流式输出」下方、文本/视觉接口配置上方提供「生图模型映射」。每条规则 SHALL 显示为两个可编辑胶囊和右向箭头，左侧表示当前选择的模型，右侧表示实际发送给生图渠道的模型 ID。用户 SHALL 能添加和删除规则，且两个胶囊 SHALL 同时支持手动填写及选择模型候选。

#### Scenario: 配置渠道模型别名

- **WHEN** 用户填写 `gpt-image-2.6-sunburst → IMAGE-2.6` 并保存
- **THEN** 映射按该方向保存并在重新打开配置时恢复
- **AND** 原生图模型选择仍保持用户选择的名称

#### Scenario: 一次获取更新生图候选

- **WHEN** 用户通过直连生图的模型获取操作成功读取模型列表
- **THEN** 原生图模型控件与映射两端可使用本次候选
- **AND** 用户仍可手动输入列表中没有的名称或 ID
- **AND** 系统不会自动猜配或创建映射规则

#### Scenario: 模型获取失败保留输入

- **WHEN** 用户获取模型列表失败
- **THEN** 界面显示错误且保留已填写的映射内容

#### Scenario: 窄屏编辑映射

- **WHEN** 配置面板可用宽度缩小或模型 ID 很长
- **THEN** 胶囊保持可编辑且完整值可检查
- **AND** 映射与文本接口不重叠，也不引起面板横向溢出
