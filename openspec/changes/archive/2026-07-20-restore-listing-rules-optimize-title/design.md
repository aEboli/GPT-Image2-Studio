## Context

应用的 Creation Listing 路径统一使用 `forceV1`。上一轮变更同时替换了整个 V1 Prompt，并将结果门禁从“拒绝任意功能词”放宽为“只拒绝高风险声明”。因此不仅标题，卖点、痛点、五点和描述也全部改变了写法。

## Decisions

### 1. 恢复旧版字段写法

`buildPlatformV1ListingPrompt` 恢复为原有 Listing SEO Agent、平台规则、客观属性和固定五点模板。旧式英中字段合同、单次请求和确定性 fallback 保持不变。

### 2. 标题使用窄范围价值例外

标题顺序为平台要求的数量、核心商品词、已提供核心卖点、该卖点直接解决的痛点或购买顾虑，再补充必要搜索词。卖点和痛点结果必须能从 `productDescription`、`sellingPoints`、SKU 或其他可追溯商品事实中得到直接支持。

若没有足够事实支持具体结果，标题只能使用由已提供数量、选项、变体或包装事实解决的购买前顾虑，不能虚构功能、性能或使用效果，也不能突破现有标题禁用尺寸规格的规则。

### 3. 非标题字段继续使用旧门禁

结果门禁在检查功能或效果词时排除 `title` 与 `zhDisplay.title`，但仍检查所有其他内容字段。标题仍经过高风险声明检查，因此排名、社会证明、认证、医疗、安全、价格、折扣、保证、退款以及没有证据的材料、兼容性和性能声明不会被直接保留。

### 4. 不重写历史记录

本变更只影响用户下一次显式生成或重写 Listing。已经保存的 Creation manifest 和 Listing 草稿不做批量修改。

## Verification

- Prompt 测试确认旧版 SEO、固定五点和非标题属性约束恢复。
- Prompt 测试确认标题必须包含已提供卖点和直接支持的痛点解决结果。
- 结果测试确认标题中的证据型结果表达被保留，而非标题功能词和标题高风险声明触发 fallback。
- 运行 Listing 专项测试、完整测试、public 同步、Pages 构建和 OpenSpec strict validation。
