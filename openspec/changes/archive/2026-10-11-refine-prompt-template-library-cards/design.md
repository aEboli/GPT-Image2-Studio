## Context

模板卡片同时支持列表和图片两种浏览方式。列表卡片的高度跟随配图比例；图片卡片需要保留原始图片比例并减少错落排列留下的空位。

## Decisions

1. 列表视图保留图片决定的卡片高度。标题和分类在单行宽度不足时隐藏，完整提示词只有在剩余高度足够时才显示。
2. 图片视图使用 CSS 多栏排版，并由模板库区域承担纵向滚动，使各列可自然连续排列。
3. 图片视图把标题和分类移到图片下方并允许完整换行；提示词仍在灯箱中查看。
4. 卡片操作区只保留“应用”，使用实心强调色按钮。
5. 模板详情灯箱中的“复制”与“应用”不在本次范围内。

## Verification

- 静态契约测试确认卡片没有复制到个人模板操作、列表文本按完整容纳情况显示、图片视图使用多栏布局且应用按钮突出。
- 模板库既有数据和预览契约继续由同一测试覆盖。
