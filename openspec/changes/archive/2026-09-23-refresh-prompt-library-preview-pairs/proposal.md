# 刷新提示词模板图片与提示词配对

Prompt Kit 的部分预览图曾按位置套用到模板，且图片视图把不同宽高比的资源强制裁切成正方形，导致图片和提示词看起来不对应。用户要求模板图片必须与提示词成对，并按真实比例显示。

本次变更将 YouMind 人像/头像快照整理成稳定的图片、标题、提示词和详情页配对，删除模板库瀑布流入口，仅保留列表和图片视图，并让图片视图保留每张素材的原始宽高比。

## 范围

- 使用 40 条带来源归属的 YouMind 图片-提示词记录构建人像与头像分类。
- 非人像分类继续使用确定性的离线预览，但每条模板拥有独立构图变体，不借用其他模板的照片。
- 图片视图使用真实比例，不通过正方形 `cover` 裁切图片。
- 保留现有模板应用、复制、编辑、删除、灯箱和离线运行行为。

## 非目标

- 不在运行时抓取 YouMind 或其他第三方站点。
- 不恢复模板库瀑布流视图。
- 不把目录条目写入用户模板存储。
