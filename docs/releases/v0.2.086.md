# GPT-Image2-Studio v0.2.086

`v0.2.086` 将主应用版本从 `0.2.076` 更新到 `0.2.086`。

## 更新内容

- AI 电商套图规划在一次请求中生成最多 20 张完整提示词，并逐图绑定营销目标、受众、商品事实和参考图。预览、生成、队列、记录、失败重试和补图沿用同一份已确认计划。
- 参考图智能识别补充具体受众群体、独立卖点、痛点和事实关联的营销建议。建议与资料不足状态按实际依据展示，不用虚构参数或商品能力补足数量。
- 规划接口支持事件流进度，界面逐步展示规划阶段、已接收任务和营销摘要；默认 JSON 调用保持兼容，模型原始响应不会通过进度事件发送到浏览器。
- 对缺少整套条目、提示词、唯一 ID、有效商品事实或参考图来源的结果执行明确校验，避免无效计划启动生图。有效预览、普通重试和补图不会重新规划或改写冻结提示词。
- Listing Agent 按所配置的 Responses 或 Chat Completions 端点选择对应请求协议。

## 版本规则

- 小功能更新：更新位 +10。
- 版本格式为 `major.minor.patch`，patch 固定三位数字；上级版本变化时，下级版本归零。

## 升级说明

- 既有配置、生成记录和图片资产不需要迁移。
- 商品图采集扩展使用独立版本线，本次主应用更新不会修改扩展版本。
