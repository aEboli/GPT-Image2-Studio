## Context

现有模板库位于页面根部，使用固定定位和视口宽度。列表通过图片加载事件计算行高，竖图会产生超出摘要需要的留白。

## Decisions

- 为预览元信息与画布增加共同的相对定位容器，打开时将既有模板库节点挂入该容器，以绝对定位填满容器。由正常布局处理窗口尺寸、缩放和侧栏尺寸变化。
- 工具栏及胶片条位于容器之外，左侧生成表单不属于模板库覆盖区域。
- 使用 CSS 限定列表行高，缩略图使用 contain，标题最多两行，摘要最多三行，删除原有按图片计算行高和隐藏标题的逻辑。
- 使用容器查询适配模板库自身宽度；受限宽度采用纵向可滚动内容，窄屏打开时为预览内容区保留足够高度。

## Validation

运行模板库与工作台布局检查、JavaScript 语法检查和 OpenSpec 严格校验；浏览器检查桌面、窄屏及缩放后的边界、滚动和模板应用。

## Results

- 模板库与工作台布局的 194 项检查通过，缓存版本相关的另外 13 项检查通过；最终改动后的聚焦复查通过。
- Playwright 在 1920、1440、1280、980、390 像素宽度验证模板库边界与预览内容区一致，左侧生成操作、预览工具栏及胶片条不被覆盖，无页面横向溢出。
- 80%、125%、150% CSS 布局缩放后边界仍一致。窄屏分类导航保持可滚动且不与结果区重叠。
- 字号、列表与图片视图切换、图片预览返回及应用模板通过，未出现页面脚本错误；未发送实际生图请求。
