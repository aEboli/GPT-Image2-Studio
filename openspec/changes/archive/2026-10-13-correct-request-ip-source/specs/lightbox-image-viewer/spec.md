## MODIFIED Requirements

### Requirement: 图片详情显示请求发起 IP

图片详情参数页 SHALL 在所有既有参数之后显示“请求发起IP”。新生成图片记录中的请求发起 IP SHALL 表示 Studio 服务端在生成请求期间通过上游 HTTP transport 查询到的公网出口 IP，不得使用浏览器访问地址替代。若记录保存了该值，参数页 SHALL 显示保存值；若查询失败或历史记录没有该字段，参数页 SHALL 显示“未记录”。已有历史记录 SHALL NOT 被当前访问者地址补写或迁移。

#### Scenario: 查看新生成图片的参数

- **WHEN** 用户打开保存了服务端出口 IP 的生成图片并选择“参数”
- **THEN** 参数列表最后显示生成时保存的服务端出口 IP

#### Scenario: 查看旧图片的参数

- **WHEN** 用户打开没有请求发起 IP 字段的历史图片并选择“参数”
- **THEN** 参数列表最后显示“请求发起IP：未记录”
- **AND** 系统不使用当前浏览器连接地址补写该字段

#### Scenario: 查看出口 IP 查询失败的图片参数

- **WHEN** 用户打开生成期间 IP 查询失败、没有请求发起 IP 字段的图片并选择“参数”
- **THEN** 参数列表最后显示“请求发起IP：未记录”
- **AND** 系统不使用当前浏览器连接地址补写该字段
