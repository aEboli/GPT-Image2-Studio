# 显示当前生图请求 URL

## Why

参数摘要已有模型和请求发起 IP，但无法直接确认当前生图请求使用的完整接口地址。用户需要在现有 IP 行下方直接查看完整 URL，便于确认生图通道与接口后缀。

## What Changes

- 在请求发起 IP 下方追加 `Url :` 一行，显示当前生图通道的完整请求 URL。
- 复用现有通道配置和地址拼接逻辑，随通道、地址和协议后缀更新；长地址沿用摘要自动换行样式。

## Impact

- 仅修改当前参数摘要的前端展示，不新增配置字段或修改请求发送行为。
- 更新 runtime-configuration 规格并验证四个生图通道的显示地址。
