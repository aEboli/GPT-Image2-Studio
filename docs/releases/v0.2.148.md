# GPT-Image2-Studio v0.2.148

发布日期：2026-11-11。主应用由 `0.2.138` 更新至 `0.2.148`，按小功能更新规则将更新位增加 10。

## 更新内容

- 重写英文与简体中文 README，统一下载入口、快速开始、API 配置、功能表和文档导航。首页各 186 行，截图按功能折叠；详细配置、参数和历史记录保留在独立文档中。
- 修正文档中的旧构建命令、2.6 模型选项、图像格式说明和迁移后的相对链接；徽章、安装包名称、页面版本与发行说明保持一致。
- Listing 标题增加西班牙语、法语、意大利语和波兰语，已有译文按英、德、西、法、意、波、中顺序展示，并支持独立复制、字符统计和导出。其他字段沿用原有语言规则。
- 套图记录的“更多”菜单增加“生成 Listing”，只处理勾选记录，支持重新生成已有草稿；原有补缺操作继续保留。
- 尺寸标注仅用于专门的尺寸／规格图片，普通营销画面的违规提示词会被修复或排除。
- 修复补图时的服务商配置错配、同套图并发覆盖和 Temu 元数据丢失；修复 Chat 缓冲文本、PDF 消息结构、401/403 与取消后的错误重试，以及页面加载失败后无法重试。
- 优化 Listing 实时输出与请求耗时的显示，并同步供本地 SHEIN 上品工作台使用的文字模型设置入口。
- 更新七个 `brace-expansion` 锁项至同主版本修复版。

## 升级说明

- 配置、已保存图片和历史记录继续使用原有数据位置。升级前可按自己的备份策略保留数据副本。
- 历史 Listing 不会自动调用模型补译；需要新增语言时重新生成对应记录。
- 旧的未提交营销计划如提示条件失效，需要重新预览规划后再生成。
- 商品图采集插件采用独立版本线，本次没有修改插件版本。
