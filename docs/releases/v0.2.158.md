# GPT-Image2-Studio v0.2.158

发布日期：2026-11-18。主应用由 `0.2.148` 更新至 `0.2.158`，按项目小功能更新规则将更新位增加 10。

## 更新内容

- 每套营销图片独立规划，从八类共 64 位视觉营销 Agent 中分配设计人设，并把构图、布光、配色和版式要求写入实际图片提示词。批量任务保留暂停、继续、停止及重试状态，补图沿用原套图设计。
- 批量 AI 提示词增加可选“设计方向”，将活动或场景偏好传入每套规划；留空沿用自动规划。
- 同一核心商品操作场景在套内只使用一次，更换机位、背景或名称不能绕过去重；同时改进语义场景识别、相似画面审核和局部修复。
- 改进功能效果图与商业 CG 的商品体积、材质、照明和接触阴影指令；已知中文图型名称正确映射到现有审核类型。
- 修复缺少结构化事实时模板套图的逐图参考分配，让尺寸、参数及功能图携带对应来源；卡片下方显示实际使用的参考图缩略图，支持换行并保持队列快照隔离。逐图补图与重生成按钮移除，整套补齐及记录操作保留。
- 输出语言选项采用中文名称；符合新命名规则的套图标题显示对应输出语言，新保存的记录及资产名称保持一致。历史资产迁移脚本默认仅预览，需要显式指定 `--apply` 才会写入。
- 新建套图数量统一为 6–20 张，快捷试水改为 6 张；参考图重构仍支持零张，内部历史数量兼容保留。
- 更新中英文 README、当前版本与下载链接，并补充 Linux 依赖安装、SSH 隧道、systemd、HTTPS 代理、数据路径和更新流程。

## 升级说明

- 升级前结束正在运行的生成任务并备份配置与图片记录。安装包与便携版继续使用现有桌面数据位置。
- 重启应用或服务后重新预览方案，才能使用新的规划、参考分配与渲染指令；历史冻结方案、用户锁定提示词和已有成图不会自动改写。
- 每套独立营销方案分别调用文字模型，批量文字请求次数随套数增加；图片总数仍以用户选择为准。Agent 随机牌池在服务进程内维护，重启后重置，不承诺跨历史任务永久不重复。
- 套图语言标记从北京时间 2026-11-17 起的记录应用，旧日期记录保留原命名；升级不会自动运行历史资产迁移脚本。
- 商品图采集扩展采用独立版本线，本次没有修改扩展版本。
