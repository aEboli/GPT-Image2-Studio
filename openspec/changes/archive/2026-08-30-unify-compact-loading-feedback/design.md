## Context

`.generation-loading-shell` 已承担图片生成中的大面积动态背景，本变更不修改它。当前主工作台中真正可见的紧凑辅助动效只有通用按钮、套图参考识别、Prompt Agent 图片分析预览及其三条分析轨道，以及胶片条临时占位；其中多数已经有稳定的 DOM、按钮禁用和 `aria-busy` 语义。

## Goals / Non-Goals

**Goals:**

- 让实际可见的紧凑异步反馈与生成加载壳采用一致的柔和模糊光带语言，同时保持 `.generation-loading-shell` 本身不变。
- 保持小控件紧凑，不把按钮、状态点或缩略图改造成大面积加载卡。
- 保留现有交互、文字、焦点、禁用和减少动态效果行为。

**Non-Goals:**

- 不替换或修改 `.generation-loading-shell` 图片生成加载壳，也不改动请求、队列、上传或分析的状态机。
- 不为每个入口引入独立动画组件、第三方依赖或新增可见说明文本。
- 不为当前没有运行时动效的连接状态、写真遗留样式或纯文字 busy 状态凭空新增动画。

## Decisions

### 一个共享的辅助光晕关键帧

在样式层定义一个缓慢的模糊光带位移与透明度变化关键帧。按钮、分析预览和缩略图占位使用相同的色彩与运动原则，根据宿主尺寸只调整裁切、模糊半径和时长。

### 保持既有 DOM 和语义

按钮仍使用既有 `.is-loading`、`aria-busy` 和禁用状态；套图参考识别、Prompt Agent 图片分析预览及其三条分析轨道，以及胶片条临时占位继续复用已有标记节点。将其视觉从锐利扫光、跳动圆点或旋转边框改为背景光晕，避免不必要的模板与事件改动。

### 减少动态效果只停止运动

减少动态效果覆盖所有辅助光晕与内联忙碌节点的动画属性。状态色、边框、文案和可访问性语义继续显示，使静态界面仍能分辨正在处理。

## Risks / Trade-offs

- [模糊在小控件中显得浑浊] -> 使用受宿主裁切的伪元素、低透明度和较小模糊半径。
- [统一样式掩盖按钮文字] -> 装饰层置于文字下方，保留现有文字层级和对比度。
- [静态测试锁定旧动画名] -> 更新断言以验证统一关键帧、目标选择器和减少动态效果覆盖，而非保留旧的 spinner 或扫描线实现。
