# GPT-Image2-Studio v0.2.7

`v0.2.7` 将主应用版本从 `0.2.6` 更新到 `0.2.7`，聚焦提示词创作连续性、Prompt Kit 复用体验、图片检查稳定性和可追溯发布。

## 更新内容

- **版本可见性与发布一致性**：工作台左下角在桌面、平板和手机布局中显示当前 `v0.2.7`。主应用版本继续以根 `package.json` 为准，新增统一补丁递增命令，并把页面版本、两个安装包说明、双语 README 和当前发行文档纳入一致性检查。
- **提示词创作连续性**：胶片条保留首次进入页面时的最近 10 张历史基线，只在本页提示词任务成功后追加结果，最多显示 50 张，避免重新载入更早历史时突然回填大量图片。加载预览改为连续的液体流动效果，阶段差异只表达视觉节奏，不冒充真实生成百分比。
- **Prompt Kit 与长期历史复用**：打开 Prompt Kit 或刷新 Prompt Agent 历史时，可复用历史会补齐为稳定的自动模板。用户修改的模板不会被覆盖，主动删除的自动模板也不会在后续刷新时重建。桌面端面板靠近提示词参数列；悬浮和键盘焦点提示使用顶层浮层，不会被面板或对话框裁剪。
- **图片检查体验**：图片详情在横图、方图和竖图之间保持固定的桌面外框及独立滚动检查器；结构化提示词中的数组值按共同字段聚合，避免显示数字索引，同时保留原始提示词的复制与复用行为。

## 升级说明

- 主应用每次更新仅递增一个补丁版本，即 `+0.0.1`。
- 既有配置、生成记录和图片资产不需要迁移。
- 商品图采集扩展使用独立版本线，本次主应用更新不会修改扩展版本。
- Windows 用户可选择独立桌面版或浏览器兼容安装包；两个安装包均未进行代码签名，首次运行可能出现来源或 SmartScreen 提示。
