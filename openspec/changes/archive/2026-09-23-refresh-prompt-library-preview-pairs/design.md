# 设计

## 数据绑定

`lib/youmind-profile-entries.mjs` 是 YouMind 人像资源的唯一配对清单。每条记录同时保存本地图片路径、展示名称、完整提示词、原始 CMS 地址和详情页；模板构建器直接消费该记录，不再通过循环索引把独立图片数组套到模板上。重复附件保留为独立记录，并通过名称和来源页区分。

## 预览策略

人像与头像模板返回对应的本地 JPEG。其他分类没有用户指定的外部图片，因此使用按模板键确定的内联 SVG；SVG 的分类、色彩和构图变体与模板元数据一致，并且不会复用人像照片。

## 布局策略

模板库只提供列表和图片视图。列表视图保留稳定的缩略图区域，并使用 `contain` 防止裁切；图片视图取消固定正方形卡片，图片使用 `width: 100%`、`height: auto` 和 `object-fit: contain`，网格项目从顶部对齐，以保留每个素材的固有宽高比。

## 验证

- 浏览器契约测试拒绝 masonry/waterfall 标记，并检查图片视图的自动比例和 `contain`。
