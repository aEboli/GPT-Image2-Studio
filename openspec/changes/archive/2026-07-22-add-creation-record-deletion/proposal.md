## Why

套图记录页当前只能搜索、查看、复用、补图和导出，生成错误、重复或已经不再需要的整套记录无法从该页面清理。记录数量增加后，用户也缺少一次选择多套或按当前搜索结果批量清理的能力。

## What Changes

- 为套图记录页增加删除当前套图、勾选多套后批量删除、按当前非空搜索筛选结果删除三种入口。
- 每条记录增加独立复选框；记录详情选择继续保持单选，不因批量勾选而改变。
- 三种删除都使用应用内模态确认对话框，显示目标套数，并明确生成图片与相关记录会被永久删除。
- 本地删除接口按明确的 `setIds` 集合删除 manifest、该套 `relativeDir` 对应的生成图片目录和 JSON 元数据目录。
- 按筛选删除仅在搜索词非空且存在匹配记录时可用；目标集合使用完整筛选结果，不受左侧最多显示 60 条的渲染上限影响。
- 删除完成后清理批量勾选、失效的记录选择与同 ID 当前结果，并重新读取服务端记录。

## Capabilities

### New Capabilities

- 无。

### Modified Capabilities

- `creation-mode`: 套图记录支持单套、勾选批量和按非空筛选结果永久删除。

## Impact

- 存储：`lib/creation-store.mjs` 增加按 ID 删除 manifest 及其专属输出目录的安全操作。
- API：Local 与 Cloudflare 增加 `POST /api/creation/sets/delete`；Cloudflare 保持无服务端记录语义并返回幂等成功。
- 浏览器：套图记录状态、列表多选、危险操作确认、删除请求与刷新逻辑。
- UI：套图记录工具栏、列表复选框、确认对话框和响应式样式。
- 测试：存储路径安全、API 契约、Local/Worker 路由与三种记录页删除目标边界。
