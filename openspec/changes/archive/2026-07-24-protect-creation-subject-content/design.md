## Context

普通 Creation 项的规划 prompt 目前要求所有可见营销文字使用目标语言，并要求把来源字段中的外语改写为目标语言；生成运行时还会追加一条目标语言指令。这些指令没有明确排除商品或包装主体表面的既有内容，因此即使 SKU prompt 已部分保护 Logo 和 printed label，后续更宽泛的语言指令仍可能让模型翻译或重绘主体。`infographic-rebuild` 则有独立的 source-only 契约，其目标就是在保留事实的前提下翻译整张来源信息图，不应被本次修复改变。

## Goals / Non-Goals

**Goals:**

- 为普通 carousel 与 SKU 项建立一条统一、明确且可复用的主体内容保护指令。
- 将目标语言严格限定为主体外新增的画布级营销文字。
- 让新计划、提交的冻结计划、历史记录重试以及 Local、Worker、repair 路径获得相同保护。
- 用回归测试证明信息图重建继续采用原有翻译契约。

**Non-Goals:**

- 不做像素级遮罩或 OCR 后处理，也不承诺生成模型能逐字复制任意复杂小字。
- 不改变信息图重建、参考图筛选、商品分析、界面参数、API 或持久化结构。
- 不保留参考图中位于商品主体之外的角标、水印、价格标签或促销贴纸。

## Decisions

1. **在共享生成参数模块定义主体内容保护指令。**
   - 规划器与运行时共用同一段契约，避免 carousel、SKU、Local、Worker 和 repair 之间产生措辞漂移。
   - 未采用在每个角色 prompt 中分别维护文案，因为这会扩大修改面并容易漏掉历史冻结计划。

2. **规划时写入，运行时兜底追加且避免重复。**
   - 新计划和预览直接展示保护指令；统一运行时 builder 为旧计划、用户保存的计划或自定义 prompt 补齐保护。
   - 未仅修改规划器，因为已冻结 prompt 和修复路径可能绕过重新规划。

3. **按“是否属于物理主体表面”划分语言作用域。**
   - 主体表面的图案、插画、符号、Logo、品牌标记、印刷/雕刻/刺绣文字及其字符、拼写、书写系统和语言视为商品身份，必须保持原样。
   - 主体外新添加的标题、营销短句、标注、说明和排版使用目标语言；主体之外的来源卡片噪声不因此获得保留资格。

4. **`infographic-rebuild` 在运行时分支前保持独立。**
   - 该角色继续直接返回专用重建 prompt，不附加普通主体锁，从而保留“完整翻译可翻译来源文字”的现有规格。

## Risks / Trade-offs

- [模型仍可能生成错误的小字] -> 使用强约束减少主动翻译和重绘，但不把概率型模型输出表述为像素级保证；实际成图仍需视觉验收。
- [保护主体文字与新增营销文字发生冲突] -> 明确物理主体边界，并声明主体原语言是目标语言规则的强制例外。
- [历史 prompt 已含冲突语句] -> 在统一运行时末端补充更具体的作用域与保护规则，使最终指令优先消除歧义。
- [共享指令重复增加 prompt 长度] -> 运行时检测规划 prompt 已包含的完整保护指令，存在时不重复追加。

## Migration Plan

1. 添加 OpenSpec 增量规格与失败回归测试。
2. 增加共享主体保护 prompt，并接入 carousel、SKU 和普通逐项运行时 prompt。
3. 执行聚焦测试、串行全量测试、Pages 构建与 OpenSpec 严格验证。
4. 归档变更并将增量规格合并回 `creation-mode` 主规格。

回滚只需移除共享指令及其两个调用点；不涉及数据迁移。
