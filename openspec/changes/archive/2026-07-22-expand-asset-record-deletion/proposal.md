## Why

套图记录已经支持删除当前记录和勾选批量删除，但同一资产工作区内的瀑布画廊、文章插图、写真和 PPT 记录仍只能逐页查看或通过零散入口删除。用户需要在所有资产页使用一致的当前项与显式多选清理方式，同时保持每类资产原有的存储边界和安全约束。

## What Changes

- 为瀑布画廊、文章插图、写真记录和 PPT 记录增加“删除当前”和“删除选中”命令。
- 为每个页面增加独立的批量勾选状态；勾选不改变当前详情或预览选择。
- 复用应用内永久删除确认交互，确认内容显示资产类型、目标名称或数量以及实际删除范围。
- 删除成功后在当前页面原位移除目标、保留搜索和滚动上下文，并在当前项被删除时选择相邻记录。
- 画廊删除单张图片与对应 JSON/浏览器缓存；文章和写真删除整组 manifest、专属图片目录与 JSON sidecar 目录；PPT 删除整套生成目录和 manifest，或安全删除只有 PPTX 文件的旧式记录。
- 套图记录现有“删除当前 / 删除选中 / 删除筛选结果”行为保持不变；其他页面不新增“删除筛选结果”。

## Capabilities

### New Capabilities

- `asset-record-deletion`: 定义五类资产页面一致的当前项删除、显式多选删除、应用内确认、原位状态更新和各类型存储安全边界。

### Modified Capabilities

- 无。

## Impact

- 存储：扩展 gallery、article illustration、portrait 和 PPT deck store 的批量删除能力与路径保护。
- API：扩展 `POST /api/output/delete` 的批量输入，并增加文章、写真和 PPT 记录批量删除路由；同步 Local、Cloudflare 与能力矩阵契约。
- 浏览器：新增各资产页当前项、勾选集合、删除请求与相邻选择状态。
- UI：四个资产页新增删除命令、列表或图片复选框，并共享一个应用内确认对话框。
- 测试与文档：增加存储、路由、浏览器静态契约和响应式布局回归，更新 README 资产页说明。
