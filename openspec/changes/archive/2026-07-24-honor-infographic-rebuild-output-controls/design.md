## Context

当前 `buildCreationItemGenerationPrompt()` 对 `infographic-rebuild` 返回固定提示词。固定提示词将目标语言列为应忽略的套图上下文，并要求原文原语言逐字保留；与此同时，生成循环已经把比例、有效尺寸和输出格式传给图像 API。因此问题集中在运行时提示词契约，而不在单图筛选或技术参数请求链。

## Goals / Non-Goals

**Goals:**

- 目标语言、输出格式、分辨率和比例在每次信息图重构生成及修复时都使用当前项的解析值。
- 目标语言只改变文字语言，不改变源图事实。
- 保持对应原图一张为唯一内容和视觉来源。

**Non-Goals:**

- 不改变套图规划、参考图筛选、Logo、平台或营销上下文。
- 不增加新的界面参数或数据字段。
- 不改变现有视觉重构强度。

## Decisions

1. **保留静态基础提示词，在运行时追加四项输出控制。**
   - 规划项仍保存稳定的 source-only 基础提示词；生成和修复根据解析后的参数生成最终提示词，避免历史记录中的旧提示词覆盖当前契约。

2. **目标语言允许忠实翻译，不允许改写或摘要。**
   - 可翻译文字必须完整转为目标语言；品牌名、型号、数字、单位、参数、声明、步骤、清单和逻辑关系保持不变。

3. **格式、分辨率和比例同时保留结构化 API 参数。**
   - 提示词中的输出控制用于消除源图画布对模型的干扰；实际编码格式和画布尺寸仍由现有 API 字段保证。

4. **仅把四项输出控制列为 source-only 隔离的例外。**
   - 其他商品、平台、Logo、受众和视觉风格字段继续禁止进入提示词或图片输入。

## Risks / Trade-offs

- [翻译导致事实漂移] -> 明确要求逐项完整翻译，并锁定专名、数字、单位和参数。
- [源图比例压过所选画布] -> 同时在提示词和结构化请求中声明解析后的比例及有效尺寸。
- [格式提示词本身不能控制编码] -> 继续以 API 的 `output_format` 为真实执行参数，测试直接检查请求体。

## Migration Plan

1. 更新规格和聚焦测试。
2. 修改运行时提示词参数传递。
3. 验证 Local、Worker、repair、全量测试与构建。
4. 重启并验证端口 `3600`。
