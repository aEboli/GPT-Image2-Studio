# GPT-Image2-Studio v0.2.021

`v0.2.021` 将主应用版本从 `0.2.020` 更新到 `0.2.021`，修复 Prompt Kit 人像模板翻页时反复显示少数图片的问题。

## 主要更新

### YouMind 人像预览

- 从用户指定的 YouMind 分类页及其提示词详情页补充并随应用打包 26 个不同的 JPEG 预览资源。
- 40 条人像与头像模板按顺序一次性消耗本地资源，不再使用取模循环，因此翻页不会回到同一批图片。
- 26 个真实资源用尽后，剩余 14 条模板使用基于模板键生成的独立离线 SVG 预览；每条模板的预览仍然稳定且唯一，不依赖运行时网络。
- 保留模板库的列表视图和图片视图，模板库不恢复瀑布流；来源页面、原始资源 URL 和本地文件清单见 [YouMind 资源归属说明](../../public/assets/prompt-templates/youmind-profile-avatar/ATTRIBUTION.md)。

### 版本与文档

- README、中文 README、Windows 文档、工作台版本标识和 `package-lock.json` 已统一到 `v0.2.021`。
- 既有配置、生成记录和图片资产不需要迁移。
- 商品图采集扩展使用独立版本线，本次主应用更新不会修改扩展版本。
