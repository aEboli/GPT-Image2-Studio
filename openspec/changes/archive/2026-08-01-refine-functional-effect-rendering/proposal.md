## Why

“功能效果渲染图”当前仍会在多处提示词和平台策略中被描述为对比图，导致生成结果出现左右分栏、干湿对照或前后对比，而不是直接展示商品主体的完整功能与渲染效果。

## What Changes

- 保持稳定角色 ID `effect-comparison` 和中文展示名“功能效果渲染图”，将其生成语义改为单一主体的完整功能可视化。
- 让通用、促销、平台搜索和平台原生规划都要求一个占主导、完整可见的产品主体，并围绕它展示已提供的功能、机制、效果路径或结果。
- 明确禁止前后对比、左右并列、分屏、成对状态、重复主体和多面板对比构图。
- 将平台图片类型的展示标签和构图策略与上述语义保持一致，同时保留已有内部图片类型 ID 以兼容历史计划。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `creation-mode`: 修改功能效果渲染图的规划与生成行为，禁止对比版式并要求单一主体功能可视化。

## Impact

- `lib/creation-planner.mjs` 中的角色、场景、买家决策和套图分工提示词。
- `lib/creation-platform-policies.mjs` 中的功能效果图片类型策略，以及对应的 `public/lib` 镜像。
- Creation Mode 预览说明、规划器和平台策略回归测试。
