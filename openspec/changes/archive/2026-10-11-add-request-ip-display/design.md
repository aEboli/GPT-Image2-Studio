# 设计

## 数据来源

服务端按 `CF-Connecting-IP`、`X-Real-IP`、`X-Forwarded-For` 的第一个地址、连接 `remoteAddress` 的顺序解析请求发起 IP，并将 IPv4 映射地址 `::ffff:x.x.x.x` 归一化为 IPv4。该字段只用于显示和生成记录追溯，不参与认证。

## 持久化边界

标准 `/api/generate` 请求把解析出的 IP 同时写入任务快照、生成结果对象和 Gallery 元数据。Gallery 的元数据归一化与索引恢复沿用现有字符串字段机制。配置接口返回当前请求 IP，浏览器状态保留该字段用于当前参数摘要；浏览器私有 API 配置不保存 IP。

## 显示行为

`buildParameterEntries()` 在参数列表最后追加“请求发起IP”。没有记录的历史数据显示“未记录”。左侧当前参数摘要在配置加载后显示当前 `/api/config` 请求的 IP。

## 风险

- 旧图片不会有历史 IP，只能显示“未记录”。
- 经过反向代理时显示代理提供的客户端地址；若代理未提供标准转发头，则回退到 Node 连接地址。
