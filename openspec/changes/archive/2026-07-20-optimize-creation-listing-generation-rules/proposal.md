# 优化 Creation Listing 生成规则

## Why

当前平台 Listing 请求虽然已经携带平台策略，但 V1 提示词仍使用 Amazon 风格的固定五点模板，并把所有功能、效果和收益表达视为违规。结果是模型输出偏向属性罗列，无法表达有证据支持的购买价值；即使模型输出了更好的文案，V1 结果门禁也会将其回退为保守模板。

## What Changes

本变更把用户提供的 evidence-bounded Listing 提示词接入平台 V1 路径：让标题、卖点、痛点、五点、描述和搜索词按平台 archetype 适配，同时允许可追溯事实支持的保守收益表达，并继续阻止品牌、平台名、认证、排名、价格、保证和其他高风险声明。

## Impact

本变更不改变旧式双语 JSON 字段合同、SKU 父 Listing 语义、无品牌净化、平台策略解析顺序或 Local/Worker 共享入口。
