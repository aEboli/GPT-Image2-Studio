## Why

Creation Mode 的参考图智能识别已经改为自动应用，但当前实现仍会把识别后的用途控件锁成只读，且应用过程中的中间重绘会让用户难以确认第一次识别是否已经生效。生成结果卡还会把很长的参考覆盖提示直接铺在图片下方，影响套图浏览。与此同时，合法的 33 张套图在冻结计划包含较长事实提示词时会被固定的 750 KB 快照字节上限拒绝。

## What Changes

- 识别请求成功后在一次状态事务中写入参考图用途、说明、商品名、类目和规划证据，并明确反馈“已自动应用”。
- 自动应用后的参考图用途保持可编辑；用户手动修改组别后立即以当前选择参与后续计划，不要求再次识别。
- 提高冻结计划的有界序列化上限，使 33 张合法套图可提交，同时保留计划项数量和格式校验。
- 结果区卡片不再在图片下方渲染完整参考覆盖/提示文本，详细信息继续通过记录与大图详情访问。

## Capabilities

### New Capabilities

- `creation-reference-apply-and-plan-size`: 定义参考图识别应用、用途编辑、冻结计划大小和结果卡信息密度行为。

### Modified Capabilities

无。

## Impact

- `public/app.js` 的参考图识别事务、参考图卡片和结果卡渲染。
- `lib/creation-planner.mjs` 的冻结计划快照边界。
- Creation 浏览器、规划器、端点和 OpenSpec 回归测试。
