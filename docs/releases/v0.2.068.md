# GPT-Image2-Studio v0.2.068

`v0.2.068` 将主应用版本从 `0.2.067` 更新到 `0.2.068`。

## 更新内容

- 图片反推优先提取原图最具辨识度的媒介、审美、配色、用光与材质词，减少复用提示词后的风格漂移。
- 加入 `4K/8K` 级视觉质量目标，明确要求清晰主体、可辨纹理、自然边缘和整洁层次；该提示词不承诺实际输出像素。
- `avoid` 按原图证据约束意外虚焦、纹理涂抹、伪影和额外杂物，同时保留有意的散景、柔焦、颗粒与运动效果。
- 更新图片转提示词入口说明及中英文 README。

## 版本规则

- 普通更新：更新位 +1。
- 版本格式为 `major.minor.patch`，patch 固定三位数字；上级版本变化时，下级版本归零。

## 升级说明

- 既有配置、生成记录和图片资产不需要迁移。
- 商品图采集扩展使用独立版本线，本次主应用更新不会修改扩展版本。
