## Why

资产库中的文章插图、写真和 PPT 记录目前只能浏览或搜索，无法按生成时间快速缩小范围；同时用户容易因为删除按钮的启用条件而误以为这些页面没有删除能力。需要让三类记录具备与套图一致的时间筛选，并保持现有显式删除边界清晰可验证。

## What Changes

- 为文章插图、写真和 PPT 记录增加“全部、今天、近 7 天、更早”和精确日期筛选。
- 文章插图和写真将关键词与时间按 AND 关系组合；PPT 直接按时间筛选。
- 让计数、空状态、当前详情、可见列表和删除后的相邻选择使用同一完整筛选结果。
- 保留三类页面现有的“删除当前”和“删除选中”，不增加“删除筛选结果”或隐式全删能力。
- 复用 Local API 已返回的 `createdAt`，不修改 manifest、删除 API 或持久化结构。

## Capabilities

### New Capabilities

- `asset-record-time-filtering`: 定义文章插图、写真和 PPT 记录的本地自然日筛选、组合条件、清空与视图联动行为。

### Modified Capabilities

- `asset-record-deletion`: 将 PPT 纳入非 Creation 资产页的筛选删除边界，明确筛选不会扩大显式删除目标。

## Impact

影响浏览器资产工作区、共享日期筛选 helper/controller、静态页面控件、响应式样式和相关单元/布局测试。服务端列表与删除路由、Cloudflare 能力矩阵、记录文件格式和输出目录均不变。
