## 方案

### 1. 输入清空

在提示词模式参考图标题和提示词标题中使用同一套轻量标题操作样式。两个清空按钮使用线性垃圾箱图标，提示词模板入口使用 `⭐`，桌面端标题行图标外框统一为 `24×24px`、`7px` 圆角以与左侧文字等高，触控布局保持 44px 点击区域；悬浮、按下与键盘焦点反馈复用当前控件的中性强调色。参考图按钮调用现有 `resetReferenceFiles()`，提示词按钮只清空 `promptInput` 并刷新计数、生成按钮和当前焦点，不触碰增强模式文本或参考图。

### 2. 结果回收与拖拽

预览工具栏按钮调用 `resolveDownloadImageBlob()` 读取当前预览的同源、缓存或已渲染图片，并包装成 `File` 后交给 `applyReferenceFiles()`。这样去重、15 张限制、对象 URL 生命周期和上传前压缩仍由现有路径负责。

预览图片设置为可拖拽，在 `dragstart` 写入仅供当前页面使用的预览键。参考图上传区和缩略图网格监听 `dragover`/`drop`，drop 时解析预览键并调用同一回收函数；没有当前图片、图片读取失败、重复或超限时显示已有错误提示。按钮使用 `aria-label`、`title` 和 `data-tooltip`，图片提供拖拽提示文本；键盘用户仍可使用按钮完成相同操作。

### 3. 图片详情布局

保留“提示词”和“参数”两个 tab。参数面板改为“生成参数文本 + 文件定位信息”垂直布局，文件名和相对路径使用现有字段 ID 更新，删除独立文件 tab 和文件 panel。CSS 为参数内容预留可滚动区域，避免文件信息被 `height: 100%` 的 textarea 挤出视口。

### 4. 参考图预览上下文

只降低参考图专用 viewer 遮罩的不透明度与模糊强度，不改变提示词分析 viewer 或图片详情 lightbox 的全局遮罩，确保参考图本身清晰，同时能辨认后方参数面板。遮罩调整以桌面和移动视口均能辨认参数标题、字段和值为验收条件；如果背景对比不足，优先降低遮罩不透明度，再降低模糊，不牺牲参考图本身的对比度。

### 5. 交互与状态验收

清空按钮只绑定各自的输入状态，并在清空后同步计数、生成按钮禁用态和焦点。结果图按钮与拖拽入口共享一个“当前预览转 File 并追加参考图”的动作；拖拽只接受页面写入的预览键，不把浏览器默认的 URL/文本当作本地文件。按钮、拖拽目标和失败状态均提供可见文本及辅助技术可读名称。

### 6. 操作说明排版

清空按钮的说明放在按钮下方，避免顶部设置区向上弹出时被滚动容器裁剪；当前结果按钮的长说明放在按钮上方并设置稳定宽度。两类说明均限制在视口内，允许中文自然换行；移动端参考图折叠面板仅在说明获得焦点或悬浮时放开溢出，其他状态继续保留圆角裁剪。

### 7. 胶片条页面会话窗口

提示词模式胶片条使用仅存在于当前页面内存中的展示数量：初始化为 10；用户在当前页面通过提示词模式提交一个有效生成任务后提升为 50。胶片条先独立截取对应数量的提示词历史图片，再与最多 6 个运行中占位合并，避免任务占位减少历史图片的可见数量。该数量不写入 `localStorage`、服务端任务或画廊元数据，因此刷新和下一次载入自然恢复为 10。

## 取舍

- 不把生成结果直接写入服务端；当前参考图仍是浏览器会话状态，符合现有提示词模式行为。
- 不复用 Creation 参考图拖拽排序模块，避免生成结果误触发 Creation 角色重排。
- 不保留隐藏的“文件” tab，避免同一信息出现两个来源；已有打开详情的默认参数 tab 保持不变。
- 不要求参数页为文件信息新增独立数据源，继续使用当前图片同步流程写入现有文件名和相对路径字段。
- 不记录胶片条扩展状态；它只表达当前页面已经继续生成的工作上下文，不成为跨载入偏好设置。
