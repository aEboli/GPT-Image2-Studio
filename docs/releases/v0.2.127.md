# GPT-Image2-Studio v0.2.127

`v0.2.127` 将主应用版本从 `0.2.117` 更新到 `0.2.127`。

## 更新内容

- 接入 gpt-image-2.6-sunburst / gpt-image-2.6-flare，覆盖路由 A/B 的 Images API 与 Responses；保留原有默认模型。
- 增加独立图像规划复杂度、auto/xhigh/max 质量、背景、JPG/WebP 压缩、中间预览和尺寸覆盖；Responses 文本模型与图像工具模型分别配置。
- 接通 WebP、GIF、SVG 的字节校验、原件保存、MIME、缩略图、历史、预览和下载；GIF 可暂停/播放，SVG 单独记录作者用量。
- 图片编辑新增标注引导，发送同尺寸透明 PNG markup，并校验与 mask 互斥。
- 普通 Images 生图支持 1–10 个候选结果并完整保存；2.6 普通参考图入口支持 16 张，其他业务输入配额不变。
- 配置、队列、历史快照、补图和参数检查器保存高级选项。CLI 提供对应参数。写真补图、文章重生成不会继承当前界面中不同的高级设置。

## 使用方法与边界

1. 在配置中选择完整的 2.6 模型 ID；使用路由 A 高级能力时开启“发送 tools[].model”。路由 B 可选择 Images API 或 Responses。
2. 展开共享高级设置；留空保持上游默认，按格式填写需要的字段。complexity、quality、外层 reasoning、SVG 作者 reasoning 独立控制。
3. 在提示词生图选择 GIF/SVG；编辑、套图、写真、文章和 PPT 等静态槽位使用 PNG/JPG/WebP。Images GIF/SVG 使用 JSON；Responses GIF 可保留任务状态流，均不请求中间图。
4. GIF 默认 9 帧、200 ms。指南与接口/SDK 的最大帧数分别为 64/16，17–64 帧明确属于待上游验证范围。GIF preview 和 SVG 作者选择需账户权限；权限失败原样反馈，不改模型或格式重试。
5. 自定义尺寸只验证正整数格式，具体模型像素范围与账户/中继支持需由实际提供方验证，未沿用 2.5 的像素上限。

## 版本规则

- 小功能更新：更新位 +10。
- 版本格式为 `major.minor.patch`，patch 固定三位数字；上级版本变化时，下级版本归零。

## 升级说明

- 既有配置、生成记录和图片资产不需要迁移。
- 商品图采集扩展使用独立版本线，本次主应用更新不会修改扩展版本。

## 验证

- 定向测试覆盖真实 Studio 服务与模拟上游，验证多候选保存、两帧 GIF 原字节、SVG 用量/原件、缩略图、16/17 参考图边界、标注上传和历史高级参数恢复。
- 隔离浏览器验证了模型/格式控件、配置保存、GIF 播放/暂停、SVG 预览、标注编辑、重载恢复和 390 像素窄屏。
- 隔离 Electron 已启动并完成页面截图，且原生 Resvg 模块在 Electron 中实际生成 PNG。此项不等于已打包安装器验收。
- 当前开发配置未提供可用 API Key，未执行真实付费模型调用。因此两个模型的实际效果、权限、真实尺寸和 17–64 帧仍未验收；本次没有将模拟图片当作模型输出。
- 全量回归 3040/3040 通过，追加资产边界回归 10/10 通过，归档后 38/38 份规范通过严格校验；共享模块与发行一致性检查通过。完整记录见 [verification.md](../../openspec/changes/archive/2026-11-05-add-gpt-image-26-support/verification.md)。
