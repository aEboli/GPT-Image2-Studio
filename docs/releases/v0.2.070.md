# GPT-Image2-Studio v0.2.070

`v0.2.070` 将主应用版本从 `0.2.069` 更新到 `0.2.070`。

## 更新内容

- 优化提示词模板卡片摘要展示，让可用的提示词空间显示为最多三行的截断摘要。
- 修正请求出口 IP 的记录来源：Studio 通过上游 HTTP transport 查询公网出口 IP；查询失败时显示“未记录”。查询不会发送 API 凭据、提示词或生成图片。

## 版本规则

- 普通更新：更新位 +1。
- 版本格式为 `major.minor.patch`，patch 固定三位数字；上级版本变化时，下级版本归零。

## 升级说明

- 既有配置、生成记录和图片资产不需要迁移。
- 商品图采集扩展使用独立版本线，本次主应用更新不会修改扩展版本。
