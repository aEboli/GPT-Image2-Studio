## Context

当前和历史 Creation 结果均由 `createCreationCard()` 创建，带有稳定的 `data-creation-card-key`，并共享 `.creation-card` 悬停高亮。写真卡片也复用了 `.creation-card` 类名，因此空闲涟漪不能仅按类名选择目标。

## Goals / Non-Goals

**Goals:**

- 鼠标在 Creation 卡片上静止 30 秒后播放一次克制的向外涟漪。
- 持续静止时按 30 秒间隔重复，移动时立即停止并重新计时。
- 保持现有橙色边框、网格尺寸和卡片交互不变。
- 让计时行为可通过假时钟快速、确定地验证。

**Non-Goals:**

- 不让写真卡片或其他工作台卡片参与涟漪。
- 不改变键盘焦点已有的橙色高亮行为。
- 不增加可配置项、后端状态或持久化数据。

## Decisions

1. **使用单个文档级空闲计时控制器。**
   - 控制器监听被动 `pointermove`，每次移动都移除当前涟漪并重新安排一个 `30000ms` 定时器。
   - 定时器触发后再次安排下一次 `30000ms` 定时器，从而在持续空闲时周期重复。

2. **只选择当前悬停的 Creation 卡片。**
   - 使用 `[data-creation-card-key]:hover` 定位目标，避免误作用到复用 `.creation-card` 的写真卡片。

3. **使用一次性 CSS 类和伪元素绘制涟漪。**
   - 控制器短暂添加 `.is-idle-rippling`，CSS 伪元素从原边框向外扩散并在 `1200ms` 内淡出。
   - 伪元素绝对定位且不接收指针事件，不改变盒模型和布局。

4. **尊重减少动态效果偏好。**
   - `prefers-reduced-motion: reduce` 下隐藏涟漪伪元素，保留原有静态橙色悬停反馈。

## Risks / Trade-offs

- [高频移动反复创建定时器] -> 只维护一个空闲定时器和一个动效清理定时器，每次重置前先清理旧实例。
- [卡片重渲染后旧节点残留类名] -> 移动和销毁时保存并清理当前节点；后续触发始终重新查询当前悬停节点。
- [涟漪覆盖相邻卡片] -> 使用短时、低透明度边框，并复用悬停卡片已有的层叠顺序。

## Verification

1. 假时钟测试覆盖首次 30 秒触发、持续空闲重复和指针移动重置。
2. 样式契约测试覆盖伪元素、`1200ms` 动画、无布局属性和减少动态效果。
3. 运行聚焦测试、串行全量测试、Pages 构建及 OpenSpec 严格验证。
4. 在本地浏览器中检查涟漪可见、卡片边界尺寸不变且不被结果网格裁切。
