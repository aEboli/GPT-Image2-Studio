# GPT-Image2-Studio v0.2.128

`v0.2.128` 将主应用版本从 `0.2.127` 更新到 `0.2.128`。

## 更新内容

- 路由 A 的“发送 tools[].model”默认开启，新配置及缺少字段的旧配置直接发送所选模型。
- 明确保存为关闭的配置保持关闭，省略开关的局部保存不会将其重置；队列快照和其他路线保持原有语义。
- 同步请求默认值、HTML 初始状态和 public/lib 镜像。

## 版本规则

- 普通更新：更新位 +1。
- 版本格式为 `major.minor.patch`，patch 固定三位数字；上级版本变化时，下级版本归零。

## 升级说明

- 既有配置、生成记录和图片资产不需要迁移。
- 商品图采集扩展使用独立版本线，本次主应用更新不会修改扩展版本。

## 验证

- 268 项相关测试全部通过，覆盖默认、关闭、重开、持久化和实际请求构造。
- 137 个共享模块一致性与发行一致性检查通过；OpenSpec 严格校验并归档。
- 本次没有重新运行全量测试、正式安装器构建或真实模型调用。
