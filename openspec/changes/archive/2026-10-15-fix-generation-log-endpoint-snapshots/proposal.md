# 修复生成日志接口地址快照与地址显示

## Why

任务轮询快照未携带生图接口地址，前端解析日志时会回退到当前连接配置，并覆盖旧日志保存的地址。配置抽屉又把直连生图与文本接口压进半宽字段，造成地址和协议后缀难以阅读。

## What Changes

- 恢复已有日志要求：地址只取任务自己的快照或结果；缺少地址时沿用日志中已有值，禁止借用当前配置。
- 服务端解析生图配置后立即把公开的 Base URL、路由和协议后缀记入任务，失败任务也保留地址，不带 API Key。
- 直连的两个地址字段各占整行，桌面抽屉适当加宽；日志 URL 独占一行，超长值可横向滚动并用键盘聚焦，少量日志按内容高度排列。
- 地址输入与后缀提供完整值提示，选择 API、切换完整 URL 或手动编辑后同步更新。

## Capabilities

### Modified Capabilities

- `runtime-configuration`: 任务公开快照保留实际接口地址，历史日志不受当前配置影响。
- `configuration-usability`: 地址字段保持完整宽度，日志地址拥有独立可检查的一行。

## Impact

修改前端日志地址解析、配置样式、完整值提示与服务端任务元数据；新增轮询回归测试并扩展已有服务端集成测试。已经丢失且无法从任务或结果找回的历史地址不推测还原。
