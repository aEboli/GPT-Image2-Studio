# GPT-Image2-Studio v0.2.071

`v0.2.071` 将主应用版本从 `0.2.070` 更新到 `0.2.071`。

## 更新内容

- 提示词模板库调整为嵌入图片预览区域，并按容器宽度自适应；列表卡片收紧布局，同时保留标题、分类和三行提示词摘要。
- 生成日志按任务自身快照保留接口地址，切换 API 后查看历史记录或失败任务时不会串用当前地址；长中转 URL 支持键盘聚焦和横向检查。
- 加宽并重新排布桌面端 API 配置抽屉，为较长接口地址补充完整值提示。

## 版本规则

- 普通更新：更新位 +1。
- 版本格式为 `major.minor.patch`，patch 固定三位数字；上级版本变化时，下级版本归零。

## 升级说明

- 既有配置、生成记录和图片资产不需要迁移。
- 商品图采集扩展使用独立版本线，本次主应用更新不会修改扩展版本。
