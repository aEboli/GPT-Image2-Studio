## Context

本次问题来自同一批未提交更新中的多个边界：本地服务把回环 socket 等同于可信浏览器来源，记录删除把完整集合与筛选集合混用，Listing 尺寸处理依赖宽泛文本和单数字锚点，颜色与类目自动推断使用无上下文子串，历史 Prompt 模板只按 ID 前缀识别，发布检查只搜索任意版本字符串。现有 `add-product-image-collector` 变更仍在进行并会触及 `server.mjs` 与 `public/app.js`，因此修复必须保持文件内现有新增逻辑并使用窄范围修改。

## Goals / Non-Goals

**Goals:**

- 为每个审查反例建立直接回归测试并修复根因。
- 保留正常回环工作台、已有记录、现有平台策略、采集器实现和公共模块同步方式。
- 让安全、事实来源和删除行为默认失败关闭。
- 让主规格、实现、测试和发布门禁重新一致。

**Non-Goals:**

- 不重构整个鉴权、类目评分或 Listing 生成架构。
- 不增加通用代理信任列表、自动证书管理或新的外部依赖。
- 不修改商品图采集器的清单、代理域名或浏览器扩展行为。
- 不重写历史记录；只修复读取兼容层的显示结果。

## Decisions

### 1. 可信回环由 socket 地址与 Host 共同决定

无令牌快捷路径只接受回环远端地址和语法合法的回环 `Host`。在解释 hostname 前先拒绝包含 userinfo、路径、查询或片段字符的畸形 authority，避免 URL 宽松解析把攻击者提供的文本重新解释为回环地址。非回环 `Host` 即使通过本机反向代理或 DNS Rebinding 到达回环 socket，也必须提供有效令牌。此类无令牌请求保持 403 且不由后端发起 Basic challenge，避免把 DNS Rebinding 请求变成认证提示；TLS 反向代理负责外部认证并向后端注入固定令牌。`explicitHost` 只描述监听地址，不授予任意请求 Host 信任。

直接绑定非回环地址仍可作为兼容能力，但因为 Node 服务本身只提供 HTTP，必须同时显式设置 `IMAGE_STUDIO_ALLOW_INSECURE_REMOTE_HTTP=1`；否则启动失败并提示使用绑定回环地址的 TLS 反向代理。服务在本地启动输出中提供当前 Basic 用户名和访问令牌；直接连接的远程浏览器可完成 Basic 认证，反向代理则必须同步该令牌或使用启动前显式配置的固定值。选择显式兼容开关而不是内置 TLS，是为了不引入证书生命周期和私钥加载面。

### 2. 删除选中的有效集合是 checkedIds 与完整筛选集合的交集

控制器继续保留完整记录和筛选外的勾选状态，但确认数量、按钮状态和实际目标都只使用当前完整筛选集合。这样清除筛选后选择仍可恢复，同时当前操作不会删除用户看不见的记录。

### 3. 尺寸以标签子句和完整标准化元组校验

证据提取先按句号、分号和换行切分，再要求尺寸与对应的产品或包装标签出现在同一非否定子句。尺寸解析识别 `N x N [x N] unit` 及单值长度，并把共用尾部单位传播到整个组；比较时统一为长度基准值并允许显示换算造成的有限舍入误差。输出中的每个长度元组都必须对应来源元组，不能用一个共享数字放行其余轴。

单位模式只统计长度单位。尺寸字段长度限制进入共享尺寸校验，因此旧 Platform V1 接受路径和当前策略路径使用同一上限。历史读取只派生显示字段，不回写存储。

### 4. 颜色识别失败关闭并逐个本地化

移除在多语言环境中存在普通词歧义的单字/短语 token，不再把 CJK token 作为任意子串命中；提取结果映射到规范颜色选项，而不是保留包含连接词的原始片段。多色标签按每个已识别颜色映射到英文或简体中文后再用单空格组合，保留 `off-white` 等受认可复合色内部连字符。

### 5. 类目自动匹配不使用无父级语义的通用末级后缀

商品名回退继续复用现有可靠评分和显式别名，不再仅凭“唯一末级名称 + 后缀”返回模板。精确类目名、完整路径和带足够上下文的现有匹配仍可用；`支架` 等宽泛叶子保持未匹配。

### 6. 旧 Prompt Agent JSON 使用结构特征识别

只有同时包含非空 `prompt` 和多个旧版分析字段的 `prompt-agent-*` 对象才提取单一提示词。新的五组结构和无关用户 JSON 保持原文。采用结构特征而不是新增迁移版本字段，因为历史本地数据没有版本标记。

### 7. 发布检查验证明确事实位置

README 必须有唯一、锚定的当前版本行；Windows 文档必须在安装包事实中包含当前版本；发布说明必须以当前版本标题开头。示例、标签命令或迁移文本中的游离字符串不能满足门禁。

## Risks / Trade-offs

- [现有直接局域网启动会失败] → 错误信息和文档给出 TLS 反代推荐路径与显式不安全兼容开关。
- [尺寸换算存在舍入差] → 标准化比较使用小范围相对/绝对容差，并用英中双单位反例覆盖。
- [移除歧义颜色 token 会减少召回] → 依照现有失败关闭规格，宁可不显示标签，也不从普通词猜色。
- [取消宽泛类目后缀会减少自动命中] → 保留精确名称、完整路径和显式别名匹配，低证据输入回落通用类目。
- [活动采集器变更并行修改相同大文件] → 只修改独立函数和测试，合并前复查最终差异及公共镜像同步。

## Migration Plan

1. 先合入规格和回归测试，再实现各模块修复。
2. 更新 `.env.example`、README 和 SECURITY，说明新的远程绑定默认值。
3. 保留旧模板和历史 Listing 的原始存储，只改变读取时归一化。
4. 完成全量验证后把增量规格合并回主规格并归档本变更。
