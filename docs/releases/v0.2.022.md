# GPT-Image2-Studio v0.2.022

`v0.2.022` 将主应用版本从 `0.2.021` 更新到 `0.2.022`。

## 更新内容

- 修复 Prompt Kit 图片与提示词错配，补齐 40 条 YouMind 配对预览，并按真实比例显示列表与图片视图
- 模板库图片视图取消固定正方形裁切，列表和图片视图均保留每张预览图的原始宽高比；更新资源缓存版本，避免旧样式残留

## 版本规则

- 普通更新：更新位 +1。
- 版本格式为 `major.minor.patch`，patch 固定三位数字；上级版本变化时，下级版本归零。

## 升级说明

- 既有配置、生成记录和图片资产不需要迁移。
- 商品图采集扩展使用独立版本线，本次主应用更新不会修改扩展版本。
