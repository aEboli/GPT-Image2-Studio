# GPT-Image2-Studio v0.2.17

`v0.2.17` 将主应用版本从 `0.2.16` 更新到 `0.2.17`。

## 更新内容

### 配置区与生成日志

- 生图工具模型和 Gemini 协议的长说明改为可见 `?` 提示标记，支持鼠标悬停和键盘聚焦，不再占用表单高度。
- 配置表单和生成日志拆成独立滚动区域；日志视口保持响应式固定高度，时间线列表单独滚动。
- 移动端、平板端覆盖旧的通用溢出规则，避免日志消失和配置区出现无意义的横向滚动。

### 传统色主题与花卉点缀

- 增加 7 套来自 `zhongguose-palette` 色库的配色：默认魏紫、青花甜白、江南竹影、雨过天青、故宫朱墙、漆器朱漆、敦煌石青。
- 通道选择栏调整为“路由模式 / 直接调用模式 / Gemini模型 / 配色”；配色入口紧跟 Gemini，点击后展开完整设置，默认不占用日志空间。
- 支持按钮与焦点、界面面层、花卉与装饰三类自定义颜色，输入经过六位 Hex 校验，清空后回退当前配色。
- 支持折枝梅、兰叶小丛、竹节竖列和牡丹团花 4 种装饰；装饰使用现有配色、不会拦截交互，并对辅助技术隐藏。
- 配色、花卉开关、样式和自定义颜色写入浏览器本地存储，首屏恢复并同步到嵌入的 Temu 工作台。

### 规范与回归

- 更新 OpenSpec 规范，补充配色入口位置和花卉装饰行为。
- 增加配色白名单、颜色校验、提示标记、日志独立滚动、Temu 主题消息和 Gemini 后配色入口测试。

## 升级说明

- 主应用每次更新仅递增一个补丁版本，即 `+0.0.1`。
- 既有配置、生成记录和图片资产不需要迁移。
- 商品图采集扩展使用独立版本线，本次主应用更新不会修改扩展版本。
