# GPT-Image2-Studio v0.2.4

`v0.2.4` 建立了从多平台商品图采集、原图归一化、批量复制与下载到 Studio 导入和 Creation 使用的完整链路，并集中完善 Creation、Listing、本地服务安全和项目发布维护。

## 版本亮点

- **商品图采集器 `v1.1.29`**：新增 Chrome/Edge 扩展，支持 1688、Amazon、Temu、TikTok Shop、SHEIN 和大健云仓。采集结果按主图、详情图和 SKU 图保留语义与顺序，规范化可信原图地址，并在共享图片或同名规格场景下保留可证明的独立 SKU。
- **批量复制、下载与 Studio 导入**：独立 Windows Native Messaging 助手可把所选原图写入系统剪贴板和同目录文件集合；Studio 支持从剪贴板识别清单或文件，预览后按全选、全不选、反选及分类选择导入，容量与失败状态会原地同步。
- **更完整的采集与预览体验**：商品页提供可自恢复悬浮入口、可拖动和折叠的采集窗、分组选择、单图查看与下载、批量操作和白天/蓝调/夜晚三主题。SKU 名称使用固定可读字号完整换行，Studio 与扩展缩略图使用 `contain` 并保留四边白色检查边界。
- **Creation 与 Prompt Agent 改进**：SKU 标签只保留可识别纯颜色并保留复合颜色连字符，生成规则文案更紧凑；批次导入卡片、队列状态、空闲反馈和 Prompt Agent 结果命名得到完善。
- **Listing 与资产记录加固**：尺寸和重量按来源证据分组处理，历史记录回读遵守字段来源边界；记录删除、时间筛选和筛选结果处理避免误作用于未选择数据。
- **本地安全与维护契约**：本地服务增加明确的认证、Host 和代理边界，修复恶意 Host 与 DNS 重绑定类绕过；新增 Windows CI、公共模块镜像检查、发布事实检查和 OpenSpec 严格验证。

## 修复与行为变化

- GigaB2B 图片区分轻量预览和规范化原图，查看、复制、下载与 Studio 导入不会把缩略图冒充为原图。
- 扩展入口在 SPA 路由变化、旧实例残留或消息无响应后可恢复，长批量操作期间仍可执行选择、查看和关闭。
- 商品图导入弹窗使用分层 Escape 行为：先关闭图片查看器，再关闭导入弹窗，不影响下层工作台状态。
- Creation 类目与颜色匹配收紧，避免宽泛词和中文子串导致误判；Prompt Agent 展示名称增加人物、动作、环境与物体信号。
- 发布一致性检查要求版本事实位于指定文档位置；严格模式还要求工作区干净且当前提交带有匹配标签。
