## Context

当前结果和历史结果都由 `createCreationCard()` 创建并共享 `.creation-card`。该类已经使用固定的 `1px` 边框，因此可以只改变边框颜色和外部阴影，在不改变盒模型的情况下提供指针反馈。

## Goals / Non-Goals

**Goals:**

- 为整张 Creation 卡片提供清晰、平滑的橙色悬停高亮。
- 保持当前网格尺寸、卡片间距和图片预览交互不变。
- 让卡片内部的键盘焦点获得等价反馈。

**Non-Goals:**

- 不改变卡片内容、排序、点击动作或图片预览样式。
- 不增加 JavaScript 状态或事件监听器。
- 不改变其他工作台卡片的交互。

## Decisions

1. **在共享 `.creation-card` 上实现 CSS 状态。**
   - 使用 `:hover` 覆盖鼠标交互，使用 `:focus-within` 覆盖卡片内部按钮的键盘焦点。

2. **固定边框宽度，仅过渡颜色和阴影。**
   - 静态状态继续保留现有 `1px` 边框；高亮状态只切换为橙色并增加外部光晕，避免布局跳动。

3. **使用短时 ease 过渡。**
   - 只过渡 `border-color` 和 `box-shadow`，不移动或缩放卡片。

## Risks / Trade-offs

- [橙色光晕遮盖相邻卡片] -> 使用透明且有限半径的阴影，并保留现有卡片间距。
- [窄网格中的高亮被裁切] -> 结果网格当前允许 `overflow: visible`，无需调整布局。

## Verification

1. 样式契约测试确认共享卡片包含过渡以及 `:hover`、`:focus-within` 橙色状态。
2. 运行聚焦布局测试和串行全量测试。
3. 运行 OpenSpec 严格验证并归档变更。
