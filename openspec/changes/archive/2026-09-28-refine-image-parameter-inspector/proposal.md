# 优化图片详情参数面板

## Why

图片详情参数当前以纯文本呈现，长值不易扫描；部分生成开关没有进入记录详情，而且文件相对路径会占用参数区域并暴露内部目录结构。

## What Changes

- 将参数按固定标签列和可换行数值列展示，支持长值换行。
- 展示透明背景、路由模式工具传输和直连模式流传输状态。
- 为 Creation 记录保存固定的不透明背景；历史记录缺失的开关显示“未记录”。
- 图片详情展示文件名，不再展示相对路径；已有的绝对本地文件参数保持可见，内部资产路径仍用于资源定位和安全删除。

## Affected Specifications

- `lightbox-image-viewer`
