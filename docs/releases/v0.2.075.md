# GPT-Image2-Studio v0.2.075

`v0.2.075` 将主应用版本从 `0.2.074` 更新到 `0.2.075`，修正套图参考图识别把成对商品拆成两个产品单位的问题。

## 更新内容

### 成对商品按可售单位计数

- 参考图分析与 SKU 主体归一化改为按可售单位计数：一双即 1 个完整产品单位，左右两只不再算 2 个单位。
- 新增共享判定模块 `lib/creation-paired-subject-units.mjs`：成对品类（手套、鞋、袜、拖鞋、耳环、耳机、护腕、护膝、滑雪杖等）与成对表述（一双、一对、成对、左右各一只、a pair of）同时命中才折算。
- 双数优先于件数：说明写明"两双"时按 2 计量，只有件数时按件数折半，"四只手套组成两双"仍为 2 个完整产品单位。
- 路亚、鱼饵等独立单卖的重复商品仍按件计数；原"成对即 2 个单位"的规则收窄为只约束这类商品，不再泛化到成对穿戴品。
- 一双只输出一条 SKU 颜色标签：左右同色合并为 `black`，左右异色合并为 `black grey`，SKU 项名称不再出现 `black black`。
- 参考主体说明在成对单件时改写为"图中共 1 个完整产品单位（一双，左右各一只合为一双）"，多双时标注"按双计数"。
- SKU 生成提示词为成对主体补充左右两只同图保留、不拆分、不重复的约束。
- 顺带修复参考主体说明清理单位计数时，对"图中一共 N 个完整产品单位"残留"图中一"的问题。

### 规范与同步

- 新增 OpenSpec 变更并归档为 `2026-10-24-count-matched-pairs-as-one-sellable-unit`，两条要求已合并进 `openspec/specs/creation-mode/spec.md`。
- `lib/creation-paired-subject-units.mjs` 已登记进 `scripts/sync-public-lib.mjs` 并同步到 `public/lib/`。

## 升级说明

- 主应用每次更新仅递增一个补丁版本，即 `+0.0.1`。
- 既有配置、生成记录和图片资产不需要迁移。历史参考图说明在命中成对证据时按新口径重算单位数，其余保持原样。
- 商品图采集扩展使用独立版本线，本次主应用更新不会修改扩展版本。
