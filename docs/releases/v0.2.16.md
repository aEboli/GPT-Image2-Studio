# GPT-Image2-Studio v0.2.16

`v0.2.16` 将主应用版本从 `0.2.15` 更新到 `0.2.16`。

## 更新内容

### 深色主题改为纯黑底

- 夜间页面底色按产品要求改为纯黑 `#000000`。`body` 不再铺那两层族色光晕与蓝黑渐变，整页就是 `var(--bg)`。
- 面层不直接用黑，否则控件与背景分不开。新增四个混色 token，各自只混入 6%–12% 的中国传统色：`--black-violet`（山梗紫 `#61649f`）、`--black-blue`（秋波蓝 `#8abcd1`）、`--black-green`（粉绿 `#83cbac`）、`--black-red`（朱红 `#ed5126`）。整体仍读作黑色，但面板、输入框、滚动条和预览台各有冷暖归属。
- 清掉沿途写死的蓝黑值。`#101f30`、`#142334` 以及 `rgba(16, 31, 48)`、`rgba(20, 35, 52)`、`rgba(28, 41, 56)`、`rgba(8, 16, 26)`、`rgba(4, 8, 16)` 五组 rgba 在样式表里已一处不剩——留一处就会让纯黑主题在局部重新偏蓝，`test/view-accent-family.test.mjs` 现在钉住这条。
- 浅色主题不动：银白 `#f1f0ed` 作场、汉白玉 `#f8f4ed` 作面，以及原有的分视图交互色都按 v0.2.15 保留。

### 主操作统一为魏紫

- 主按钮、选中导航和常规交互统一改为魏紫 `#7e1671`，悬停青莲 `#8b2671`，按下绀紫 `#461629`，按钮文字银白 `#f1f0ed`。深色的 `--accent-hover` / `--accent-active` 改为具名色而非从 `--accent` 派生，因为派生值在纯黑上压不住三态的文字对比。
- 深色五个视图族（生成、解析、修编、成套、存档）共用魏紫。切换功能不再把大面积冷暖色带进黑色主题；浅色仍按族切换 `--accent`。
- 山梗紫作为 `--ornament` 承担焦点环与细线，顶栏下沿那道原本的金线随之改色。黄色只保留给警告状态。
- 此前借 `--warning` 当交互色的几处（套图 Listing 开关、套图卡片悬停、参考图绑定框）改走 `--accent`，否则它们在新主题里会变成一片黄。
- `select` 的 `option` 弹窗由操作系统绘制，必须显式给底色与字色。此前写死浅色 `#fffef9` / `#2b333e`，现在改走 `var(--bg-soft)` 与 `var(--text)` 随主题切换。
- 样式资源版本更新为 `20260911-imperial-black-3`，静态部署和已打开的浏览器不会继续命中旧的深色 CSS。
- TEMU 上品工作台同源改造，`theme-color` 一并从 `#101f30` 改为 `#000000`。

### 提示词模板按钮改用图标

- 该按钮此前是一个 `⭐` emoji 字符，由操作系统按自己的字体彩色渲染，既不跟随 `currentColor`，在不同系统上也不是同一个字形。现改为 lucide sparkles 描边 SVG，与参数区其余图标同一套线宽（`14px`、`stroke-width: 1.8`），并用 `var(--accent)` 上色。

## 升级说明

- 主应用每次更新仅递增一个补丁版本，即 `+0.0.1`。
- 既有配置、生成记录和图片资产不需要迁移。本次只改配色与一个图标，请求体、生成参数和输出目录都不变。
- 浅色主题的取色与分视图交互色不变，仅深色主题重做。
- 商品图采集扩展使用独立版本线，本次主应用更新不会修改扩展版本，仍为 `1.1.33`。

### 仓库整理

- 删除仓库根目录两张未被任何文档或测试引用的截图 `portrait-no-image-name.png`、`prompt-template-popover.png`，以及只引用 `.gitignore` 之外产物的设计 QA 草稿 `design-qa.md`。
- 删除 `docs/superpowers/`：其中 14 份实现计划与设计稿均已由 `openspec/specs` 与 `openspec/changes/archive` 覆盖，且正文夹带对本仓库之外工具链的指令。历史内容仍可从 Git 历史取回。

## 验证

- 2312 项测试通过；`npm run check:release`、`npm run sync:public-lib -- --check`（120 个模块）与 `openspec validate --all --strict`（58/58）通过。
- Electron 探针在真实渲染里读 computed style 复核两个主题：夜色 `body` 背景为 `rgb(0, 0, 0)` 且不再有渐变，正文对底 18.43:1；主按钮填魏紫 `rgb(126, 22, 113)` 配银白文字 8.23:1；提示词模板按钮已是 `svg`，`stroke` 跟随 `currentColor`，尺寸 14px。
- 已知未达标项：魏紫作**前景色**压在近黑底上只有 2.24:1，涉及选中导航页签的文字与下划条，以及本次改成 SVG 的提示词模板图标。作为填充底色它是够的（银白压在它上面 8.23:1），但作为墨色低于正文 4.5:1 与图形部件 3:1 的下限。同一行的清空按钮走 `--muted`，实测 7.75:1。若要修，最小改法是让「魏紫只作填充」，选中页签文字与该图标改走 `--text` 或更浅的同色系伴色，而不改主操作的填充色。
