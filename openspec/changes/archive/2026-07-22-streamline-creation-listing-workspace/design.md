## Context

Listing 草稿当前位于 Creation 记录结果滚动区底部。每条草稿重复显示英文标题，并在七个带边框字段中逐条交错显示英文和中文参考；所有文本都表现为复制按钮，两个字符数徽标又持续占据每个字段标题。页面在单条父 Listing 下仍产生很长的滚动距离，商品文案与 SEO 信息没有任务分组，滚动后也无法继续操作生成、完整复制和导出。

现有旧版 Listing JSON、七字段顺序、字段级中英文独立复制、完整双语复制与结构化导出均已形成稳定契约。本次只允许修改浏览器展示与交互状态，不得改变生成、持久化、API 或历史草稿读取。

## Goals / Non-Goals

**Goals:**

- 让用户优先看到单语言发布文案，并能按需切换中文或双语对照。
- 将高频商品文案和低频搜索优化字段分开，减少一次可见内容和滚动距离。
- 让生成、完整复制和导出在 Listing 区域内持续可达。
- 用清晰的复制控件和低强调字符统计替代多层卡片与强提示徽标。
- 保持桌面、平板和移动端的可读布局与键盘语义。

**Non-Goals:**

- 不修改 Listing 提示词、标题规则、陈述句规则、字段内容或关键词策略。
- 不修改 JSON schema、API、存储、导出载荷或自动迁移历史记录。
- 不删除字段级、条目级或完整 Listing 的现有复制能力。
- 不重构 Creation 记录列表、图片网格或其他资产页面。

## Decisions

### 1. 使用会话内共享视图状态

语言模式使用 `en`、`zh`、`compare`，内容模式使用 `copy`、`search`，存放在现有 `state.creation` 中。渲染函数读取该状态并通过卡片 `data-*` 属性控制可见内容；容器事件委托更新状态后重渲染记录和当前 Creation 视图。这样切换在正常刷新渲染中不会丢失，也不引入持久化字段或浏览器存储迁移。

备选方案是在每个按钮上直接修改当前 DOM。该方案在生成状态或记录同步触发重渲染后会恢复默认值，因此不采用。

### 2. 保留全部结构化内容，仅改变可见分组

渲染仍按标题、卖点、痛点、五点描述、商品描述、后台搜索词、关键词分组创建七个字段，并分别标记为 `copy` 或 `search`。CSS 根据卡片当前内容模式隐藏另一组，切换时不重新解释或改写 Listing 数据。

### 3. 单语言优先，对照模式响应式排列

默认 `en` 只显示英文值、英文复制控件和英文字符数；`zh` 对应显示中文；`compare` 同时显示两种语言。英文和中文值继续拥有各自独立的复制载荷。对照模式在可用宽度充足时使用两列，在移动布局中改为上下排列，避免压缩长词、单位或技术标识符。

### 4. 操作栏固定在 Listing 滚动边界内

记录页 Listing 标题、状态、重新生成、完整复制和导出组成一个 `position: sticky` 的工作区操作栏。它只在 Listing 面板滚动到结果区顶部后保持可见，不覆盖记录页全局工具栏。记录摘要中的原生成按钮继续保留，便于尚无草稿时启动生成。移动布局下，Creation 记录页自身较高的标题和筛选区保持普通文档流，避免其粘性层覆盖 Listing 的内容与语言切换控件。

### 5. 字段采用分隔区而不是嵌套卡片

Listing 草稿保留一个外层条目容器；内容框和字段移除独立卡片背景，通过间距与分隔线建立层级。字段标签保持静态文本，字段级复制改为独立的小型命令按钮；条目文字仍是无边框复制目标，维持既有逐条复制能力。字符数改为低对比度行内元数据。

## Risks / Trade-offs

- [用户误以为隐藏字段未生成] -> 内容切换始终展示两个明确分组及字段数量，并仅通过视图状态隐藏，完整复制和导出继续包含全部七字段。
- [对照模式在窄屏过密] -> 移动布局强制上下排列，控件允许换行且不改变固定宽度按钮尺寸。
- [重渲染丢失当前视图] -> 视图模式存入 `state.creation`，记录与 inline 视图共享同一状态读取函数。
- [新增重新生成按钮触发重复请求] -> 复用现有生成控制器与并发状态，两个生成入口同步禁用并显示生成中状态。
- [历史草稿缺少部分中文值] -> 仅在对应中文内容存在时显示中文复制目标；不合成或补写内容。

## Migration Plan

1. 先增加渲染和交互回归，固定默认模式、分组、复制载荷与生成入口同步状态。
2. 修改 HTML、共享 Listing 视图和样式，再同步 `public/lib` 浏览器副本。
3. 运行定向测试、完整测试、Pages 构建、同步检查和 OpenSpec 严格验证。
4. 在 `3600` 的同一条真实记录上完成桌面与移动端截图、切换和复制验证。
5. 回滚时恢复展示层文件即可；Listing 数据和已导出文件无需迁移。
