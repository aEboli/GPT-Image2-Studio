# GPT-Image2-Studio v0.2.072

`v0.2.072` 将主应用版本从 `0.2.071` 更新到 `0.2.072`。

## 更新内容

- **提示词增强**：默认文本改为可编辑的英文清晰度指令，先保留原提示词、参考图、主体和构图，再降低非预期模糊、锯齿、色带与压缩伪影。原图有意的柔焦、颗粒、像素风和极简表现会继续保留；`8K` 是视觉质量目标，不代表实际输出分辨率。
- **当前调用摘要**：新增所选生图服务的可点击 origin（协议、域名及可选端口），省略 API 路径与凭据。
- **生成日志**：行布局更紧凑；成功结果显示简短文件名，完整接口地址、错误详情与任务状态继续保留，便于查看和排错。
- **移除图片裂变工作台**：删除专属工作台及其分析契约和入口。已有图片资产、生成记录和历史发行说明不受影响；旧 `#product-agent` 地址回到提示词生图。

## 版本规则

- 普通更新：更新位 +1。
- 版本格式为 `major.minor.patch`，patch 固定三位数字；上级版本变化时，下级版本归零。

## 升级说明

- 既有配置、生成记录和图片资产不需要迁移。
- 商品图采集扩展使用独立版本线，本次主应用更新不会修改扩展版本。
