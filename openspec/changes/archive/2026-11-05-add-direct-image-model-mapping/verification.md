- 流式输出下方显示可编辑的「当前模型 → 请求模型」胶囊，支持多行增删、手填及共享的已获取候选。
- 浏览器、本地配置、公开模型元数据、JSON/FormData 和任务快照保存映射；省略字段保留原值，空数组明确清空。
- 按完整 ID 区分大小写单次替换，不链式替换；空白草稿忽略，不完整和重复来源在保存前提示修正。
- Images 生成/编辑、参考图自动切换 edits、Chat Completions 生图和 Responses 图像工具发送实际渠道 ID。普通及 SSE 请求均覆盖；独立文本模型及其他通道保持原值。
- 已知模型映射为渠道别名仍按已知能力校验；自定义名称明确映射为已知 ID 时使用对应能力。未知名称不靠字符串相似度扩展能力。
- 任务与画廊保留所选及实际发送模型，参数检查器可分别查看。排队任务冻结规则；套图、写真和文章已保存任务的补图不采用当前新别名。
