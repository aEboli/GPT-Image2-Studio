# GPT-Image2-Studio v0.2.11

`v0.2.11` 将主应用版本从 `0.2.10` 更新到 `0.2.11`。

## 更新内容

### Temu 上品工作台

- 套图记录工具栏的入口改名为“temuexcel导出工作台”，不再需要先勾选套图记录，且入口不再随勾选状态被禁用。点击后直接进入工作台主界面。
- 勾选的套图记录不再触发自动导入对话框。需要带入已有套图时，在工作台内主动使用“从 Studio 导入”。
- “变种信息”区域新增“新增变种”操作，每次只追加一条可编辑 SKU 行，继承商品级申报价、尺寸、重量与库存默认值，不重建双变种笛卡尔矩阵，也不改写已有行。
- 批量快速导出移入工作台的“批量快速导出”标签，仍按套图记录批量生成工作簿。

### 本地画廊与图片显现

- 画廊改用服务端生成的 WebP 缩略图（最长边 512px）加载列表，替代直接加载原图。
- 生成主预览与图片详情灯箱在图片完成浏览器解码后再以柔和显现方式呈现；重复渲染同一图片地址不重播动画。
- 图片编辑与快速溶图两个模式接入同一显现行为。

### 本地优先与启动

- 移除 `fonts.googleapis.com` 与 `fonts.gstatic.com` 的预连接和样式表请求，界面改用本地系统字体栈（`--font-ui`）。首屏不再依赖第三方字体主机。
- Windows 启动脚本改为每次启动只采集一次本地 TCP 监听端口快照，命中端口须先通过 Studio 健康检查才复用，否则选取范围内第一个可用端口。

### 套图生成稳定性

- 套图单项在本地流等待到期后，仅中止流读取，保留上游原任务回查（超时 120 秒），避免后台自动补图重复提交仍在运行的任务。
- 迟到的流事件与旧清单不再覆盖已保存的正式图片。
- 参考图分类将“功能卖点证据”与“材质/结构细节”拆为两类，各自的提示词只作为支撑证据而非可售主体。
- 多颜色、尺码或大小变体的尺寸事实按变体分组绑定，不再压成一个全局摘要。

## 升级说明

- 主应用每次更新仅递增一个补丁版本，即 `+0.0.1`。
- 既有配置、生成记录和图片资产不需要迁移。
- 本次新增 `jimp` 与 `@jsquash/webp` 两个运行时依赖用于服务端缩略图，从源码运行需重新执行 `npm install`；桌面安装包与免安装 ZIP 已内置。
- 画廊缩略图在首次浏览各目录时按需生成并缓存，首次加载会略慢于后续访问。
- 商品图采集扩展使用独立版本线，本次主应用更新不会修改扩展版本。
