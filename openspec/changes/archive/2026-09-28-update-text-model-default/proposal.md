# 更新文本模型默认值

## Why

Responses 与直连文本/视觉通道当前共享默认模型 `gpt-5.4-mini`。新配置、空值回退、界面占位提示和配置示例都继续指向该模型。

## What Changes

- 将两个文本通道的共享默认模型更新为 `gpt-6-luna`。
- 更新界面初始显示、文本模型输入占位、环境变量示例和中英文配置说明。
- 保留本地、浏览器和请求中显式配置的模型值；不重写已有用户配置。

## Impact

- 能力：`runtime-configuration`
- 验证：共享默认值测试、配置默认值测试、OpenSpec 校验和公共模块同步检查。
