## Why

Listing 在缺少可追溯重量时，会把包装重量固定补成 350 g、商品重量固定补成 250 g，并覆盖模型已经给出的分类化估算，导致不同商品出现相同而失真的重量。需要让估重真正依据商品品类、结构、数量和包装差异，同时继续明确标记为估算值。

## What Changes

- 无明确重量证据时，按商品品类、长度与结构、已知材质、件数和包装增量生成保守重量估算，不再复用一个固定通用数值。
- 保留上游模型给出的合规数值估算；只有字段缺失或不可用时才应用本地分类化兜底。
- 明确重量证据继续原样优先，商品净重与包装毛重仍保持独立来源边界。
- 增加服装回归场景，确保中长款轻薄旗袍可落在约 320 g 净重、约 420 g 包装重，且与其他品类产生差异。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `creation-listing-agent`: 将缺失重量时的固定常数兜底改为商品感知估算，并保留可用的上游估算。

## Impact

影响 `lib/creation-listing-agent.mjs` 的重量提示、生成结果规范化、本地兜底和历史回读，以及对应 Listing Agent 测试。Listing 字段结构和 API 形状不变，无新增依赖。
