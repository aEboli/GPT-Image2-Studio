# GPT-Image2-Studio v0.2.1

`v0.2.1` 重点完善电商套图的平台化规划、Listing 生成与冻结计划执行链路。浏览器、本地服务、Cloudflare Worker、队列、记录与修复流程现在围绕同一份有效计划工作，并补强旧记录兼容、事实边界和跨端一致性。

## 版本亮点

- **19 个平台的套图规划**：内置平台图片类型、推荐数量、比例、分辨率、语言、构图、文字密度、场景与 Logo 策略，支持套图级和单图级手动覆盖。
- **全平台 Listing V2**：Listing 生成、重写、查看、复制与导出不再仅限 Amazon；按平台与 locale 解析字段和文案策略，并为低证据平台采用保守建议。
- **冻结计划端到端执行**：正式生成、后台队列、Local/Worker、保存记录与补图修复复用提交时的 `effectivePlan`，避免提交后表单或内置策略变化导致结果漂移。
- **旧数据保持可读**：历史 V1 Listing 草稿保留原始 Unicode 内容且不在读取时迁移；缺少新字段的旧 Creation 记录继续使用兼容回退。

## 改进

- 显式生成数量可与所选图片用途完整对齐，支持补足到 18 张，并为自定义槽位生成受事实边界约束的用途标题与提示词。
- 平台下拉切换改为即时生效，不再弹出确认框；切换后重新计算平台计划，同时保留商品信息、参考素材、Logo、SKU、输出格式与模型/API 配置。
- 兼容图片类型、平台计划摘要和高级编辑器跟随当前显示的冻结队列快照；历史任务回退为只读展示。
- Listing 草稿按平台展示发布字段与内部建议字段，补充待复核状态、动态字段标签和更准确的复制范围。
- Creation 记录灯箱优先展示实际生成提示词与已保存的请求快照；时间线保留生成开始与完成时间。
- 优化宽屏、缩放和移动端布局，提升窄屏和高信息密度场景下的可读性。
- 合并参考素材流程，移除已废弃的独立风格参考上传字段；旧值恢复时使用安全回退。

## 修复

- 修复预览已冻结但正式生成重新规划的问题，确保 Local 与 Cloudflare Worker 使用相同的图片顺序、提示词、比例、尺寸和语言。
- 修复队列、manifest、记录复用和补图修复可能按当前表单或当前策略重算的问题。
- 修复旧记录灯箱从当前配置推测生成参数的问题；缺少快照时不再虚构历史参数。
- 修复参考图分析的陈旧响应覆盖新平台或类目状态的问题，并收紧敏感人群、无依据营销声明和高风险 claim 的事实门控。
- 修复不同语言下不受支持的材质、认证、兼容性、性能等声明可能漏检的问题。
- 修复 Listing 本地端点与 Worker 端点在策略、locale、上游请求、校验与保守回退上的差异。
- 修复显式图片数量、所选角色、兼容图片类型计数与冻结计划不一致的边界情况。
- 修复时间线更新后生成起止时间丢失，以及记录时间样式作用范围过大的问题。

## 工程质量

- 将平台规划、Listing policy、生成快照和记录灯箱逻辑收敛为共享模块，并保持 `lib/` 与 `public/lib/` 浏览器镜像一致。
- 扩充平台 policy/resolver、Listing V2、Local/Worker parity、队列/存储/修复、记录灯箱、浏览器状态与端到端回归测试。
- 本地服务默认绑定回环地址，并加强敏感写接口的同源或启动令牌校验。
- 完善 Cloudflare Worker manifest 冻结字段与 R2 自定义元数据大小边界，避免将完整提示词写入受限元数据。
- 同步 OpenSpec 规格、设计与验收场景，覆盖平台规划、Listing、冻结快照和无确认平台切换。

## 升级说明

- 版本号由 `0.2.0` 升级到 `0.2.1`，Git tag 为 `v0.2.1`。
- Windows 用户可直接安装 `GPT-Image2-Studio-Setup-v0.2.1.exe`。覆盖安装前建议备份自定义环境变量、本地配置与重要输出。
- 源码运行要求保持为 Node.js 20 或更高版本；更新依赖后重新启动服务。
- 旧 Creation 记录和 V1 Listing 草稿无需手动迁移；用户主动重写 Listing 时才会生成并冻结 V2 policy 元数据。
- 平台切换现在会立即生效并清除该平台的自动规划和覆盖状态；需要恢复时重新选择原平台。
- 独立“风格参考图”上传入口已移除，请使用现有商品参考素材与角色标注流程。
- Cloudflare Pages 部署需要基于本版本重新执行构建并发布新的 `dist/` 产物。
