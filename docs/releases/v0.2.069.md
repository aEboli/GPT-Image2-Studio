# GPT-Image2-Studio v0.2.069

`v0.2.069` 将主应用版本从 `0.2.068` 更新到 `0.2.069`。

## 更新内容

- 商品图采集扩展升级到 `1.1.34`。多图下载改为最多 8 路并发提交，单张失败不会中断其他图片；采集窗显示忙碌状态、部分失败数量和首个错误，并支持辅助技术与减少动态效果设置。
- 修正深色基础主题及六套传统主题的文字、边框、按钮、输入框和弹出层对比度与表面层级。
- 同步商品图采集规范、主题资源缓存版本及中英文 README。

## 版本规则

- 普通更新：更新位 +1。
- 版本格式为 `major.minor.patch`，patch 固定三位数字；上级版本变化时，下级版本归零。

## 升级说明

- 既有配置、生成记录和图片资产不需要迁移。
- 主应用与商品图采集扩展使用独立版本线；本次扩展版本为 `1.1.34`。
