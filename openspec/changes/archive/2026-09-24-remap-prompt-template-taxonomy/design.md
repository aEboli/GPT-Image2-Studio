## Context

Prompt Kit 当前通过静态模块生成 6 个一级分类、24 个二级分类和 240 条模板。只有 40 条记录含有 YouMind 来源图片与提示词配对，其他条目使用通用合成图片。用户提供的截图将浏览目录分为“使用场景”“风格”“主体”三个维度，并提供 41 个二级标签；用户另外提供了一条厨房场景图片与完整提示词。

## Goals / Non-Goals

**Goals:**

- 使用截图中的全部分类名称和层级。
- 让每条目录记录只存储一个稳定 ID、一张本地图片和一段完整提示词，并在三个维度各映射一次。
- 保留离线运行和现有浏览、搜索、预览、应用及复制功能。

**Non-Goals:**

- 不为缺少真实匹配素材的二级分类生成占位模板。
- 不在运行时抓取 YouMind 或其他网站。
- 不改变个人模板存储或 Prompt Agent 历史逻辑。

## Decisions

- 以 `youmind-profile-entries.mjs` 保存唯一图片/提示词记录，以 `prompt-template-library.mjs` 中的显式 ID 映射保存三个分类维度。这样不同筛选入口复用同一条记录，不复制提示词或资源。
- “全部”目录按模板 ID 去重；每个一级维度内每条记录只属于一个二级分类。空分类保持空，不使用无关图片填充。
- 将用户给出的厨房图片作为单独本地 PNG 和一条来源记录，与 40 条现有来源配对共同组成目录。
- 移除旧生成预览资源，避免未配对内容残留或被未来代码误用。

## Risks / Trade-offs

- 现有素材无法覆盖截图中的全部 41 个二级分类，因此部分筛选项会暂时为空；保留空项比展示错误图片和提示词更可靠。
- YouMind 与其公开仓库在实现期间连接超时，无法核对比仓库已有 40 条来源配对更多的新条目；当前目录以本地可核验配对和用户示例为界。

## Migration Plan

- 替换静态目录与默认筛选，镜像同步浏览器模块。
- 删除不再引用的通用预览图片。
- 更新目录规范和测试，验证每条记录三个维度各映射一次且图文均存在。
