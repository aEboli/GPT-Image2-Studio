# GPT-Image2-Studio v0.2.044

`v0.2.044` 将主应用版本从 `0.2.043` 更新到 `0.2.044`。

## 更新内容

- 将路由模式的 `tools[].model` 开关默认改为关闭，并同步配置、请求构造、浏览器模块、README 与回归测试；开启时才发送所选生图工具模型。
- 关闭时完整省略 `tools[].model`，保留下拉框选择和排队任务快照；旧配置缺少 `includeImageToolModel` 时也归一化为关闭。
- 更新运行时规范、归档变更记录和中英文 README，明确中转兼容行为与按需开启方式。

## 版本规则

- 普通更新：更新位 +1。
- 版本格式为 `major.minor.patch`，patch 固定三位数字；上级版本变化时，下级版本归零。

## 升级说明

- 既有配置、生成记录和图片资产不需要迁移。
- 商品图采集扩展使用独立版本线，本次主应用更新不会修改扩展版本。
