# GPT-Image2-Studio v0.2.117

`v0.2.117` 将主应用版本从 `0.2.116` 更新到 `0.2.117`。

## 更新内容

- 套图按必要视觉信息选择参考：简单白底默认仅主体，细节、视角、状态和款式按缺失信息追加；完整事实来源继续保留。
- 区分实际附件与事实溯源，去除重复内容，保留不可替代的视面和开合状态；必要参考仍可超过八张，并遵守字节预算。
- 强化握把、手机操作及重复渲染构图的审核。高置信重复在两轮修复后仍冲突时保留为待调整，不自动发图，其他合格项可继续。
- CG 和功能渲染默认干净白底，重新安排来源支持的姿态与镜头，并使用有依据的光效、热流和空间作用。严格白底商品展示单独禁止概念光效和新增文案。
- 预览可核对实际参考用途。新计划冻结附件与提示词；旧记录、原提示词及上一版已冻结队列继续兼容。

## 版本规则

- 普通更新：更新位 +1。
- 版本格式为 `major.minor.patch`，patch 固定三位数字；上级版本变化时，下级版本归零。

## 升级说明

- 既有配置、生成记录和图片资产不需要迁移。
- 商品图采集扩展使用独立版本线，本次主应用更新不会修改扩展版本。

## 验证

- 发布前需运行项目测试、构建、发行一致性检查和 OpenSpec 严格校验；实际结果以本次发布交付记录为准。
