# GPT-Image2-Studio v0.2.020

`v0.2.020` 将主应用版本从 `0.2.19` 更新到 `0.2.020`。

## 主要更新

### Prompt Kit 模板库

- 新增六个一级分类、24 个二级分类，每个二级分类提供十条可直接复用的提示词。
- 模板库支持搜索、分类筛选、列表/图片两种视图、列表字号调节、完整提示词灯箱预览、一键应用和复制到我的模板。
- 删除模板库的瀑布流视图；历史生成画廊仍保留自己的瀑布布局。
- 人像与头像分类内置从用户指定的 YouMind 集合抓取的八张真实预览图，保留原始资源 URL 和提示词页面归属，运行时不依赖外站。
- Prompt Kit 默认模板替换为证件照、商务头像、电商主图、生活写真、室内家居、城市旅行和营销海报等实用场景；旧内置模板会迁移到 v2 集合，用户自定义模板和 Prompt Agent 历史不受影响。

### 创作提示词与 Windows 运行时

- 套图轮播、SKU 和信息图重构提示词改为长度受控的正向指令，减少重复的反向约束；历史记录中的冻结提示词不改写。
- 项目自有 Windows 启动器、Native Messaging 和兼容安装器脚本统一要求 PowerShell 7.4+，缺少运行时或脚本时明确返回失败；纯 Node/Electron 和停止服务 CMD 入口保持独立。

### 发布与版本管理

- 版本格式统一为 `major.minor.patch`，`patch` 固定三位数字。
- 新增 `npm run release:major`、`release:minor`、`release:feature` 和 `release:patch`，分别执行分级升级并同步包、锁文件、工作台、README、Windows 文档和发行说明中的版本事实。
- 依赖锁定补充 `image-size@2.0.4` 和 `uuid@11.1.1` 覆盖，保持构建链路可复现。

## 升级说明

- 既有配置、生成记录和图片资产不需要迁移。
- 首次打开 Prompt Kit 时，旧 `default-template-*` 内置条目会替换为当前 v2 默认集合；用户自定义条目和 `prompt-agent-*` 条目保留。
- Windows 源码脚本需要 PowerShell 7.4 或更高版本；普通 Node.js 服务仍支持 Node.js 20+，桌面构建使用 Electron 所需的 Node.js 22.12+。
- 商品图采集扩展使用独立版本线，本次主应用更新不会修改扩展版本。
