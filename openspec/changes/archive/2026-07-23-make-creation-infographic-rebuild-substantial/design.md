## Context

现有信息图重构已经在规划、Local、Worker 和修复路径中统一使用 `buildCreationInfographicRebuildPrompt()`，并且每项只发送匹配的原始源图。问题不在图片筛选，而在 canonical prompt 同时要求保持布局、层级、字体、颜色、背景、裁切和相对位置不变，并明确禁止 redesign，因此模型只能近似复刻。

OpenAI 官方 GPT Image 提示指南建议对复杂图像任务使用清晰的分段结构，并显式区分“需要改变的内容”和“必须保留的不变量”。本次沿用该方式调整固定提示词，不改变 API 或数据流。

## Goals / Non-Goals

**Goals:**

- 继续让对应原始信息图一张成为唯一视觉与信息来源。
- 保留商品身份、完整可见文字、语言、数字、单位、参数、声明、步骤、清单和逻辑关系。
- 让输出第一眼即可看出是重新设计的信息图，而不是清晰化或微调版。
- 让新提示词自动覆盖新计划、正式生成、Worker、历史记录修复和重试。

**Non-Goals:**

- 不恢复主体图、其他信息图、Logo、平台、目标语言或营销策略输入。
- 不增加视觉分析、相似度评分或自动二次生成服务。
- 不修改模型路由、比例、尺寸、质量、格式或推理参数。
- 不新增用户可调的重构强度或风格选项。

## Decisions

1. **只修改 canonical prompt，不修改参考图筛选和请求协议。**
   - Rationale: 当前单图隔离方向正确，用户反馈只说明视觉变化不足；保持数据流不动是最小必要变更。
   - Alternative considered: 重新引入主体图或风格图以放大变化。该方案会再次引入商品替换和其他信息污染。

2. **提示词使用 `GOAL`、`SOURCE FACTS`、`REQUIRED REDESIGN`、`MUST PRESERVE`、`FAILURE CONDITIONS` 和 `CANVAS` 分段。**
   - Rationale: 分段能同时表达重构目标、可变视觉维度和不可变事实，避免“faithfully reconstruct”被模型理解成临摹。
   - Alternative considered: 只删除 `do not redesign`。该方案没有给模型足够明确的新构图任务，仍可能只做轻度风格化。

3. **要求新总体布局和信息架构，并至少明显改变三个额外视觉维度。**
   - Rationale: 单一换色或字体变化不足以构成重构；多维变化能建立可观察的最低标准，同时给不同类型信息图保留设计空间。
   - Alternative considered: 固定一种左右分栏或卡片模板。该方案会让不同信息图趋同，也属于引入源图之外的统一风格。

4. **事实保真与视觉保真分离。**
   - Rationale: 商品身份、文字和参数必须保留，但布局、视觉层级、背景、字体系统、色彩和组件表现必须允许重做。
   - 商品可以重新缩放、裁切和放置以服务新构图，但不得改变款式、颜色、部件或数量，也不得被替换成相似商品。
   - 文字分组和阅读顺序可以为清晰度重新组织，但不得改变文本、归属关系或逻辑含义。

5. **继续在运行时覆盖历史保存提示词。**
   - Rationale: 现有 `buildCreationItemGenerationPrompt()` 已按 `infographic-rebuild` role 返回 canonical prompt；更新常量即可让旧记录修复使用新行为，无需迁移 manifest。

## Risks / Trade-offs

- [模型为了明显变化而改写小字或数字] -> 在 `MUST PRESERVE` 中逐项锁定原文、语言、数字、单位和逻辑关系，并维持高质量生成参数由用户控制。
- [模型把新构图理解成替换商品] -> 明确允许改变的是位置和视觉表达，不允许改变商品身份、款式、颜色、部件和数量。
- [模型仍然近似复刻] -> 在 `FAILURE CONDITIONS` 中把沿用同一网格、只清晰化、只微调间距或换色列为失败，并要求新布局加至少三个视觉维度变化。
- [固定提示词不能保证所有图片一次成功] -> 自动相似度评估和二次生成不在本次范围内；以代表性真实生成做视觉验收并保留人工补图流程。

## Migration Plan

1. 更新 canonical prompt 和提示词行为测试。
2. 验证 Local、Worker 和 repair 仍执行同一新提示词并只带一张源图。
3. 完成全量测试、构建和 OpenSpec 严格验证后重启 `3600` 服务。
4. 回滚时恢复旧提示词常量；数据结构和历史 manifest 不需要回滚。
