# tighten-config-drawer-alignment

## Why

配置抽屉已经按提供方拆分了字段，但在实际宽屏下接口标题会被右侧工具栏挤成省略号，凭据与模型的标题行也不总是落在同一条基线上。抽屉和日志按视口整屏铺开后，表单结束区域还会留下明显的无效空白，日志条目之间的纵向节奏也偏松。

## What Changes

- 为接口标题保留可读的最小轨道，让协议后缀和完整 URL 控件使用剩余宽度。
- 统一配置字段标题行、模型操作按钮和输入控件的高度与列线，继续保持单行省略而不换行。
- 在宽屏下给配置抽屉建立有边距的面板边界，并保持表单与日志等宽、独立滚动。
- 收紧配置日志条目的内边距和元信息间距，减少空白但保留完整值的可检查入口。

## Non-Goals

- 不修改接口请求、参数归一化、保存键名或 API 历史隔离逻辑。
- 不删除配置字段，不把长文本改为换行布局。
- 不改变平板和手机的单列触控布局。

## Impact

- `public/styles.css` 增加配置抽屉的最终响应式对齐规则。
- 配置表面回归测试增加标题可读宽度、宽屏面板边界、等宽列和日志密度断言。
