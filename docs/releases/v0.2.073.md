# GPT-Image2-Studio v0.2.073

`v0.2.073` 将主应用版本从 `0.2.072` 更新到 `0.2.073`。

## 更新内容

- **描述性图片文件名**：新生成图片使用时分与主体/动作/场景描述；套图保留编号，同名资产递增后缀且不覆盖既有图片、缩略图或元数据。记录、画廊和下载沿用实际保存的文件名。
- **界面配色**：新增八套中的「黑曜」并设为新用户默认；已保存的「靛蓝」选择及其持久化标识继续兼容。
- **套图队列**：队列项在位次旁显示商品名，便于区分等待中的商品。
- **配置抽屉**：关闭时将隐藏控件设为 inert，避免键盘焦点进入不可见表单。

## 版本规则

- 普通更新：更新位 +1。
- 版本格式为 `major.minor.patch`，patch 固定三位数字；上级版本变化时，下级版本归零。

## 升级说明

- 既有配置、生成记录和图片资产不需要迁移。
- 商品图采集扩展使用独立版本线，本次主应用更新不会修改扩展版本。
