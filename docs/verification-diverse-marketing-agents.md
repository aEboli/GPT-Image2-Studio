# 每套独立视觉营销 Agent 验证

## 实现范围

内置 64 位视觉营销 Agent，分属杂志叙事、电影叙事、感官静物、平面实验、功能证据、生活纪实、自然氛围和都市企划八类。每位都有明确的品类观察、购买视角、场景语言、构图、环境配色、布光和版式策略。完整人设位于 `lib/creation-marketing-personas.mjs`。

随机单位为一套营销图片。一位 Agent 统筹套内各张图片；不同套独立规划。设置 1 个方案、每方案 20 套时，会执行 20 次独立套图规划，不再把一份提示词重复生成 20 套。套内 20 张图片仍在正常成功路径的一次文本请求中统筹，不改成逐张请求规划。

## 随机与执行链路

- 新套图从 64 人牌池随机无放回抽取，均衡消耗八种流派并优先避开最近的流派；一轮用尽后重新抽取。
- 每套使用独立变化种子。相同会话、相同商品输入和相同非空种子的请求重试沿用同一人设；预留表上限为 2,048 项。
- 人设和近期四份设计摘要进入初次文本规划与局部修复上下文。模型被要求从场景叙事、主体空间关系、环境配色、照明和版式中的至少四个维度区分套图，并将具体设计写入最终提示词。
- 实际生图提示词追加本套的视觉执行规则，不只是保存 Agent 名字。冻结计划、队列、记录和补图保留同一人设及最终提示词。
- 批量每套完成入队后释放本套冻结结果，下一套重新规划。暂停保留当前未入队结果，继续时不重新规划该结果或重复提交已入队套图。两个规划槽位和现有图片并发上限保留。
- 手动确认方案第一次生成使用原冻结内容；该方案已入队后再次创建新套，先独立规划。新规划失败不回退重复提交旧方案。

## 边界

人设不改变商品实物颜色、结构、参数、配件和已确认功能。严格白底主图不引入环境、道具或文字；纯白功能图和商业 CG 保持白底约束；无字任务不增加标题、图标或标签。用户锁定提示词不追加人设指令。新计划使用版本 14 与指纹契约 15，旧版本仍按原契约提交，不自动迁移历史计划。

随机牌池和请求预留位于当前服务进程内；服务重启后重新开始随机轮次。已保存套图的人设与提示词继续保留。超过 64 套允许进入新轮次，不承诺无限历史不重复。该功能增加独立套图的文本规划次数，不增加用户配置的图片总数。

- 人设覆盖：64 个完整且唯一的人设，八个流派，多轮牌池不重复、相邻流派回避、50 套同时分配不同人设、稳定重试及返回值隔离。
- 执行覆盖：不同 Agent 进入文本请求及实际图片提示词；同样的模拟初稿会获得不同视觉执行指令；局部修复、保存、冻结和补图保持本套设计。
