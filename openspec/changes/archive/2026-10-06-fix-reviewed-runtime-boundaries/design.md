## Decisions

1. 服务端密钥绑定配置中归一化后的地址与接口后缀。请求显式携带所用密钥时可以覆盖地址；复用服务端密钥时改变目标必须报错，错误不得包含密钥。
2. 桌面端继续监听系统分配的回环端口。沙盒 preload 仅暴露读取、保存 API 配置的方法，主进程检查发送窗口、顶层 frame 与 Studio origin，并将配置原子保存到稳定用户目录。公开 HTTP 配置仍只返回掩码。
3. 文件事务锁覆盖读改写；临时文件与正式文件同目录，以原子替换避免读到截断数据。四类清单和提示词历史共享该机制，失败后队列继续可用。
4. 扩展版本通过注入函数参数传递；回归测试序列化函数到独立页面环境，禁止依赖后台闭包。
5. 历史容量只约束终态快照。Listing 请求计时器在响应正文消费结束后释放。

## Verification

- 覆盖四个提供方通道、旧直连字段及完整接口 URL 的密钥与地址绑定。
- 覆盖 PPT 路径拒绝、全部清单并发读写、历史并发追加和超过容量的运行中任务。
- 使用慢正文 HTTP 上游验证 Listing 取消；使用隔离 Electron 用户目录验证跨端口与跨进程恢复。
- 运行全量测试、公共模块同步、发布事实、OpenSpec 严格校验、桌面冒烟与构建。
