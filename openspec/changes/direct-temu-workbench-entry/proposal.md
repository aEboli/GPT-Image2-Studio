## Why

当前套图记录工具栏中的入口显示为“导出 Temu Excel（N）”，并把是否勾选记录同时当作“打开 Temu 工作台”和“批量快速导出”的前置条件。即使用户只是想进入工作台新建、编辑或查看商品，也必须先勾选一套图；一旦勾选，宿主还会把这些 set ID 传入子文档并自动弹出“从 Studio 导入”对话框。

这把两个不同目的混在了一起：工作台入口应当直接进入工作台主界面，而批量快速导出才需要明确指定一批套图记录。用户需要无需勾选即可进入正常工作台界面，且已经勾选记录也不能改变该入口的默认去向。

## What Changes

- 本 change 依赖 `absorb-temu-listing-workbench` 提供的内置覆盖层与“批量快速导出”标签，但对两者共享的入口语义作后续覆盖：其“未勾选不打开、勾选后自动 Studio 导入”的约定不再适用。
- 将套图记录主入口的可见名称改为 `temuexcel导出工作台`；保留既有元素标识、单一监听器归属和非选择相关的安全阻塞条件。
- 主入口不再要求勾选任何套图记录。未勾选时可直接打开工作台，已勾选时同样打开工作台主界面。
- 主入口每次打开均以空的 set ID 集合启动工作台，不得传递当前勾选记录、过滤结果或任何等价的预选数据；因此初始化不会自动打开“从 Studio 导入”对话框或执行任何 Studio 导入动作。初始化继续同步工作台所需的展示上下文，例如主题和语言。
- 在工作台内保留“从 Studio 导入”这一显式用户操作；只有用户在工作台主界面主动点击该操作时，才可打开其导入对话框。
- 覆盖层中的“批量快速导出”标签继续使用套图记录的显式勾选批次。该标签在没有有效勾选记录时不得发起批量导出，并继续提示用户先勾选记录。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `creation-mode`: 套图记录的 Temu 主入口从“按勾选记录导出”调整为可直接进入的工作台入口；批量快速导出仍保持显式多选语义。
- `temu-listing-workbench`: 工作台由套图记录入口以空选择集合启动，默认呈现工作台主界面而不是 Studio 导入对话框。

## Impact

- Frontend: 套图记录工具栏的标签、可用性和点击分支；工作台覆盖层启动器；同源子文档的初始化消息处理。
- Existing behavior: 批量快速导出的请求、预检、严格/待补全模式、批次默认值表单和显式选择要求保持不变；单套提示词 TXT、记录 JSON 与 Listing JSON 导出保持不变。
- Tests: 需要覆盖未勾选直达、已勾选仍不预选/不自动导入、批量快速导出仍要求显式选择，以及工作台内手动 Studio 导入仍可用。
