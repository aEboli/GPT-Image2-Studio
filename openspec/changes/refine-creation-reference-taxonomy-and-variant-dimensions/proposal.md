## Why

Creation Mode 当前把功能卖点参考图和材质/结构细节参考图混在同一分类中，无法准确表达功能证据；同时，多个颜色、尺码或大小变体的尺寸事实在规划阶段被压成一个全局摘要，生成提示词失去每个数值对应的主体边界。

## What Changes

- 新增稳定的 `feature` 参考图角色，中文显示为“功能卖点”，并将材质/结构角色收窄为材质、纹理、外观结构和工艺证据；使用说明仍只负责操作流程。
- 参考图分析为尺寸卡支持结构化 `dimension_groups`，每组保留变体标签、精确规格事实以及可选的商品参考图索引/文件名绑定。
- 规划器保留兼容的扁平 `dimensionSpecs`，同时为尺寸轮播和 SKU prompt 使用按组的规格摘要；可靠绑定缺失时不把同一组数值复制到所有 SKU，也不交叉组合不同组的 Length/Width。
- 尺寸提示词明确保持原始字段标签和每组主体对应关系，禁止把 Width、Height 等字段重命名为另一个字段或把公制/英制换算值当作独立规格。
- 保持历史参考角色、历史计划和无分组尺寸输入兼容；结构化分组缺失时按稳定参考索引/文件名回退为独立组。

## Non-Goals

- 不从像素重新执行 OCR，不承诺生成模型对小字和复杂箭头的像素级复刻。
- 不猜测没有证据的颜色、尺码、型号或尺寸归属。
- 不改变套图 role ID、平台策略、参考图数量/字节预算或上游 API 参数。

## Impact

- 参考图分析指令和 JSON schema 增加功能角色与尺寸分组字段。
- `lib/creation-planner.mjs`、Creation 前端分类/分析 payload、相关测试和 Creation Mode 增量规范需要同步更新。
- 历史保存数据仍读取既有 `role`、`note`、`reference_indexes` 和扁平 `dimensionSpecs` 字段。
