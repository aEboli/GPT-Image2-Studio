## 方案

### 1. 保持现有液体语义和任务壳

继续复用现有 `preview-loading-shell`、任务 ID 槽位和 `aria-hidden` 装饰子树。提示词模式的液体主体、液面和底部沉积不改变；只将细流拆为两个视觉轨道。

### 2. 错相细流

每个 orb 保留一条主细流，并增加一条窄一些的相位细流。两条细流使用相同的重力关键帧，但相位细流以当前 `flowDuration` 的负半周期延迟开始。单条细流在入口上方重置时，另一条细流仍处于可见的下落或摊平阶段，因此容器内不会出现整段细流同时消失的空窗。

细流关键帧的首尾保持相同的非零低透明度和位置，循环边界速度由 `ease-in-out` 收束；不可见重置只发生在容器裁剪范围之外。

### 3. 阶段参数

`getPreviewLoadingShellTheme()` 先计算实际的阶段流动时长，再返回 `flowPhaseDelay`（负半周期毫秒值）。`getPreviewLoadingOrbRenderState()` 和 `applyPreviewLoadingOrbState()` 将该值传入 CSS 自定义属性；这样不同阶段和并发能量不会破坏错相关系。

### 4. 降级和边界

`prefers-reduced-motion: reduce` 继续停止两条细流、液面、沉积、外环和多任务场动画，并保留静态底部锚定形态。新增细流不改变布局尺寸、可访问名称或非提示词模式的共享加载壳。

## 取舍

- 不使用 JS 定时器或逐帧 DOM 更新，避免轮询刷新造成跳帧并保持合成层动画的低开销。
- 不引入 Canvas、WebGL 或第三方物理引擎；错相 CSS 轨道足以消除循环边界，同时保留既有视觉物理隐喻。
