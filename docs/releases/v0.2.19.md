# GPT-Image2-Studio v0.2.19

`v0.2.19` 将主应用版本从 `0.2.18` 更新到 `0.2.19`。

## 更新内容

### Grok 图片生成与编辑

- 新增独立 Grok 通道，默认地址为 `https://api.x.ai/v1`，默认图像模型为 `grok-imagine-image-2.0`；地址、API Key、接口后缀和模型独立保存、测试并获取模型列表。
- 使用 xAI JSON 图像协议：无参考图请求 `images/generations`，带参考图请求 `images/edits`，单次最多 5 张参考图。
- 所选尺寸映射为 `1k` / `2k` 分辨率，不支持的比例就近匹配；不向 Grok 发送 GPT 的像素 `size`、输出格式、透明背景或本地蒙版参数。本地蒙版编辑需使用 GPT 路线。

### 参数与 API 历史隔离

- Grok 质量仅提供并发送 `low` / `medium`，默认 `medium`；旧值以及 GPT 专属质量档会收敛为 `medium`，修复不受支持的质量导致的 HTTP 400。
- GPT、Gemini、Grok 分别记住自己的质量选择。Grok 图片请求、预览元数据、任务快照、套图快照和图片记录省略 GPT 专属思考等级；GPT 文本/视觉规划仍保留所选思考等级。
- 全工作台移除自动质量与自动分辨率选项。旧值在显示、入队、保存和发送前解析为确定默认值：GPT 质量 `high`、按比例选择明确像素；Gemini 分辨率 `1K`；Grok 质量 `medium`、分辨率由所选尺寸映射。
- GPT 路由、GPT 直连生图、GPT 直连文本/视觉、Gemini、Grok 的 API 历史互相隔离，各自最多 20 条。旧版无归属历史仅归入 GPT 路由，不复制到所有入口。

### 配置区与生成日志

- 配置区统一为 `GPT / Gemini / Grok / 配色`。GPT 的路由/直连切换紧贴配置区下方，仅选中 GPT 时显示；切换到配色不会改变当前生图路线。
- 配置与日志在宽屏下使用均衡的独立列，窄屏调整为上下布局；压缩无效留白，对齐字段、模型控件和操作区，配置与日志各自滚动。
- Gemini 固定的 `images/generations` 后缀与 GPT、Grok 共用接口标题几何结构，不再伪装成可编辑的后缀。完整地址可通过提示信息和无障碍标签查看，请求逻辑及保存结构保持兼容。
- 精简并统一按钮、配置字段与日志文案；长内容使用单行省略和完整信息提示，避免撑宽或换行破坏布局。
- 配色区提供每行 4 个的 7 套简短色块，移除自定义颜色与花卉点缀，默认使用「靛蓝」。

### 既有工作流与文档

- 套图、写真、文章插图和 PPT 使用独立的思考等级与质量设置，计划、后台任务、补图、失败重试和 PPT 单页编辑保留有效参数。
- GPT 路由/直连提示词生图支持按任务保存透明 PNG 选择；新套图计划固定一个 SKU 主体，保留 SKU 生成规则选择。
- 中英文 README 同步更新配置教程、Grok 配置、环境变量、历史隔离、明确分辨率和工作流边界。已完成的本次 OpenSpec 变更归档，并合并回主规范。

## 升级说明

- 主应用每次更新仅递增一个补丁版本，即 `+0.0.1`。
- 既有配置、生成记录和图片资产无需手动迁移；旧的自动参数会解析为明确默认值，通道 API 历史按上述规则兼容旧数据。
- 升级前后均保留原有服务商连接配置；各通道 API Key 不互相覆盖。
- 商品图采集扩展使用独立版本线，本次主应用更新不会修改扩展版本。
