## Why

用户截图显示已选择 2.6，但找不到 GIF/SVG 操作；同时要求优化 SVG 位图缩略预览与原件下载的体验。实际代码中切换模型只刷新状态与质量，没有刷新格式和高级参数入口。用户本次优化请求授权以下明确范围。

## What Changes

- 修复路由 A/B 模型切换后的格式与 2.6 参数联动。
- 在提示词生图的开始按钮前显示 2.6 格式快捷入口，选 GIF 即可调整帧数/时长，选 SVG 显示矢量原件说明。参数与原有共享配置双向一致，提交时仍冻结快照。
- 在前端说明并拦截 GIF/SVG 的参考图、多候选、透明背景和未指定工具模型组合。
- 画廊、胶片条和详情优先使用 SVG 原件 URL，通过 img 安全展示，不内联注入 SVG；明确标注格式和原件下载。位图缩略服务继续保留给需要它的其他路径。
- 保留旧模型、其他工作流、已保存资源及现有页面布局，只增加局部入口。

## Capabilities

### Modified Capabilities

- gpt-image-26-support: 输出入口联动及 SVG 原件预览可发现性。

## Impact

现有 image-options-view、browser-image-cache、public/app.js、HTML/CSS、共享镜像及相关回归。不增加提供方 API 或真实收费调用。
