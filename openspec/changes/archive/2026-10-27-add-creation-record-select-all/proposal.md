# Why

套图记录已经支持逐条勾选，并将勾选集合用于批量删除和 Temu 导出。目前用户需要逐条点击复选框才能快速选择大量符合当前筛选条件的记录，分页中尚未显示的匹配记录也需要一并纳入选择。

# What Changes

- 在套图记录列表底部增加全选/取消全选按钮。
- 按当前搜索和时间筛选选择全部匹配记录，包括当前分页尚未显示的记录。
- 切换选择时保留筛选范围之外的既有勾选。

# Non-Goals

- 不改变筛选、分页、单条勾选、删除或 Temu 导出请求格式。
- 不自动删除或导出记录。

# Capabilities

### Modified Capabilities

- `creation-mode`: 套图记录按当前筛选结果全选或取消全选。
