## Context

Creation Mode 的角色 ID、历史计划和平台图片类型都已稳定，不能通过重命名内部键解决重复卖点；本次需要在提示词拼接边界内统一角色语义。图片详情当前由最终 CSS 覆盖为约 360–420px 检查器，且参数文本有较大最小高度，宽屏主图和窄屏可见信息都会被挤压。

## Goals / Non-Goals

**Goals:**

- 保留 `hero`、`benefit`、`atmosphere`、`effect-comparison` 及 `comparison-proof` 的兼容 ID。
- 让首图获得所有可靠的非尺寸商品事实和卖点事实，按角色预算输出到目标语言营销文案；尺寸/重量仍只由尺寸或参数图负责。
- 将 `benefit` 的可见标签改为“目标人群共鸣图”，定位为目标买家在决定性处境中的情绪/需求共鸣，避免卖点列表和参数卡。
- 让氛围图有具体触发动作、人物或环境线索与购买瞬间。
- 让功能图显式枚举全部可靠功能，允许同一主体周围的无损连续场景拼接作为容量兜底，并维持无对比禁令。
- 让图片详情桌面检查器默认约 300–340px，参数文本以内容区滚动为主；移动端保持图片优先。

**Non-Goals:**

- 不改生成 API、历史 manifest、文件名、SKU 语义或平台硬性白底/无文字主图约束。
- 不重绘已有图片，也不静默改写已保存提示词。
- 不让“目标人群共鸣图”承担尺寸、参数、库存、价格或未提供的社会证明。

## Decisions

1. **首图使用角色专属全量事实通道。** 在 `buildCreationRoleSourceFocus` 中为 `hero` 设置较高但有界的事实上限，并合并身份、可见文案、卖点、材质、场景、使用、包装和信任类别；显式排除尺寸类别。这样不会让普通角色都变成信息墙，也不会把精确尺寸泄漏到首图。
2. **用兼容 ID 承载新的共鸣角色。** `benefit` 继续作为首图后的第二槽位，但标题、brief、意图、场景和买家问题都改成“目标人群共鸣图”；`info-benefit` 等平台图片类型保持平台自身语义，不把历史平台槽位强行改名。
3. **把下单瞬间写入正向构图和反向禁令。** 氛围提示必须同时包含可见产品、具体使用/拥有动作、目标人群和购买触发情绪；加入“不得平淡静物陈列、不得只有装饰氛围”的测试锚点。
4. **功能事实先收集再拼接。** 为 `effect-comparison` 从描述、卖点和已应用参考笔记收集去重后的功能/机制/效果/使用事实，输出 `FUNCTION COVERAGE LOCK`。默认要求一个统一主体；当事实数量或长度超过单画面可读阈值，使用“同一主体的连续无损场景拼接”而非对比、重复主体或独立卡片。
5. **只缩窄检查器，不隐藏信息。** 将最终 lightbox 桌面列从 `minmax(360px,420px)` 调整到 `minmax(280px,340px)`，并把参数文本最小高度降至约 96–120px；文件名、路径仍在参数面板下方，面板自身继续滚动。移动断点仍为单列图片优先。
6. **验证采用源文件契约 + 浏览器证据。** 新增 planner/layout 断言，再同步 `public/lib` 镜像；以隔离端口打开本地工作台，在宽屏和窄屏检查主图占比、信息可读性与无横向溢出。

## Risks / Trade-offs

- [全量事实过多会让首图文字拥挤] → 只合并去重后的可靠非尺寸事实，设置有界上限，并要求清晰的信息层级而非逐字倾倒。
- [平台原生主图可能与首图规则冲突] → 保留平台 blocking policy 优先级；只有允许营销文字的角色才注入全量首图文案。
- [模型仍可能漏掉功能] → 在 prompt 中列出功能覆盖清单并要求逐项可见；无法同屏时使用同一主体连续拼接规则，测试锁定关键文本。
- [检查器过窄导致路径难读] → 保持中间截断/换行、滚动容器和文件名/路径字段；布局测试覆盖长路径与 390px 视口。

## Migration Plan

1. 补充 OpenSpec 增量规格与 planner/layout 回归测试。
2. 修改 canonical `lib`，执行 `npm run sync:public-lib` 更新浏览器镜像。
3. 在隔离端口启动本地服务，执行聚焦测试、完整测试、`openspec validate` 与浏览器截图检查。
4. 如需回滚，仅回退本次变更涉及的角色提示词与 lightbox 最终覆盖规则；不触碰其他脏工作区文件或运行中的服务。

## Open Questions

- 目标语言翻译由现有 target-language prompt 约束完成；本次不在本地硬编码各语言词典，以避免覆盖模型可读的商品事实。
