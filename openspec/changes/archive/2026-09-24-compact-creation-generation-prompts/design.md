## Context

Creation Mode 先生成每个图片角色的计划提示词，再由运行时组装比例、主体身份锁和目标语言边界，并为每张实际参考图追加标签。当前通用首图的系统文字在这些阶段重复表达视觉风格、商品主体身份、商品表面保护和新增文案语言；比例 helper 还会附加中文用途说明。上游 Responses 请求已将比例、分辨率、质量、格式和背景作为结构化字段发送。

工作区已有未提交的主体保护、目标语言和尺寸处理调整。本变更应在这些现有改动上压缩措辞，不回退或重写其他行为，并继续满足 `creation-mode` 已有的表面内容保护、参考图身份优先级和历史提示词运行时兜底要求。

## Goals / Non-Goals

**Goals:**

- 让控制指令以简洁英文描述画面、比例和参考图角色，不输出可避免的中文界面显示名。
- 合并规划阶段和运行时重复的主体、表面内容及语言要求。
- 减少主提示词和单张参考图标签的重复内容。
- 用固定示例检查重复指令已合并、默认界面标签与比例用途说明已移除，且核心画面语义完整保留；字符数只作前后对比，不设置字符目标或上限。
- 保留用户提供的商品事实原文、适用的平台硬约束、参考图角色证据、主体身份保护和目标语言要求。

**Non-Goals:**

- 不翻译用户输入，也不保证所有动态用户内容都只有拉丁字符。
- 不删去确有约束力的平台、品类、角色或参考图说明。
- 不改变商品或包装原有图案、标记、表面文字及其语言，也不改变角色、构图、场景和平台约束的画面含义。
- 不改动上游请求参数、任务数量、规划结果或专用信息图重构路径。

## Decisions

### 只压缩系统生成的控制文字

商品名称、描述、卖点、尺寸事实和参考图备注属于用户提供的事实，按原文进入提示词；系统生成的 UI 标签、类别名称和说明则使用精简英文或直接省略。即使目标语言为英语，也不因提示词压缩而猜测或翻译商品事实。

### 比例只传递比例值

Creation Mode 使用独立的简短比例后缀，例如 `Aspect ratio: 1:1.`。不把比例选项的用途标签或重复构图指令拼进提示词；精确尺寸和比例仍由现有 API 工具参数分别传递。其他功能继续使用共享比例 helper。

### 合并主体和文案边界

保留一条完整但紧凑的商品身份与表面内容规则，并为新增画布文案保留一条目标语言规则。商品或包装原有图案、标记、表面文字及其语言保持不变。规划器生成的提示词如果已包含这些语义，运行时不再重复追加；历史冻结提示词仍由运行时补足缺失约束。SKU、参考图主锚点和辅助图角色需要的差异化事实继续保留。

套图提示词不设置字符数上限。规划与运行时拼接不得为了满足总长度而删除段落或截断内容；只合并重复控制语句，按图片角色选取相关事实。

### 省略通用规划标签

默认通用平台、默认通用品类和 UI 风格名称不单独作为模型指令。若某个选择包含实际生成约束，则只保留简洁、可执行的英文约束文本；不可丢失平台限制或经用户选择的品类专属指导。

### 参考图标签只绑定图与角色

每条标签继续按附件顺序标识文件与分配角色，并保留该角色的具体说明/备注。主体锚点的身份规则只出现一次；不在标签中重复写两种近义的“identity authority”和“subject anchor”段落。支撑参考图仍明确仅提供其分配角色的证据。

### 通过生成样例验证压缩和语义

对 `universal:generic-hero`、英文目标语言、1:1、1K、商品参考图的固定样例检查比例后缀不含用途文本，且主体身份、主体内容与目标语言约束没有在规划和运行时重复附加。回归还检查商品事实、参考图角色、构图与场景指导、有效平台硬约束和历史提示词兜底继续存在。字符数只用于确认压缩是否有效，不设字符目标或上限。`infographic-rebuild` 保持独立。

固定 18 图、8 张参考图的通用首图样例实测为：规划首图提示词 1,920 字符，最终运行时提示词 2,041 字符，逐图提示词与该图实际参考标签合计为 1,206 至 2,908 字符。这些是样例观察值，不是提示词长度目标或上限。

## Risks / Trade-offs

- 删除重复措辞可能降低一部分冗余强化；主体身份、表面内容、参考图角色和新增文案语言边界必须各有一条明确规则。
- 用户输入原文可能含中文。保留这些字符是为了不猜测翻译和篡改商品事实；本变更只保证系统生成的控制性文字使用简洁英文。
- 非通用平台或类别指令如包含实际硬约束，必须保留其要求；精简不能通过截断商品事实或改变画面含义完成。

## Migration Plan

1. 更新 Creation Mode planner 与 runtime 的系统提示词拼接，并精简 Creation reference labels。
2. 添加固定样例的比例后缀、标签及关键语义回归断言，并记录前后字符数作参考。
3. 运行受影响测试、完整测试、公共模块同步检查、OpenSpec 严格校验和差异检查。

无需数据或 API 迁移；已有已保存提示词继续由当前运行时兼容处理。
