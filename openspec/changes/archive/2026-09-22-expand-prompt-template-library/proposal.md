## Why

Prompt Kit 目前只显示一列模板名称和编辑表单，无法像提示词探索站点一样按主题浏览、快速比较和查看视觉参考。模板数量增加后，用户需要先找到分类，再在瀑布流、列表或图片视图中选择合适的提示词；现有的应用、编辑、删除和 Prompt Agent 历史也必须继续可用。

参考站点在当前开发环境无法稳定访问，因此本次将参考其一级/二级分类浏览方式，制作一次性静态快照。模板和缩略图随应用发布，运行时不依赖第三方站点，也不会把整套目录写入用户的 localStorage。

## What Changes

- 新增静态提示词模板目录，使用一级分类、二级分类和模板条目三级结构；每个二级分类提供十条可直接复用的提示词，并带有离线可用的预览缩略图。
- 将模板库弹层扩展为可搜索、可筛选的浏览面板，默认使用瀑布流视图，并支持列表视图和图片视图。
- 列表视图显示左侧缩略图、右侧可换行提示词和应用按钮，并提供字号调节；图片视图隐藏提示词，在悬停或聚焦时显示模板名称与应用操作。
- 所有目录图片支持点击放大，在现有图片查看器中同时显示完整提示词并可复制；目录条目也支持直接应用到提示词输入框。
- 保留现有用户模板、默认模板、编辑、删除、新建、插入和 Prompt Agent 历史同步；目录模板为只读快照，可复制到用户模板后再编辑。
- 为桌面、平板和手机布局增加响应式分类导航、视图切换和文本换行规则。

## Capabilities

### Modified Capabilities

- `image-to-prompt`：增加分层模板目录、视图切换、预览放大和目录模板应用契约。
- `workbench-usability-foundation`：增加模板库在多设备上的可扫描布局、字号调节和可访问交互契约。

## Impact

- 新增 `lib/prompt-template-library.mjs` 及 `public/lib` 镜像和同步清单条目。
- 修改 `public/app.js`、`public/index.html`、`public/styles.css` 和模板相关回归测试。
- 不改变生成请求协议、模板存储键或服务端 API；目录数据不会写入用户模板存储。

## Non-Goals

- 不在应用运行时抓取或代理第三方站点，不保证外站内容实时同步。
- 不把目录中的预览图当作用户生成资产保存到图库。
- 不改变现有用户模板和 Prompt Agent 历史的删除、迁移与持久化规则。
