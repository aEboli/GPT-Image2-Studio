## Context

共享加载壳已覆盖提示词主预览、套图卡片、胶片条和多个专项生成入口。其 DOM 同时创建 `drop`、`wave`、百分比、状态和心跳图标；其中水位填充与气泡造成截图中底部的水流。现有背景光雾由加载壳伪元素绘制，图标池已有 20 个图标，但初始化索引固定为第 0 项星形。

## Goals / Non-Goals

**Goals:**

- 让所有共享加载位置只呈现一个连续、低干扰的动态模糊背景。
- 保留进度时序、状态色相、可访问性语义、等待态和加载壳复用。
- 使每个新加载壳的初始图标随机且可在测试中稳定注入随机值。

**Non-Goals:**

- 不改变上游 heartbeat 事件、进度估算算法、图标池内容或图标的后续不重复轮换规则。
- 不给每个生成入口建立专属动画，也不增加新的第三方依赖。

## Decisions

### 用伪元素绘制动态模糊背景

移除 `drop` 和 `wave` DOM，使用加载壳的 `::before` 绘制全幅、软边的叠层光带，并以缓慢的 `transform` 和透明度变化制造连续动态。`::after` 保留中心可读性遮罩，文字和图标仍位于更高层。这样没有水位、气泡或横向液面，同时不再维护无视觉用途的水层节点。

选择单个伪元素而不是额外动画节点，以保持共享壳的 DOM 更小，也避免小尺寸缩略图出现独立的动效布局。背景只使用柔和的线性光带而非可辨认的颗粒或图案，减少视觉噪声。

### 保留阶段色相与进度深浅

现有 `--generation-loading-fluid` 仍由真实请求阶段和百分比推导，改为为模糊背景取色。保留其插值过渡可在不引入水体的前提下让背景颜色自然地随任务推进变化。

### 在图标构造时选择随机初始索引

`startIndex` 继续支持明确传入，方便测试和调试；未传入有效索引时使用同一注入式随机函数从完整图标池选择初始项。加载壳按 `loadingKey` 复用，因此一次任务内不会因重渲染重新抽取；后续 heartbeat 继续使用既有“排除当前项”的选择器。

## Risks / Trade-offs

- [模糊层在大画布上频繁重绘] → 只保留一个背景伪元素、拉长动画周期，并使用 transform/opacity 而不是水层、气泡等多层背景位置动画。
- [移除水层影响共享壳断言] → 先更新针对 DOM 与样式的回归测试，保留进度、等待态、清理和复用测试。
- [随机测试不稳定] → 构造函数接受固定随机函数，测试断言确定的非星形初始索引。

## Migration Plan

1. 更新加载规范和回归测试。
2. 更新共享模块与样式，并通过同步脚本生成浏览器副本。
3. 跑定向及全量测试、严格 OpenSpec 校验和浏览器视觉检查。
4. 归档变更，由 OpenSpec 将增量规范合并回主规范。
