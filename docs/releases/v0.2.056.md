# GPT-Image2-Studio v0.2.056

`v0.2.056` 将主应用版本从 `0.2.046` 更新到 `0.2.056`。

## 更新内容

- 强化图片转提示词的风格锁定，并修复桌面配置持久化、提供方凭据隔离与并发记录问题

## 版本规则

- 小功能更新：更新位 +10。
- 版本格式为 `major.minor.patch`，patch 固定三位数字；上级版本变化时，下级版本归零。

## 升级说明

- 既有配置、生成记录和图片资产不需要迁移。
- 商品图采集扩展使用独立版本线，本次主应用更新不会修改扩展版本。
