## Why

用户要求为生成的 Listing 标题补充截图中的西班牙语、法语、意大利语和波兰语，并限定其他部分不变。当前标题与其他字段均支持英文、德文和简体中文，需要仅扩展标题的语言覆盖。

范围已由用户于 2026-11-11 确认：后续消息“除了标签其他不变”中的“标签”指上一条请求的“标题”，仅扩展标题语言。

## What Changes

- 仅为标题新增西班牙语（`es`）、法语（`fr`）、意大利语（`it`）和波兰语（`pl`）译文，使用独立的 `titleTranslations` 对象保存四个字符串；不扩展为四种语言的完整 Listing。
- 所有现有 Listing 生成入口在原请求中一并请求这四种标题译文，保持英文顶层标题、德文 `deDisplay.title` 和中文 `zhDisplay.title` 的既有位置与含义。
- 标题沿用现有纵向展示方式，语言顺序为英文、德文、西班牙语、法语、意大利语、波兰语、简体中文；缺失的译文直接省略。
- 新增标题译文沿用已有的独立复制和字符统计能力，并进入复制全部和 JSON 导出；保存、读取及归一化保留重音字符和波兰语特殊字符。
- 译文遵守原有标题的事实、数量、品牌、内部编号、尺寸规格和宣称限制，不新增产品事实，不改变平台或目标市场。
- 其他字段、现有英德中译文、字段顺序、页面布局、生成调度和导出工作台映射保持原样；不新增语言选择器、复选框或整段辅助文案。
- 历史草稿不自动调用模型、不伪造四语标题；用户明确重新生成后采用新契约。

## Capabilities

### New Capabilities

- 无。

### Modified Capabilities

- `creation-listing-agent`：仅为标题生成并保存四种新增语言译文。
- `creation-mode`：仅在标题字段扩展展示、复制、字符统计及结构化导出。

## Impact

- `lib/creation-listing-agent.mjs`：生成提示词、结构化 schema 和现有契约兼容链路。
- `lib/creation-listing-draft.mjs`、必要的 Listing 内容清理位置：标题译文归一化及既有标题限制。
- `lib/creation-listing-view.mjs` 与必要的 `public/lib` 对应副本：标题展示、复制及 JSON 导出；复用现有样式。
- Listing 生成、保存读取、历史兼容和视图回归测试。
- 用户已确认本提案；当前工作区已有的其他修改不纳入本次变更。
