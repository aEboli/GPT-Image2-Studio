## Context

模板预览复用通用图片详情灯箱，并通过 `isPromptTemplateLibraryItem` 标记来源。模板库弹层仍保留在灯箱下方，因此返回动作不应关闭父弹层。

## Decisions

1. 复用现有灯箱，不新增第二套图片预览组件。
2. 仅对模板库预览显示“关闭”和“应用”，避免普通图片详情出现重复操作。
3. “关闭”清理灯箱和模板库，并将焦点交还模板库入口；“应用”沿用模板库现有应用函数，将焦点交给主提示词输入框。
4. “复制”继续复制原始提示词，不受新增应用动作影响。

## Verification

- 静态契约测试确认模板预览详情包含返回/关闭/复制/应用控件。
- 静态契约测试确认关闭与应用路径分别调用父弹层关闭和模板应用逻辑。
