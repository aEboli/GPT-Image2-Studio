## Why

套图记录已经积累到数百套，目前只能按文本搜索，用户无法快速定位今天、最近一周、更早或某个具体日期创建的记录。时间筛选还必须与现有搜索、详情选择和“删除筛选结果”共享同一目标集合，避免界面显示与批量操作范围不一致。

## What Changes

- 在套图记录页增加“全部、今天、近 7 天、更早”快捷时间筛选和精确日期输入。
- 时间筛选按 manifest 的 `createdAt` 和浏览器本地自然日计算，并与关键词搜索叠加。
- 记录计数、空状态、默认详情、最多显示 60 条的列表和按筛选删除均使用完整组合筛选结果。
- “删除筛选结果”在关键词或显式时间筛选至少一个非默认时可用；空关键词加“全部时间”仍不能隐式删除全部。
- 增加清空筛选操作，并补齐桌面、平板和手机布局及无障碍状态。

## Capabilities

### New Capabilities

- 无。

### Modified Capabilities

- `creation-mode`: 套图记录支持按创建时间筛选，并让筛选删除遵循当前完整组合筛选集合。

## Impact

- 浏览器：套图记录筛选状态、时间选项渲染、搜索组合、计数、选择和删除确认文案。
- 共享模块：新增可独立测试的 Creation record 本地日期筛选函数，并同步到 `public/lib`。
- UI：套图记录上下文栏新增快捷时间选项、日期输入和清空筛选按钮。
- 测试与文档：增加日期边界、组合筛选、筛选删除和响应式静态回归，更新 README 能力说明。
- API 与存储：无变更。
