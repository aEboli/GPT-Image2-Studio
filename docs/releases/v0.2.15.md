# GPT-Image2-Studio v0.2.15

`v0.2.15` 将主应用版本从 `0.2.14` 更新到 `0.2.15`。

## 更新内容

- 重调中国传统色配色：夜场抬到暗蓝、点缀统一降彩度，描边与控件轮廓补到 WCAG 下限，修正点缀填色上的浅底浅字

## 升级说明

- 主应用每次更新仅递增一个补丁版本，即 `+0.0.1`。
- 既有配置、生成记录和图片资产不需要迁移。
- 商品图采集扩展使用独立版本线，本次主应用更新不会修改扩展版本。

## 验证

- 发布前需运行项目测试、构建、发行一致性检查和 OpenSpec 严格校验；实际结果以本次发布交付记录为准。
