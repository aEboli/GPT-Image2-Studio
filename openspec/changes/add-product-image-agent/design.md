# Design

## Analysis contract

`product-image-agent` 是图片裂变工作台使用的 Prompt Agent 模式。它使用默认文本视觉配置，不跟随路由 C 的图像协议模型。输出包含商品事实、痛点、卖点、受众、场景、风险和 3–6 张基础图片计划。每张计划包含引用图序号、画幅、`prompt_en`、`prompt_zh`、`avoid_en` 和 `avoid_zh`。

## Browser flow

图片裂变工作台在浏览器内维护母图、空间/途径/内容方向选择和分析结果。选择项会形成空间 × 途径 × 内容方向的任务矩阵；用户可以复制单格指令、逐格生成、顺序生成未完成任务或重做已有结果。生成请求使用基础计划指定的参考图，并直接调用现有图片生成 SSE 流；生成结果保留为当前会话中的预览和下载链接。

## Safety and fidelity

分析提示词要求只使用图片或用户上下文可确认的事实，禁止编造品牌、性能和文字。英文提示词必须不包含中文或其他非拉丁文字；中文只作为对照展示。
