# GPT-Image2-Studio v0.2.066

`v0.2.066` 将主应用版本从 `0.2.056` 更新到 `0.2.066`。

## 更新内容

- API 历史按通道保存并恢复最后一次保存的模型，路由模式也会恢复生图工具模型；未保存的模型编辑不会覆盖历史记录。
- 当前生图参数摘要与图片详情显示请求发起 IP，并将 IP 保存到生成记录；旧记录缺少该值时显示“未记录”。
- 修复 Vercel Serverless 初始化：忽略平台注入的 `HOST`，避免把云端函数当作本地 HTTP 服务绑定端口。

## 版本规则

- 小功能更新：更新位 +10。
- 版本格式为 `major.minor.patch`，patch 固定三位数字；上级版本变化时，下级版本归零。

## 升级说明

- 既有配置、生成记录和图片资产不需要迁移。
- 商品图采集扩展使用独立版本线，本次主应用更新不会修改扩展版本。
