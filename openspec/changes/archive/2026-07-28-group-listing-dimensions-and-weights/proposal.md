# Change: 合并 Listing 尺寸与重量展示

## Why

Listing 底部当前依次显示包装尺寸、产品尺寸、包装重量和产品重量，包装信息与产品信息被拆散，阅读时需要来回对应。

## What Changes

- 将页面中的四个独立展示段合并为“包装尺寸和重量”与“产品尺寸和重量”两个规格块。
- 每个规格块内部固定先显示尺寸、后显示重量，并保留英文与简体中文独立复制能力。
- “复制全部”使用相同的两个组合规格块。
- 结构化 JSON 继续保留四个独立字段，避免破坏现有数据契约和历史 Listing。

## Capabilities

### Modified Capabilities

- `creation-listing-agent`: Listing 规格字段的展示、全文复制和结构化导出边界。

## Impact

- 受影响代码：Listing 视图、全文复制和 V2 结构化导出字段排列。
- 不修改重量或尺寸的提取、估计、单位换算和历史回读逻辑。
