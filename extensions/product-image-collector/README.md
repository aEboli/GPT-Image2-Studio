# GPT-Image2-Studio 商品图采集插件

## 安装

1. 解压下载的 ZIP 文件，保持目录结构不变。
2. 在 Chrome 或 Edge 地址栏打开扩展管理页，并开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择解压后的目录。
4. 刷新已打开的 1688 商品详情页，页面右侧会自动出现 `G2 商品图` 悬浮入口；点击入口即可打开采集窗，也可以继续使用扩展图标打开。

Chrome 和 Edge 会要求用户确认本地扩展安装。本插件不会修改注册表，也不会尝试静默安装。

## 使用

- “复制到 Studio”会把选中图片写成版本化文本清单，不会复制 Cookie、密码或图片二进制。
- “下载所选”只保存图片，不会下载或打开 JSON 文件。目录格式为 `GPT-Image2-Studio/YYMMDD/商品ID-标题/`，例如 2026-07-27 使用 `260727`。
- 主图按 `主图-1`、`主图-2` 命名，详情图按 `详情图-1`、`详情图-2` 命名，SKU 图按 `SKU-1-规格名` 命名；共用一张图片的多个规格会合并到同一受限长度文件名。
- 选择区支持全选、反选、只选主图、只选详情图和只选 SKU 图。
- 插件优先读取 1688 页面声明的主图、SKU 规格和公开详情描述，并以已知商品区域作为兼容回退；页面结构不受支持时不会扫描整页图片。
- 多个 SKU 规格使用同一张图片时只保留一张独立图片，并在卡片上显示该图片覆盖的规格数量和名称。
- 悬浮窗可以拖动；拖到页面左侧或右侧边缘后会自动隐藏成窄条，移入或点击窄条即可展开。
- 关闭采集窗后，页面右侧的 `G2 商品图` 悬浮入口会重新出现；入口本身不会读取或采集页面图片。
