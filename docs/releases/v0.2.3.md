# GPT-Image2-Studio v0.2.3

`v0.2.3` 首次正式提供独立 Windows 桌面应用，并集中完善 Creation 记录管理、平台化冻结计划、信息图重构与 Listing 交付可靠性。桌面版、浏览器版、本地服务和 Cloudflare Worker 继续复用同一套工作台与数据格式。

## 版本亮点

- **独立 Windows 桌面应用**：新增 Electron 43 + NSIS 桌面版，具备独立窗口、任务栏身份、单实例、动态回环端口、安装/卸载和窗口关闭后的服务回收。桌面窗口只允许工作台回环地址，外部链接交给系统浏览器处理。
- **记录与资产删除工作流**：Creation 记录支持删除当前、删除选中和删除筛选结果，并增加“今天 / 近 7 天 / 更早 / 指定日期”筛选。瀑布画廊、文章插图、写真和 PPT 记录也支持当前或批量删除；删除目标经过路径边界校验，成功后在原页面更新并保留筛选与滚动上下文。
- **平台受众与转化计划真正冻结**：通用电商和 18 个平台使用结构化营销语境，参考分析可生成非敏感、证据可追溯的 `audienceStrategy`，每张图获得确定性的 `conversionIntent`。浏览器会提交完整 `effectivePlan`，Local 与 Worker 重新校验条目、大小和平台硬规则后执行，队列、记录和修复不再因表单或策略变化而漂移。
- **更可靠的商品图规划**：参数规格图改为最多突出 4 个与购买决策相关的关键规格，避免退化为密集表格；到手清单改为拆包平铺全部已确认物品。SKU 标签可保留主体、镜片、带子、框架等可靠可见部件的完整特征颜色，不再丢弃共有的中性色。
- **Source-only 信息图重构**：新任务默认关闭，启用后为每张非主体参考图追加独立重构项。每项只发送对应原图，不混入主体图、Logo、平台、商品或受众上下文；结果保留可验证事实并显著重做信息架构，同时遵循所选目标语言、比例、分辨率和输出格式。Local、Worker 与修复路径使用同一运行时规则。
- **Listing 更贴近买家决策且保持证据边界**：卖点、痛点、五点和描述可表达有证据支持的用途与价值；证据充足且平台允许时，英文标题提示目标至少 120 字符。七个字段固定在同一页面连续显示，英文后紧接简体中文，并保留两种语言的独立复制与完整双语导出。

## 修复与行为变化

- Platform V1 会自动移除模型输出中缺少依据的低风险属性、材质、颜色、结构或场景词；解析失败、双语主体缺失或高风险声明仍明确失败。
- **Listing 失败行为变更**：真实模型请求、解析或内容验收失败时不再保存 mock 或确定性兜底草稿。重新生成失败会保留已有 Listing，并向页面返回可读错误；显式 `mock: true` 只用于测试。
- Listing 展示不再提供“商品文案 / 搜索优化”或“英文 / 中文 / 对照”切换，最终界面统一为七字段、英中上下连续阅读。
- 标题长度、Bullet 标签、痛点句式、双语数组数量或关键词桶为空等非关键格式差异不再单独使可用 Listing 失败；平台硬上限、事实支持和高风险安全边界继续优先。
- Creation 正式生成会优先执行服务端复验后的冻结计划，客户端的 `canGenerate`、计数和验证结果不再被直接信任；旧客户端缺少 `effectivePlan` 时仍兼容重新规划。

## 升级说明

- 版本号由 `0.2.2` 升级到 `0.2.3`，Git tag 为 `v0.2.3`。
- 推荐 Windows 用户使用独立窗口桌面版 `GPT-Image2-Studio-Desktop-Setup-v0.2.3-x64.exe`；需要原有浏览器启动方式时使用兼容版 `GPT-Image2-Studio-Setup-v0.2.3.exe`。
- 两种安装包均未进行代码签名。首次运行时 Windows 可能显示来源或 SmartScreen 提示，请先核对下方 SHA-256。
- 现有 Creation、Listing 和资产记录无需迁移；历史 Listing 继续兼容显示、复制和导出。
- 源码服务仍要求 Node.js 20 或更高版本；桌面开发和安装包构建要求 Node.js 22.12 或更高版本。Cloudflare Pages 部署需基于本版本重新构建并发布 `dist/`。
