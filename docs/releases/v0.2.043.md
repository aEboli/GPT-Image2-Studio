# GPT-Image2-Studio v0.2.043

`v0.2.043` 将主应用版本从 `0.2.033` 更新到 `0.2.043`。

## 更新内容

- 新增 YouMind GPT Image 2 Prompt Kit 快照与三维模板库、图片裂变工作台、路由生图工具模型开关、生成队列与加载恢复体验，并同步 Windows 启动器、COS 人像参考资源和商品详情合并输入。

## 版本规则

- 小功能更新：更新位 +10。
- 版本格式为 `major.minor.patch`，patch 固定三位数字；上级版本变化时，下级版本归零。

## 升级说明

- 既有配置、生成记录和图片资产不需要迁移。
- 商品图采集扩展使用独立版本线，本次主应用更新不会修改扩展版本。
