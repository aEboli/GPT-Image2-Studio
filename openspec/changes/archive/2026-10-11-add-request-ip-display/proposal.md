# 在图片参数中显示请求发起 IP

## Why

图片详情和当前生图参数摘要只能看到调用模式、模型与中转地址，无法确认这次请求是从哪个客户端地址发起的。历史图片也需要保留生成时的地址，避免详情页只显示当前访问者地址。

## What Changes

- 服务端为当前配置响应提供请求发起 IP，并在左侧参数摘要的最底部显示。
- 标准生图任务将请求发起 IP 保存到 Gallery 元数据、任务结果和图片详情参数中。
- 旧记录没有该字段时显示“未记录”，不根据当前请求补写历史数据。

## Affected Specifications

- `lightbox-image-viewer`
- `runtime-configuration`
