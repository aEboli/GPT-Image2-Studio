## Why

Creation infographic rebuilds can add attractive but unsupported labels when the model interprets product appearance as evidence for a feature. The source image must remain the complete information authority even when the layout and visual design change.

## What Changes

- Define the source infographic as a closed inventory for all output text, numeric facts, icons, callouts, badges, and their relationships.
- Require every rebuilt information element to map to a source element with the same meaning and scope.
- Clarify that product appearance alone identifies the product but does not substantiate a written feature or benefit; unreadable source text is omitted.
- Keep the single-source input boundary and the existing target-language and output controls.

## Capabilities

### Modified Capabilities

- `creation-infographic-rebuild`: make source-to-output content mapping explicit and disallow appearance-based feature inference.

## Impact

- Updates the canonical runtime prompt and its focused regression coverage.
- No changes to reference selection, API parameters, saved records, or other Creation image roles.
