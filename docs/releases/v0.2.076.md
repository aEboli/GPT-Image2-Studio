# GPT-Image2-Studio v0.2.076

`v0.2.076` 将主应用版本从 `0.2.075` 更新到 `0.2.076`。本次 GitHub 更新还包含先前留在本地 `v0.2.075` 提交中的成对商品计数改进。

## 更新内容

### 商品事实与参考图

- 智能识别同时整理商品外观锁定点、带来源的事实、买点、痛点、使用场景、未知项和冲突项；场景建议不会自动升级为性能参数或商品承诺。
- 多张参考图中的互补事实会分别保留。只有同一商品、同一属性、相同条件下的互斥值才作为冲突；无法确认的对应关系作为待确认信息，不丢弃独立可读事实。
- 用户指定的主主体始终优先。事实来源随计划预览、队列、生成、补图和记录保存；旧记录缺少分析字段时仍可读取。

### 电商套图规划

- 先为整套图分配任务、事实来源和表达形式，再生成逐图提示词；按核心操作识别重复场景，不循环候选来凑图，资料不足时显示缺口。
- 资料充分时，6–10 张自动轮播至少安排 2 项不同的信息任务，12–18 张至少安排 3 项。卖点、参数、尺寸、可见结构与有依据的步骤分别匹配自己的事实和版式。
- 按类目去重槽位角色，保留足量计划中的首图、尺寸、信息图、细节、场景和多角度任务；真人角色数量随类目调整，画面形式按商品稳定选择。
- 多 SKU 对比图要求至少两个有来源的可售变体；尺寸与参数图要求可解析数值。证据不足时跳过对应图片，服务端在生成与补图前重新校验冻结计划。
- 画布文字过滤无依据的医疗、安全、认证、价格和绝对化宣称，同时保留安全帽、医用口罩等品类词。

### 信息图与 SKU

- 信息图重构只以源图中可读内容作为文字、数值、图标和关系的依据；商品外观不能单独证明功能。来源明确支持直接且唯一关系的推导可保留，推导数值须标为估算并保守取整。
- 成对售卖商品按完整可售单位计数：一双手套算一个 SKU 主体，左右颜色合并为一条颜色标签；彼此独立单卖的商品仍按件计数。

### 平台兼容

- 套图自动画像收敛为通用电商 18 槽方案，默认分辨率档位为 `1K`。未知及已退役的平台 ID 回落到通用画像；Listing 草稿平台策略仍由独立策略表维护。

## 升级说明

- 既有配置、生成记录和图片资产不需要迁移；历史冻结计划及已保存提示词保持可读，新规划规则作用于新计划。
- 商品图采集扩展使用独立版本线，本次主应用更新不会修改扩展版本。
