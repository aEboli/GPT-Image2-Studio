# GPT-Image2-Studio v0.2.033

`v0.2.033` 将主应用版本从 `0.2.023` 更新到 `0.2.033`。

## 更新内容

- 新增图片裂变工作台：最多上传 15 张商品母图，使用默认文本/视觉模型提炼可确认的商品事实、痛点、卖点、目标人群和使用场景；无法由图片确认的内容会进入风险列表供人工复核。
- 新增“用途 × 渠道 × 方向”路由任务板。每个任务保留来源母图、画幅比例、纯英文生图提示词和简体中文对照，支持逐格生成、重做、复制指令、下载和未完成任务批量生成。
- 新增 `product-image-agent` 结构化 JSON 协议，分析使用默认文本模型配置，生成仍复用现有 `/api/generate` 图片接口。
- 新增按模板稳定生成的 Prompt Kit 本地预览资源，并修正预览文件名扩展名判断。
- 图片编辑提示词会在保留用户其他要求的前提下规范英文目标语句；Creation 普通轮播图和 SKU 提示词压缩重复控制文字，同时保留商品事实、参考图角色、平台约束、主体身份、表面内容和目标语言边界。

## 版本规则

- 小功能更新：更新位 +10。
- 版本格式为 `major.minor.patch`，patch 固定三位数字；上级版本变化时，下级版本归零。

## 升级说明

- 既有配置、生成记录和图片资产不需要迁移。
- 商品图采集扩展使用独立版本线，本次主应用更新不会修改扩展版本。
