# GPT-Image2-Studio v0.2.023

`v0.2.023` 将主应用版本从 `0.2.022` 更新到 `0.2.023`。

## 更新内容

- 修复 Prompt Kit 模板库列表与图片视图的图片比例和网格布局，保持 YouMind 图片与提示词配对

## 版本规则

- 普通更新：更新位 +1。
- 版本格式为 `major.minor.patch`，patch 固定三位数字；上级版本变化时，下级版本归零。

## 升级说明

- 既有配置、生成记录和图片资产不需要迁移。
- 商品图采集扩展使用独立版本线，本次主应用更新不会修改扩展版本。
