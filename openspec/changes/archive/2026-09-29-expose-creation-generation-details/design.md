# 设计

## 现状

套图服务端已将实际请求提示词写入 `generationPrompt`，并把路由、模型、分辨率、格式、质量、思考等级和参考图写入逐图快照。套图工作区的结果预览却将提示词置空并启用 image-only 模式。

## 决策

- 标准套图结果复用记录灯箱构造器，以 `generationPrompt` 为首选提示词，并继续使用已有的规划提示词作为旧记录回退。
- Creation 记录灯箱参数使用严格快照模式，缺失值显示“未记录”，不从当前配置推断。
- Logo 批处理保持现有纯图片预览。
- 不更改生成 API、持久化格式或单套提示词 TXT 导出内容。

## 验证

- 回归断言覆盖标准套图结果使用记录灯箱、严格快照参数和 Logo 批处理例外。
- 运行套图灯箱、记录灯箱与 Creation 工作区相关测试，以及 OpenSpec 和差异检查。
