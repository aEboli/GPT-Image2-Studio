# GPT-Image2-Studio v0.2.5

`v0.2.5` 增加了从套图记录生成 Temu 标准 Excel 的本地工作流，并继续完善 Creation、Listing、SKU 标签、记录导出和发布维护契约。

## 版本亮点

- **套图记录导出 Temu Excel**：可勾选一套或多套 Creation 记录，每个 SKU 独占一行，按已保存商品事实和 Listing 写入项目内置标准模板；稳定保留套图与 SKU 顺序。
- **图片链接与 Cloudinary unsigned upload**：已有公网 HTTPS 图片直接复用；本地图片可在 Node.js 或 Windows 桌面程序中使用 Cloudinary unsigned upload 获取 `secure_url`。请求会拒绝本地路径、私网地址、凭据 URL、签名和 Secret 字段，并使用受限缓存和重试。
- **事实边界与导出问题**：缺少 Listing、价格、尺寸、重量、库存、产地或公网图片时保留空单元格，并在“导出问题”工作表记录 set、SKU、行、字段和待处理原因，不猜测或伪造商品事实。
- **Creation 与 Listing 兼容性**：兼容读取历史记录、接受已解析 Listing 草稿、收紧 SKU 颜色标签与套图生成规则，保留既有记录字段来源边界。
- **发布依赖维护**：生产链上的 `brace-expansion` 锁定到 `1.1.18`，消除本次审计发现的高风险 DoS 依赖版本。

## 修复与行为变化

- Temu 导出仅复用明确保存的商品与 SKU 事实，不从文件名、图片、提示词或模型响应发明 SKU；没有 SKU 时生成可定位的待补全行。
- 工作簿沿用版本化模板，回读检查模板身份、sheet、写入行数、数据类型、公式和问题 sheet；文本写入会处理公式前缀、XML 控制字符、无效 Unicode 和 32767 字符边界。
- 图片解析限制在受信输出根目录与明确 manifest item，公网 URL 只接受可访问的 HTTPS 资源；Cloudinary 配置只允许 `cloudName` 与 `uploadPreset`，不会持久化 API Key、API Secret、签名、Authorization 或 Cookie。
- 浏览器界面复用 `recordCheckedSetIds`，下载成功后保持当前详情、筛选、勾选和滚动状态；Cloudflare Worker 明确返回本地能力不支持，不生成假工作簿。

## 升级说明

- 版本号由 `0.2.4` 升级到 `0.2.5`，Git tag 为 `v0.2.5`。
- 现有配置、Creation、Listing、图片和其他资产记录无需迁移。
- 推荐 Windows 用户使用独立窗口桌面版 `GPT-Image2-Studio-Desktop-Setup-v0.2.5-x64.exe`；需要浏览器启动方式时使用兼容版 `GPT-Image2-Studio-Setup-v0.2.5.exe`。
- Temu Excel 只在本地 Node.js 或 Windows 桌面程序中可用，不会登录、导入或发布到 Temu。上传前仍需人工核对模板与 Temu 实际校验结果；本次发布不代表 Temu 平台导入验收。
- Windows 安装包未进行代码签名，首次运行时可能显示来源或 SmartScreen 提示，请先核对 SHA-256。
- 商品图采集器仍为已发布的 `v1.1.29`，本次源码未改变，因此不重复附加旧 ZIP。
