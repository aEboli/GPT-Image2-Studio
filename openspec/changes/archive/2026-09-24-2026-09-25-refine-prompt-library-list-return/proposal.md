# refine-prompt-library-list-return

## Why

模板库列表中的长提示词会把卡片撑高，导致文字区域与图片上下不齐；预览页左侧的返回操作也需要明确回到原模板库位置，避免被误认为关闭整个模板库。

## What Changes

- 列表卡片根据预览图的真实宽高比计算固定高度。
- 提示词区域限制在图片同高的内容区内，超出部分显示多行省略号。
- “返回模板库”只关闭当前灯箱，恢复模板库弹层、分类和滚动位置；右上角“关闭”继续关闭模板库。

## Impact

- `public/app.js` 增加列表卡片尺寸计算和模板库返回状态恢复。
- `public/styles.css` 调整列表视图图片、内容和多行文本裁切规则。
- `test/prompt-template-library.test.mjs` 增加返回绑定和布局契约检查。
