## Why

套图模式的参考图智能识别目前只发送一次请求。上游暂时失败、返回非 2xx 或返回空识别结果时，用户必须手动再次点击识别，套图创建流程会被中断。

## What Changes

- 套图参考图识别失败后自动重试最多 3 次。
- HTTP 错误、请求异常和空的参考图识别结果都视为失败并进入重试。
- 任一次重试得到有效识别结果后立即停止，并继续现有结果应用流程。
- 3 次重试仍失败时保留最后一次错误，继续使用现有失败反馈。
- 请求被取消或参考图快照已变化时，旧请求不得继续应用结果。

## Non-Goals

- 不改变服务端识别提示词、模型、图片上传上限或结果结构。
- 不改变套图生成、补图和其他模式的重试策略。

## Capabilities

### Modified Capabilities

- `creation-mode`: 套图参考图识别失败后的客户端自动恢复行为。

## Impact

- 修改 `public/app.js` 的套图参考图识别请求循环。
- 更新浏览器静态契约测试，覆盖重试次数、空结果判定和反馈文案。
