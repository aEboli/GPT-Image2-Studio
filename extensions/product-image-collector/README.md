# GPT-Image2-Studio 商品图采集插件

## 安装

1. 解压下载的 ZIP 文件，保持目录结构不变。
2. 双击 `native-host/install-native-host.cmd`，完成当前 Windows 用户的本地剪贴板助手安装。
3. 在 Chrome 或 Edge 地址栏打开扩展管理页，并开启“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择解压后的目录。
5. 刷新已打开的 1688、Amazon、Temu、TikTok Shop、SHEIN 或大健云仓商品详情页，页面右侧会自动出现 `G2 商品图` 悬浮入口；点击入口或扩展栏图标都会直接展开采集窗。

Chrome 和 Edge 会要求用户确认本地扩展安装。本插件不会尝试静默安装。剪贴板助手安装脚本只把固定 EXE 复制到当前用户的 `%LOCALAPPDATA%`，并为 Chrome 和 Edge 写入固定名称的 Native Messaging host；`allowed_origins` 仅允许本插件的稳定扩展 ID。需要移除时双击 `native-host/uninstall-native-host.cmd`。
插件只申请六个平台明确商城域名的 HTTPS 站点访问权限，以及用户点击“复制图片”时调用专用助手所需的 `nativeMessaging` 权限；不申请回环 HTTP、`<all_urls>`、Cookie、历史记录或商家后台权限。自动入口、后台和采集器都会再次校验完整商品详情页地址，不会在首页、搜索页、分类页或 Seller Center 后台采集。

## 使用

- “复制到 Studio”会把选中图片写成版本化文本清单，不会复制 Cookie、密码或图片二进制。
- “复制图片”会调用插件自己的 Windows 本地剪贴板助手，把当前选中项写成一个多文件 FileDrop 剪贴板，可直接一次粘贴到聊天软件；无需启动或打开 Studio。单批最多 1000 张、请求最多 4 MiB、图片总量最多 512 MiB；成功后插件内会短暂显示半透明提示并淡入淡出，不会静默退化为只复制第一张。
- “下载所选”只保存图片，不会下载或打开 JSON 文件。目录格式为 `GPT-Image2-Studio/YYMMDD/商品ID-标题/`，例如 2026-07-27 使用 `260727`。
- 主图按 `主图-1`、`主图-2` 命名，详情图按 `详情图-1`、`详情图-2` 命名，SKU 图按 `SKU-1-规格名` 命名；共用一张图片的多个规格会合并到同一受限长度文件名。
- 选择区支持全选、反选、选主图、选详情图和选 SKU 图；三个分类按钮会把该分类全部追加到当前选择，不会取消其他分类或单图的既有选择。“开启折叠 / 关闭折叠”与全选、反选位于同一行。开启后采集窗会自动停靠到最近的网页边缘并收缩为可见窄栏，移入时展开，移出时再次折叠，不会整窗消失。
- 插件使用独立平台适配器识别商品 ID、标题、主图、详情图和 SKU 图。1688 标题只读取当前商品名称，不包含代发排行、库存、退款率、揽收率或加购人数；所有采集标题末尾统一显示无引号的 `——平台名称`。1688 继续优先读取页面声明的主图、SKU 规格和公开详情描述；Amazon 当前页面只读取与地址 ASIN 一致的受限 ATF/BTF 图库和带图规格声明，不执行页面脚本，也不追加其他规格隐藏图或 40×40 缩略图；TikTok Shop 当前页面优先读取与地址商品 ID 一致的高清主图、详情图和带图销售属性，每个带图属性值只保留一个 SKU，不按尺寸组合重复。其他平台优先读取 Product JSON-LD、高清图片属性及对应平台已知商品区域。页面结构不受支持时不会扫描整页图片。
- 当前支持消费者可见详情页：1688 `/offer/*`、Amazon `/dp/<ASIN>` 与 `/gp/product/<ASIN>`、Temu `-g-<商品ID>.html`、TikTok Shop 旧 `www.tiktok.com/shop/pdp/.../<商品ID>` 及当前 `shop.tiktok.com/<地区>/pdp/.../<商品ID>`、SHEIN `-p-<商品ID>.html`，以及大健云仓 GigaB2B 的 `product/product&product_id=`。不包含各平台商家后台。
- Temu 新版商品页从左侧语义主图库按顺序采集主图，从右侧命名规格选项采集 SKU 图，并从商品详情容器采集懒加载详情图。点击采集时如详情区存在 `See more`，插件只展开该商品详情区域并等待图片加载稳定；不会点击推荐区的 `View more` 或 `See more items`。
- 大健云仓当前商品页从 `#image-show` 采集主图，并恢复主图与规格缩略图对应的 CDN 原图；当前激活规格使用主图库最后一张作为 SKU 图，其他命名规格使用各自缩略图对应的原始对象。卡片仅加载约 300×300 的轻量预览，查看、复制和下载仍使用原图。页面没有独立详情图区域时，详情图显示为 0；采集过程不会点击规格、跳转商品或把推荐图和相似商品图猜成详情图。
- 清单、Studio 本地图片代理和独立剪贴板助手都会按平台成对验证来源与图片 CDN；Amazon、Temu、TikTok Shop、SHEIN、大健云仓或 1688 的图片域名不能跨平台混用，助手对每次重定向也会重复校验。
- 主图和详情图在各自分类内按图片地址合并重复项；一张图片同时属于主图、详情图或 SKU 图时会在各分类中完整保留对应语义。多个 SKU 规格使用同一张图片时，每个规格仍分别显示、选择、复制和下载，并使用各自的 SKU 顺序与规格文件名。
- 每个分组标题栏显示图片总数、已选数量、组内全选框和组内下载图标；组内全选不会清除其他分组的选择，部分选中时会显示半选状态，组内下载只提交该组当前选中的图片。已选卡片使用蓝色边框，图片底部左侧显示名称、右侧显示分辨率；SKU 卡片在操作按钮上方另行完整显示规格名称，不使用省略号。同一行四张卡片使用统一动态字号，以该行最难完整显示的规格名所需字号为准。Amazon 声明图先标记为未知尺寸，卡片加载规范化原图后再显示自然分辨率；大健云仓通过轻量图片元数据读取原图尺寸，不把 300px 预览或 74px 规格缩略图冒充为原图分辨率。
- 每张图片下方都有查看和下载图标按钮，悬停可查看中文说明；查看层只显示在插件面板内部，不会遮罩或超出到商品页其他区域。查看器删除左上角返回、图片标题和底部图片说明，仅保留右上角关闭以及上一张、下一张按钮。关闭、切换和六项图片工具均使用带轻微底色的半透明按钮；“全屏”以 cover 方式铺满插件舞台，`1:1` 回到未变换的 100% 比例并完整保留图片原始宽高比，两者每次点击只执行一次且可以连续重复点击，不会保持选中或卡住。“全屏”不会调用浏览器全屏；鼠标滚轮仍可在 50% 到 400% 之间缩放，放大后可按住鼠标左键拖动，点击插件内图片外区域或快速双击图片也可关闭。单图下载不要求先勾选该图片。
- 采集窗默认铺满当前网页可视区右侧全高，桌面宽度约为视口的 31%，并限制在 520–540px，在当前显示缩放下接近截图中的 800px；完整商品标题位于左侧标题区并可自然换行，标题下方不再显示数量。已选图片数、图片总数和 SKU 规格数完整显示在六个选择按钮下方的状态行；插件品牌仍位于商品标题右侧。每行显示 4 张媒体区约 115–120px 的缩略图，分组左右保留 8px，卡片之间使用 6px 小间距；按钮和文字维持当前紧凑比例。缩略图使用纯白背景并完整适配，非 1:1 图片会留白而不会裁切；查看、复制和下载仍使用原图片。图片底部使用浅色半透明信息栏，左侧完整显示 `主图-1`、`详情图-1` 或 `SKU 图-1` 短名称，右侧完整显示分辨率。全选、反选、开启/关闭折叠和三个分类选择按钮保持在同一行，窄屏时可横向滚动。主图、详情图和 SKU 图分组使用同一色相与饱和度，通过连续明度变化区分层次。图片列表在内部滚动且底部操作栏保持可见；从合并标题栏空白区域拖动可把窗口移到页面任意可见位置，释放到左右边缘时会恢复全高停靠。
- 关闭采集窗后页面右侧的 `G2 商品图` 悬浮入口会重新出现；入口本身不会读取或采集页面图片。
