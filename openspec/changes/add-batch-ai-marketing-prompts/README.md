# add-batch-ai-marketing-prompts

为 Creation 套图增加批量 AI 营销提示词规划与自动入队能力。

## 当前提案的术语

- **方案数量**：一次批量操作需要独立请求并提交的 AI 营销方案数量，例如 5 个方案。
- **每个方案生成套数**：每个独立方案要加入队列的套图任务数量，例如每个方案 2 套。
- **套图数量**：现有套图数量，表示每个队列任务内部要生成的营销图片数量，例如每套 2 张。

## 当前采用的解释

本变更把“很多套”解释为多次独立营销规划请求。按用户 2026-10-31 的双并发要求，每次请求使用新的变化种子，同时最多执行两个方案，任一方案冻结并完成入队后补充下一方案。详细并发边界见后续 enable-creation-dual-concurrency 增量规范。
