# GPT-Image2-Studio v0.2.13

`v0.2.13` 将主应用版本从 `0.2.12` 更新到 `0.2.13`。

## 更新内容

### 文章插图连续分镜

- 规划器先统计原文的自然段落簇，再要求每个段落或每个独立视觉节拍至少产出一张成品插图。
- 动作、情绪、对话、镜头角度或地点变化时追加连续帧；相邻分镜按可连续播放的动画帧对待，不合并节拍、不设置插图数量上限。
- `recommendedImageCount` 按实际产出的成品帧数返回，而不是一个预设的推荐值。

### 文章插图整套并发生成

- 文章插图生成改用与其他套图模式相同的有界并发循环扩散整套目标项，遵循配置中的请求并发数量和任务提交间隔，不再按单项串行推进。
- 同一批次内待生成的参考卡先于分镜完成，后续帧可以复用这些参考卡。

### 直连图片请求失败信息

- 直连图片请求连接失败时，错误信息会指明实际请求的端点，并把 Node 的 `fetch failed` 展开为底层原因，例如 `ENOTFOUND`、`ECONNREFUSED`、TLS 错误或 `UND_ERR_CONNECT_TIMEOUT`。
- 该路线在附带参考图后会把 `images/generations` 改写为 `images/edits`，因此失败地址不一定等于配置中填写的那一条；错误信息现在能区分中转不可达、端点填错和连接被拒绝。

### README 新手配置 API 教程

- 两份 README 的「配置说明」新增分步教程：需要准备的三样凭据、如何打开配置面板、路由模式/直接调用模式/Gemini 通道如何选择、每个通道填什么字段。
- 说明了测试连接与获取模型列表的真实行为：两者都请求 `GET <基础地址>/v1/models`，未保存的新 Key 也参与测试；测试通过只证明凭据与 `/models` 可用，不代表该通道支持生图、编辑、参考图或最大分辨率。
- 补充首次生成的验证路径、输出目录，以及常见首次使用报错对照表；「快速开始」增加指向该教程的入口。

## 升级说明

- 主应用每次更新仅递增一个补丁版本，即 `+0.0.1`。
- 既有配置、生成记录和图片资产不需要迁移。
- 商品图采集扩展使用独立版本线，本次主应用更新不会修改扩展版本。
