# GPT-Image2-Studio v0.2.2

`v0.2.2` 聚焦电商套图的可控规划、资产记录工作区和长任务可靠性。Creation Mode 现在将附加图片模块、平台计划、参考图识别和冻结计划贯穿到预览、队列、生成、记录与修复；资产浏览与详情检查也统一为更紧凑的工作台。

## 版本亮点

- **可控的 Creation 图片模块**：新增“SKU 图”开关，默认开启；“信息图重构”在新任务中默认关闭。两个选择会写入预览、队列、manifest 和修复参数，历史任务缺少 SKU 开关时保持兼容的开启行为。
- **平台计划更贴近实际素材需求**：19 个平台策略保留原生轮播槽位上限，通用电商保留 18 个槽位；套图级语言、比例、分辨率与兼容图片类型状态会冻结到有效计划。每个自动方案均包含尺寸或真实尺度用途，缺少尺寸证据时不会编造数值。
- **参考图识别一次应用且可人工纠正**：识别结果会一次性写入用途、说明、商品名、类目和规划证据；用途下拉框仍可编辑，后续预览与生成立即使用当前选择。
- **更大的有效冻结计划边界**：最多 64 个计划项、4 MiB 的有效计划可在 Local 与 Cloudflare Worker 路径提交，支持提示词较长的合法大套图，同时继续保留格式和字段校验。
- **全平台 Listing 统一交付**：19 个平台的策略影响内容侧重点，但新建或重写的草稿统一输出旧版中英对照字段。模型失败时直接生成可用 fallback，不进入审核或复制导出门槛；内容会移除品牌、商标、店铺、卖家和平台名称。
- **资产工作区与检查器更新**：瀑布画廊、文章插图、套图、写真和 PPT 记录采用统一导航、选择器和命令菜单；大图检查器提供提示词、参数和文件信息标签页。

## 修复与稳定性

- 修复参考图识别自动应用后的用途锁定与中间重绘问题，生成结果卡不再铺开过长的参考覆盖文本，完整信息仍保留在记录和详情中。
- 修复长任务流在未收到终止 SSE 事件时被误判为成功的问题，并改善上游 HTTP 错误、任务轮询和本地终止任务的处理。
- 修复人物参考图分析的陈旧响应可能覆盖当前素材状态的问题；PPT、文章插图与其他流式生成路径使用一致的终止事件判断。
- 修复已移除的通用灯箱删除控件与文章插图静态回归断言不一致的问题。

## 升级说明

- 版本号由 `0.2.1` 升级到 `0.2.2`，Git tag 为 `v0.2.2`。
- 新建套图默认生成 SKU 图、不默认生成信息图重构；需要旧工作流时，在生成前手动开启“信息图重构”。已保存任务的显式选择会保持不变，无需迁移。
- 源码运行仍要求 Node.js 20 或更高版本。Cloudflare Pages 部署需要基于本版本重新执行构建并发布新的 `dist/` 产物。
- Windows 用户可安装 `GPT-Image2-Studio-Setup-v0.2.2.exe`。覆盖安装前建议备份本地配置和重要输出。
