# GPT-Image2-Studio v0.2.138

`v0.2.138` 将主应用版本从 `0.2.128` 更新到 `0.2.138`。

## 更新内容

- 修复选中 2.6 后只更新模型名称和质量、未刷新 GIF/SVG 输出选项与参数入口的问题，路由 A/B 均即时生效。
- 在“开始生成”上方显示五种格式快捷按钮，GIF 帧数与时长直接填写，和共享高级设置双向同步；更多参数可一键展开。
- GIF/SVG 与参考图、多候选、透明背景及路由 A 未指定工具模型的冲突，在生成新任务前说明并拦截。
- SVG 的画廊、胶片条和详情优先加载矢量原件，保留 img 隔离展示、服务端校验及延迟加载；已有位图缓存不覆盖原件。画廊增加“SVG 矢量”标识，下载按钮显示“下载 SVG 原件”。

## 版本规则

- 小功能更新：更新位 +10。
- 版本格式为 `major.minor.patch`，patch 固定三位数字；上级版本变化时，下级版本归零。

## 升级说明

- 既有配置、生成记录和图片资产不需要迁移。
- 商品图采集扩展使用独立版本线，本次主应用更新不会修改扩展版本。
