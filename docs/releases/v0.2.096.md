# GPT-Image2-Studio v0.2.096

`v0.2.096` 将主应用版本从 `0.2.086` 更新到 `0.2.096`。

## 更新内容

- 新增 AI 营销提示词批量规划，可设置独立方案数量和每套入队数量；最多同时规划两套。每套通过事实、参考图和质量校验后，复用现有套图队列加入任务。
- 展示逐方案状态、运行耗时和重试信息。规划瞬时错误支持有界重试；失败、资料校验问题或用户取消会暂停后续方案。继续执行从失败方案恢复，并只补入尚未入队的副本。
- 加强营销质量审核，覆盖整套核心购买理由、主要功能事实、可见功能表现、图片任务重复和构图重复；修复时保留有效条目，锁定或平台必需任务仍遵守原有约束。
- 优化商品主图、使用场景和商业 CG 等视觉任务，强化产品身份、材料表现及有依据的功能效果。
- 统一 Responses 与 Chat Completions 的推理强度参数映射。仅当上游明确拒绝推理参数时，才在有界条件下调整或移除该参数；生图及状态不明的请求不会因此重放。

## 已知限制

- 批量进度目前仅保存在当前页面会话中。刷新后，已入队任务按现有队列和记录处理；尚未提交的方案不会自动恢复。

## 版本规则

- 小功能更新：更新位 +10。
- 版本格式为 `major.minor.patch`，patch 固定三位数字；上级版本变化时，下级版本归零。

## 升级说明

- 既有配置、生成记录和图片资产不需要迁移。
- 商品图采集扩展使用独立版本线，本次主应用更新不会修改扩展版本。
