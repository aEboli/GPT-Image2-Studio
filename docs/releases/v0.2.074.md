# GPT-Image2-Studio v0.2.074

`v0.2.074` 将主应用版本从 `0.2.073` 更新到 `0.2.074`。

## 更新内容

- **Prompt Kit 模板库**：内置 520 组带来源署名的 YouMind GPT Image 2.5 / GPT Image 2 提示词与配对图片，分别为 321 组和 199 组；支持按模型、使用场景、视觉风格和主体筛选，并支持搜索、排序、来源查看和一键应用。预览图随应用本地分发，记录保留来源页面和 CC BY 4.0 署名信息。
- **API 历史**：保存的 API 条目现在会按通道恢复对应的文本/视觉模型、生图模型、地址、接口后缀和 Key；选择器中只显示脱敏 Key，清单不会进入请求载荷或服务端配置。
- **界面配色**：配色从 8 套扩展到 12 套，保留「靛蓝」兼容标识并继续以「黑曜」作为新用户默认配色；配色选择会同步到嵌入的 Temu 工作台。
- **生成与查看体验**：优化生成等待动画的颜色相位与重建行为、图片查看器的小图适配、图片导入和灯箱交互，并改进图片转提示词结果的主体命名回退规则。
- **扩展兼容性**：商品图采集扩展的查看器适配小尺寸图片放大，扩展版本线保持独立。

## 版本规则

- 普通更新：更新位 +1。
- 版本格式为 `major.minor.patch`，patch 固定三位数字；上级版本变化时，下级版本归零。

## 升级说明

- 既有配置、生成记录和图片资产不需要迁移。
- 商品图采集扩展使用独立版本线，本次主应用更新不会修改扩展版本。
