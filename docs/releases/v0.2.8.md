# GPT-Image2-Studio v0.2.8

`v0.2.8` 将主应用版本从 `0.2.7` 更新到 `0.2.8`。

## 更新内容

- 移除已停用的 Cloudflare 运行路径，强化 Responses 原始结果恢复，并完善提示词任务队列与 Windows 发布产物。

## 升级说明

- 主应用每次更新仅递增一个补丁版本，即 `+0.0.1`。
- 既有配置、生成记录和图片资产不需要迁移。
- 商品图采集扩展使用独立版本线，本次主应用更新不会修改扩展版本。
