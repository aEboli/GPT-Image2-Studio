# GPT-Image2-Studio v0.2.12

`v0.2.12` 将主应用版本从 `0.2.11` 更新到 `0.2.12`。

## 更新内容

### 套图 SKU 与尺寸事实

- 浏览器请求、商品参考图补全和套图规划器现在都会保留尺寸组的 `variant`、`color`、`size` 标识。
- SKU 尺寸事实只会跟随其正确的变种/参考图组；共享或存在歧义的参考图绑定不会错误套用到其他 SKU。
- 参考图中已有的尺寸组会按可靠绑定补充到 SKU 主体，保留已有主体自身的尺寸事实。

### 文字语言与信息图边界

- 套图提示词现在明确保护商品和包装实物表面已有的文字。已印刷、雕刻、压印或刺绣的文字保留其原始字符和语言；画布周边新创作的标题、标签、标注、说明、步骤、包装清单和规格使用所选目标语言。
- 平台、场景、类目和视觉语言等规划标签明确为内部元数据，不会进入画面文字。
- 信息图重构沿用实物表面文字的保护边界，同时完整、忠实地翻译周边版式中的可翻译文字，并保留品牌名、型号、数字和单位。

### Prompt Agent 兼容解析

- JSON 解析支持 UTF-8 BOM、围栏或夹杂文字的 JSON、末尾多余逗号，以及同一响应在多个字段重复出现的情形。
- 流式解析支持 Chat Completions 的 `choices[].delta.content`、未标注 `text/event-stream` 的 SSE 正文、声明为 event stream 的一次性 JSON 信封，以及未带最后空行分隔符便关闭的最终 SSE 事件。

## 升级说明

- 主应用每次更新仅递增一个补丁版本，即 `+0.0.1`。
- 既有配置、生成记录和图片资产不需要迁移。
- 商品图采集扩展使用独立版本线，本次主应用更新不会修改扩展版本。
